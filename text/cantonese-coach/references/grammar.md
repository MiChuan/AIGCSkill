# 語法：12 個骨架 + 12 個必踩的坑

粵語語法不難，難在**它跟普通話像到會讓你套錯**。下面每一條都按同一個格式講：
句型 → 三行例 → 對比（普通話／英語）→ 最常見的錯 → 一句練習。

三行例的格式固定：**漢字 / 粵拼 / 意思**。少了粵拼，學習者記住的是錯的音。

## G1 係 / 喺 / 有 —— 三個字，三種關係

| 字 | 粵拼 | 管什麼 | 例 |
| --- | --- | --- | --- |
| 係 | hai6 | 判斷（A 就是 B） | 我**係**香港人。 |
| 喺 | hai2 | 位置（在） | 我**喺**香港。 |
| 有 | jau5 | 擁有 / 存在 | 我**有**兩個細佬。 |

```
我係香港人。
ngo5 hai6 hoeng1 gong2 jan4
我是香港人。
```

**對比**：普通話「是」與「在」分得清，但兩個字的粵語讀音都是 hai 開頭，初學者極易互換。
英語 `be` 一個動詞通吃，粵語偏偏要分三份。

**最常見的錯**：`你係邊度？`（你是哪裡？）→ 應該係 `你喺邊度？`（你在哪裡？）
前者會被理解成「你是哪個地方的人」，後者才是問位置。

**練習**：把「我在香港工作，我是設計師，我有三個同事」譯成粵語，三個動詞各用一次。

---

## G2 否定四件套：唔 / 冇 / 未 / 唔使 / 唔好

| 詞 | 粵拼 | 否定什麼 | 例 |
| --- | --- | --- | --- |
| 唔 | m4 | 一般動作、狀態 | 我**唔**去。 |
| 冇 | mou5 | 擁有、經歷（= 唔有） | 我**冇**錢。 |
| 未 | mei6 | 尚未（到現在為止沒有） | 我**未**食飯。 |
| 唔使 | m4 sai2 | 不需要 | **唔使**多謝。 |
| 唔好 | m4 hou2 | 禁止（不要） | **唔好**遲到。 |

```
我未食飯。
ngo5 mei6 sik6 faan6
我還沒吃飯。
```

**對比**：普通話「沒／沒有」覆蓋擁有與完成，粵語把「冇（擁有）」與「未（尚未）」分開。
`我冇食飯` = 我沒吃飯（事實），`我未食飯` = 我還沒吃（暗示等一下會吃）。這兩個不能混。

**最常見的錯**：`我唔有錢` → `我冇錢`；`我唔食咗` → `我未食` 或 `我冇食`。

**練習**：用四種否定分別回答「你去唔去？」「你有冇錢？」「你食咗飯未？」「使唔使幫你？」

## G3 體貌：六個跟在動詞後面的標記

粵語不靠時態，靠**體貌**（動作處於哪個階段）。

| 標記 | 粵拼 | 意思 | 例 |
| --- | --- | --- | --- |
| 咗 | zo2 | 完成、出現新狀態 | 我食**咗**飯。 |
| 緊 | gan2 | 正在進行 | 我食**緊**飯。 |
| 過 | gwo3 | 曾經 | 我去**過**日本。 |
| 住 | zyu6 | 狀態持續 | 佢著**住**件紅衫。 |
| 開 | hoi1 | 一向如此（習慣） | 我食**開**辣嘢。 |
| 吓 | haa5 | 短暫、試一下 | 睇**吓**先。 |

```
我食緊飯。
ngo5 sik6 gan2 faan6
我正在吃飯。
```

**對比**：普通話「了」同時管完成與狀態變化，粵語的「咗」只出現在**動詞後、賓語前**：
`食咗飯` 對，`食飯咗` 錯。英語用 `-ed / have -en` 表達的，粵語用體貌 + 時間詞共同表達。

**最常見的錯**：
- `我唔知咗`（咗不能加在否定式上）→ `我唔知`
- 每個過去的事都加咗：`我琴日去咗香港` 可以，但 `我琴日去香港` 也完全正確 —— 有明確時間詞時，咗是可省的

**練習**：同一件事（吃飯）用六個標記各造一句，體會差別。

## G4 嘅：的 + 構成「…的那個」

```
呢本係我嘅書。
ni1 bun2 hai6 ngo5 ge3 syu1
這是我的書。
```

`嘅` 有兩個用法：
1. **領屬／修飾**：我嘅書、好食嘅嘢、香港嘅天氣
2. **名詞化**：`紅色嘅好啲`（紅的那個比較好）、`邊個嘅？`（是誰的？）

**對比**：普通話「的」在口語裡常省，粵語 `嘅` 一般不能省：`我書` 聽起來像「我的書」的殘缺版，本地人會覺得怪。

**最常見的錯**：漏 `嘅`。`我朋友` 在粵語裡可以指「我的朋友」，但 `我嘅朋友` 更自然；而 `我嘅書` 絕不能說成 `我書`。

**練習**：把「我的手機、好吃的東西、昨天買的那個」譯成粵語，三個都要有 `嘅`。

## G5 量詞：指示詞後面必須有量詞

| 錯 | 對 | 粵拼 |
| --- | --- | --- |
| 呢書 | 呢**本**書 | ni1 bun2 syu1 |
| 嗰人 | 嗰**個**人 | go2 go3 jan4 |
| 一書 | 一**本**書 | jat1 bun2 syu1 |

常用量詞：個 go3（人、通用）、隻 zek3（動物、一隻）、條 tiu4（長條狀）、張 zoeng1（紙、枱）、
本 bun2（書）、架 gaa3（車）、杯 bui1、碗 wun2、件 gin6（衣服、事）、間 gaan1（房、店）、
部 bou6（機器、電影）、對 deoi3（鞋）、套 tou3（戲、衫）。

**對比**：英語 `this book` 不需要量詞，普通話「這書」口語也勉強能省，**粵語不能省**。
指示詞 + 量詞 + 名詞 是固定三格。

**練習**：指房間裡五樣東西，每樣都用「呢 + 量詞 + 名詞」講一次。

## G6 比較：過 / 同…一樣 / 最

```
佢高過我。
keoi5 gou1 gwo3 ngo5
他比我高。
```

| 句型 | 例 | 說明 |
| --- | --- | --- |
| A + 形容詞 + 過 + B | 佢高過我 | 粵語特有語序，形容詞在前 |
| A + 同 + B + 一樣 + 形容詞 | 我同佢一樣高 | 相等 |
| A + 冇 + B + 咁 + 形容詞 | 我冇佢咁高 | 不及 |
| 最 + 形容詞 | 呢個最平 | 最高級 |

**對比**：普通話「他比我高」是「比 + 人 + 形容詞」，粵語是「形容詞 + 過 + 人」。
直接把普通話語序搬過來會變成 `佢比我高` —— 本地人聽得懂，但一聽就知道不是母語者。

**最常見的錯**：`我高過佢啲`（我想說「高一點」）→ 應該係 `我高佢少少` 或 `我高過佢少少`。

**練習**：用「過 / 一樣 / 冇咁 / 最」比較三個朋友的身高。

## G7 俾：給、被、讓 —— 一個字三種角色

```
我俾本書你。
ngo5 bei2 bun2 syu1 nei5
我給你一本書。
```

| 用法 | 例 | 意思 |
| --- | --- | --- |
| 給予 | 我俾錢佢 | 我給他錢 |
| 被動 | 佢俾人偷咗銀包 | 他被人偷了錢包 |
| 使役／容讓 | 俾我試吓 | 讓我試試 |

**對比**：普通話「給我一本書」→ 粵語 `俾本書我`：**先物後人**，跟普通話相反。
被動句粵語用 `俾`，普通話用「被」，書面語才用「被」。

**最常見的錯**：`我俾你本書`（普通話語序）→ `我俾本書你`。

**練習**：把「他給了我一張票」「我的車被撞了」「讓我看看」譯成粵語。

## G8 將：把字句

```
我將啲書放喺枱面。
ngo5 zoeng1 di1 syu1 fong3 hai2 toi2 min6
我把書放在桌上。
```

`將` 用來把賓語提前，強調「怎麼處置」。口語裡更常用的是直接語序：`我放啲書喺枱面`。
所以 `將` 不是必須的，它是**強調處置結果**時才用。

**最常見的錯**：每句都用將（受了普通話「把」的影響），聽起來像新聞播報。

**練習**：同一句話寫兩個版本（有將／冇將），講出語氣差別。

## G9 得：能力、可能、可以

| 句型 | 例 | 意思 |
| --- | --- | --- |
| 得 / 唔得 | 得！／唔得。 | 行／不行 |
| 得唔得？ | 聽日得唔得？ | 明天行嗎 |
| V + 得 + 補語 | 睇得到 | 看得到 |
| 有得 + V | 有得食 | 有得吃（有供應／有機會） |

**對比**：普通話「能／可以／會」三分，粵語主要用 `得`（可能性）與 `識`（技能）、`會`（將然）。
`我識講粵語`（我會說，技能）vs `我得閒`（我有空）vs `我得`（我行）。

**最常見的錯**：`我可以去嗎？` → 粵語口語 `我可唔可以去？` 或 `我去得唔得？`

**練習**：用「得唔得」問三個請求（借筆、改時間、拍照）。

## G10 問句：不用「嗎」

| 類型 | 句型 | 例 |
| --- | --- | --- |
| 正反問 | V + 唔 + V | 你去**唔去**？ |
| 係唔係 | 係唔係 / 係咪 | 你**係唔係**香港人？ |
| 完成問 | V + 咗 + 未 | 你食**咗**飯**未**？ |
| 特指問 | 咩 / 邊 / 點 / 幾 | 你講**咩**？／去**邊**度？／**點**解？／**幾**時？ |
| 語氣問 | 句尾 + 呀 / 咩 | 你去呀？／你唔去咩？ |

**對比**：粵語口語**沒有**句末「嗎」。`你去嗎？` 是書面語腔，本地人會講 `你去唔去呀？`

**最常見的錯**：用「嗎」「呢」「吧」當語氣詞 —— 這三個在粵語裡不承擔疑問功能
（`呢` 在粵語是「這」，`吧` 幾乎不用）。

**練習**：把五句普通話問句改寫成粵語口語問句，一句一種句型。

## G11 副詞位置：兩個字最容易放錯

| 詞 | 粵拼 | 位置 | 例 |
| --- | --- | --- | --- |
| 先 | sin1 | **動詞後** | 你走**先**。／食飯**先**。 |
| 都 | dou1 | 動詞前 | 我**都**去。 |
| 就 | zau6 | 動詞前 | 我**就**嚟。 |
| 仲 | zung6 | 動詞前 | 佢**仲**未到。 |
| 啱啱 | ngaam1 ngaam1 | 動詞前 | 我**啱啱**走。 |
| 埋 | maai4 | 動詞後 | 食**埋**佢。 |
| 晒 | saai3 | 動詞後 | 做**晒**啲嘢。 |
| 返 | faan1 | 動詞後 | 著**返**件衫。 |

**對比**：「先」在普通話是「先吃飯」，粵語是「食飯先」—— 這是最高頻的語序錯。
「都」在粵語的用法比普通話寬：`我都去` 可以指「我也去」，也可以指「我乾脆去」。

**最常見的錯**：`我先食飯` → `我食飯先`。

**練習**：把「你先走，我隨後就來，我們一起吃」譯成粵語，注意「先」的位置。

## G12 語序：時間 → 地點 → 動作；先物後人

```
我聽日喺屋企食飯。
ngo5 ting1 jat6 hai2 uk1 kei2 sik6 faan6
我明天在家吃飯。
```

兩條固定順序：
1. **時間 → 地點 → 動詞**：`聽日`（時間）`喺屋企`（地點）`食飯`（動作）。這點跟普通話一致，跟英語相反。
2. **給予句先物後人**：`俾本書我`（給一本書我），不是 `俾我一本書`。

**最常見的錯**：受英語影響把地點放句尾（`我聽日食飯喺屋企`），或者給予句用英語語序。

**練習**：講出週末計劃，每句都要有時間 + 地點 + 動作。

## G13 連接詞：口語的三種搭配

| 搭配 | 例 | 備註 |
| --- | --- | --- |
| 因為…所以… | 因為落雨，所以我唔去 | 口語可以只用其中一半 |
| 雖然…但係… | 雖然遠，但係好食 | 「但係」不是「但是」 |
| 如果…就… | 如果落雨，我就唔去 | 「就」可省 |
| 一…就… | 一到夏天就熱 | 高頻 |
| 越嚟越… | 越嚟越貴 | 「越來越」 |

**最常見的錯**：`但是`、`所以呢` 的書面腔；口語用 `但係`、`所以`。

## 教學約定

- 每個語法點**一次只教一個**，例句不超過 5 句。
- 例子的三行（漢字／粵拼／意思）必須齊全，唔可以只寫漢字。
- 講「為什麼錯」時，用一句話講完，唔好展開成語法史。
- 每個語法點都配**一個必須避免的錯**，比配三個正確例句更有用 —— 因為學習者只會記住他本來就會犯的那個。
