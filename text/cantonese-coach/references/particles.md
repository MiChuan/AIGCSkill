# 語氣助詞：粵語的「態度層」

一個句子在粵語裡有兩層：**命題層**（說了什麼）和**態度層**（我對這件事什麼態度）。
語氣助詞就是態度層。它不改變事實，只改變說話人站在哪裡。

這也是粵語最不像教科書的地方 —— 教材教「你去邊度？」，街上聽到的是「你去邊度呀？」。
少了那個 `呀`，句子文法沒錯，但聽起來像審問。

---

## 1. 十二個句末助詞

| 助詞 | 粵拼 | 態度 | 例 | 對應的英語語調 |
| --- | --- | --- | --- | --- |
| 呀 | aa3 | 緩和、確認、禮貌疑問 | 你去**呀**？ | 尾音微升，語氣放軟 |
| 啦 | laa1 | 建議、勸、催促 | 走**啦**。 | "come on" |
| 喇 | laa3 | 狀態已改變、已經 | 食咗**喇**。 | "already" |
| 囉 | lo1 | 顯而易見、無奈 | 咁做**囉**。 | "obviously / whatever" |
| 咯 | lok3 | 讓步、那就 | 咁我走**咯**。 | "well then" |
| 咩 | me1 | 反問、意外 | 你唔知**咩**？ | "really?" |
| 喎 | wo3 | 轉述、提醒 | 佢話唔嚟**喎**。 | "apparently" |
| 啩 | gwaa3 | 推測、不確定 | 佢應該到咗**啩**。 | "I suppose" |
| 嘅 | ge3 | 陳述事實（帶解釋） | 我唔知**嘅**。 | "that's just how it is" |
| 啫 | ze1 | 只是、而已 | 講笑**啫**。 | "just kidding" |
| 嘛 | maa3 | 理所當然 | 你話嘅**嘛**。 | "like you said" |
| 添 | tim1 | 額外、更進一步 | 仲有**添**。 | "on top of that" |

另外兩個高頻但不算典型助詞：

| 詞 | 粵拼 | 用法 | 例 |
| --- | --- | --- | --- |
| 先 | sin1 | 次序（動詞後）／暫且 | 你走**先**。／等陣**先**。 |
| 咁滯 | gam3 zai6 | 幾乎、差不多 | 我差啲跌親**咁滯**。 |

## 2. 同一件事，八種講法（教學最有效的一張表）

命題固定：`佢走咗`（他走了）。加不同助詞，態度完全不同。

| 講法 | 粵拼 | 說話人站在哪 |
| --- | --- | --- |
| 佢走咗**喇**。 | keoi5 zau2 zo2 laa3 | 報告新狀態：他走了（所以可以進去了） |
| 佢走咗**啦**。 | keoi5 zau2 zo2 laa1 | 勸你接受：他走了，算了吧 |
| 佢走咗**囉**。 | keoi5 zau2 zo2 lo1 | 無奈：走了就走了 |
| 佢走咗**咯**。 | keoi5 zau2 zo2 lok3 | 讓步：那我也走了 |
| 佢走咗**咩**？ | keoi5 zau2 zo2 me1 | 意外：他走了？（我以為他還在） |
| 佢走咗**喎**。 | keoi5 zau2 zo2 wo3 | 轉述提醒：聽說他走了（你要知道） |
| 佢走咗**啩**。 | keoi5 zau2 zo2 gwaa3 | 推測：他大概走了 |
| 佢走咗**嘅**。 | keoi5 zau2 zo2 ge3 | 強調事實：他確實走了（在解釋原因） |

教學上先教 `喇 / 啦 / 咩 / 嘅` 四個，這四個覆蓋日常八成的態度需求。其餘四個等中級再補。

## 3. 動詞後的助詞：管「動作階段」而不是「態度」

| 助詞 | 粵拼 | 功能 | 例 |
| --- | --- | --- | --- |
| 咗 | zo2 | 完成 | 食**咗**飯 |
| 緊 | gan2 | 進行 | 食**緊**飯 |
| 過 | gwo3 | 經歷 | 食**過** |
| 住 | zyu6 | 狀態持續 | 坐**住** |
| 開 | hoi1 | 一向如此 | 食**開**辣 |
| 吓 | haa5 | 短暫、試一下 | 睇**吓** |
| 埋 | maai4 | 連同、一併 | 食**埋**佢 |
| 晒 | saai3 | 全部完成 | 食**晒** |
| 返 | faan1 | 回復原狀 | 著**返**件衫 |
| 起上嚟 | hei2 soeng5 lai4 | 一旦…起來 | 熱**起上嚟** |

**兩層可以疊**：動詞助詞在動詞後，句末助詞在句尾。

```
我食晒啲飯喇。
ngo5 sik6 saai3 di1 faan6 laa3
我把飯全吃完了。
```
`晒` 管「全部」，`喇` 管「已經」—— 一個管範圍，一個管時間。

## 4. 五組高頻組合

| 組合 | 粵拼 | 語氣 | 例 |
| --- | --- | --- | --- |
| 嘅啫 | ge3 ze1 | 只是在…而已（軟化） | 我講吓**嘅啫**。 |
| 咗喇 | zo2 laa3 | 已經完成了（通知） | 搞掂**咗喇**。 |
| 緊呀 | gan2 aa3 | 正在…（回應催促） | 做**緊呀**。 |
| 先啦 | sin1 laa1 | 先…吧（建議） | 食飯**先啦**。 |
| 都得 | dou1 dak1 | 也可以（讓步） | 聽日**都得**。 |

## 5. 教科書陷阱：三個用錯會很怪的詞

| 書面／普通話 | 粵語口語 | 說明 |
| --- | --- | --- |
| 你去**嗎**？ | 你去**唔去呀**？ | 粵語口語冇句末「嗎」 |
| 你**呢**？ | 你**點呀**？ | 粵語的「呢」(ni1) 主要是「這」（呢個）；句末 `呢`(ne1) 只作對比追問，範圍窄，初學先用「你點呀」 |
| 好**吧** | 好**啦** / 好**啩** | 「吧」在粵語口語幾乎不用 |

要注意：`呢` 在粵語有兩個身份 —— `呢個`（這個，ni1）和句末 `呢`（ne1，用於對比追問，例如「我唔去，你**呢**？」）。
後者存在但範圍比普通話窄得多，初學者先別用。

## 6. 三個練習

**練習 A（5 分鐘）**：拿一句中性句 `佢唔嚟`，加上 `喇 / 啦 / 咩 / 嘅 / 啩 / 喎` 六個助詞，
每個都講出「說話人相信什麼、想對方做什麼」。講不出來就是還沒懂。

**練習 B（10 分鐘，聽力）**：看一段港劇，只記句末助詞，不記內容。
一集裡 `喇 / 啦 / 呀 / 嘅` 應該各出現十次以上。記錄「字幕翻譯有沒有體現這個語氣」——
通常沒有，這就是為什麼看字幕學不到助詞。

**練習 C（3 分鐘，輸出）**：把一句太硬的拒絕軟化三次：
`我唔去` → `我唔去喇` → `我唔去嘅` → `我唔去嘅，你哋玩啦`。體會軟化的層次。

## 7. 驗收

- [ ] 能講出 `喇` 與 `啦` 的差別（一個報狀態、一個勸）
- [ ] 能聽出 `咩` 是反問而不是普通疑問
- [ ] 知道 `嘅啫` 用來軟化，`嘅` 用來解釋
- [ ] 不會在粵語口語裡用「嗎」「吧」
- [ ] 一句話能講兩個版本（硬版／軟版），並說出為什麼要軟
