# 詞彙：100 個怎麼選、怎麼排、怎麼背

詞表本身在 `specs/deck-core-100.json`（`vocab_deck.py` 一鍵出卡片、CSV、默寫紙）。
這份文件講的是**選詞的判據**，以及四張必須另外練的附表 —— 數字、量詞、時間、稱謂。
那四張表刻意不進 100，因為它們是「封閉集合」，靠 drill 背比靠卡片背快得多。

---

## 1. 三層分法與它的理由

| 層 | 數量 | 判據 | 例子 |
| --- | --- | --- | --- |
| 第一層：冇佢活唔到 | 30 | 一天要用三次以上，或者缺了它連話都開不了口 | 唔該、幾多、係、唔、去 |
| 第二層：旅行現場一定撞到 | 45 | 場景可預測，缺了它要改用英文 | 埋單、走冰、轉左、藥房 |
| 第三層：傾偈講感受先用 | 25 | 表達態度、時間、因果 | 攰、鍾意、其實、但係 |

**為什麼不按主題分**（食物 20 個、交通 20 個）：
真實對話不會按主題發生。你在茶餐廳會同時用到 `唔該`（第一層）、`凍奶茶`（第二層）、`其實`（第三層）。
按主題分的詞表，學習者會在「交通課」學完 20 個詞，然後在餐廳一個都用不上。
按**頻率 + 可組合性**分層，才是能立刻用的順序。

---

## 2. 挑詞的三個判據

1. **能不能組合**：`唔該` 能長出 `唔該晒`、`唔該埋單`、`唔該借借`；`請` 在粵語口語幾乎不長東西。
   一個詞能組出越多常用搭配，優先級越高。
2. **能不能救命**：`我聽唔明`、`講慢啲`、`救命` 這三句，任何一個場景都用得上，屬於最高優先。
   反過來，`菠蘿包` 很具體，但指一下就可以代替。
3. **出現頻率是否可驗證**：優先選你在港劇、YouTube、街上**反覆聽到**的詞。
   只在教材裡出現、街上聽不到的詞（例如 `請問`），放後面。

**刻意排除的三類**：
- 書面語對應詞（吃、喝、看、說、漂亮、喜歡、累）—— 學了會干擾，直接學粵語詞
- 專有名詞（景點、店名）—— 現場看牌子即可
- 低頻但「好有意思」的詞（歇後語、俚語）—— 中級以後再說，初級學了沒有使用場景

## 3. 附錄 A：數字與錢（必練，不進 100）

| 數字 | 粵拼 | | 數字 | 粵拼 |
| --- | --- | --- | --- | --- |
| 一 | jat1 | | 六 | luk6 |
| 二 | ji6 | | 七 | cat1 |
| 三 | saam1 | | 八 | baat3 |
| 四 | sei3 | | 九 | gau2 |
| 五 | ng5 | | 十 | sap6 |

規則：
- **報數用「二」，帶量詞用「兩」**：二十二 ji6 sap6 ji6、**兩**個人 loeng5 go3 jan4、**兩**蚊 loeng5 man1。
- 二十口語可講「廿」jaa6：廿一 jaa6 jat1。
- 百 baak3、千 cin1、萬 maan6、零 ling4。
- 錢：蚊 man1（元）、毫 hou4（角）、仙 sin1（分）。`三蚊`、`五毫`、`兩蚊半`。
- 買單相關：埋單 maai4 daan1、找錢 zaau2 cin2、加一 gaa1 jat1（加一服務費）、貼士 tip1 si2。

⚠️ 粵語的「一」**不變調**（普通話 yī / yí / yì 三讀）。`一蚊`、`一個`、`一日` 全部讀 jat1。

## 6. 附錄 D：香港 / 廣州 / 澳門 的差別

教材、媒體、粵拼方案都以**香港**為準，所以本 skill 默認香港標準。實際交流會遇到：

| 概念 | 香港 | 廣州 | 備註 |
| --- | --- | --- | --- |
| 巴士 | 巴士 baa1 si2 | 巴士（口語）／公交（書面） | 廣州書面語受普通話影響更深 |
| 的士 | 的士 dik1 si2 | 的士（口語）／出租車（書面） | 同上 |
| 冰箱 | 雪櫃 syut3 gwai6 | 冰箱 bing1 soeng1 | |
| 士多（小商店） | 士多 si6 do1 | 小賣部 | 香港英文借詞多 |
| 手機 | 手機 sau2 gei1 | 手機 | 一致 |

**英文借詞**（香港高頻，學了立刻聽得懂街上的話）：
巴士 baa1 si2、的士 dik1 si2、士多 si6 do1、芝士 zi1 si2、多士 do1 si2、
沙律 saa1 leot2、三文治 saam1 man4 zi6、免治 min5 zi6、貼士 tip1 si2、波 bo1、咕喱 gu1 lei1。

## 8. 附錄 F：唔該 vs 多謝（一張決策樹）

```
對方做了什麼？
├─ 提供了服務、勞力、方便（上菜、遞東西、讓路、回答問題、收錢）
│   → 唔該 m4 goi1
├─ 給了你東西 / 讚美你 / 幫了一個大忙（禮物、紅包、搬家）
│   → 多謝 do1 ze6
└─ 不確定
    → 唔該（它同時有「勞煩你」的意思，比較安全）
```

回應：
- 對方講 `唔該` → `唔使`／`唔使客氣`
- 對方講 `多謝` → `唔使客氣`／`唔好客氣`

這是粵語最容易被普通話母語者搞錯的一條（普通話「謝謝」通吃）。
用錯不會被責怪，但一開口就知道你是外來者。

## 9. 卡片規則（背詞的質量取決於卡片長什麼樣）

1. **一卡一義**：正面漢字，背面粵拼 + 意思 + **你自己造的句子**。
2. **不抄例句**：抄來的句子記不住，自己造的（哪怕有錯）才記得住。錯的句子拿來給教練改，一舉兩得。
3. **聲調一定寫數字**：`nei5 hou2`，不要寫 `néihóu`，也不要只寫 `nei hou`。
4. **一卡不超過 7 個字**：超過就拆成兩張。
5. **答錯兩次退回上一間隔**：見 `curriculum.md` 的間隔表。
6. **每週清一次「死卡」**：連續三次答對的卡移到「維護隊列」，每月抽一次，不再佔用每日時間。
