# 案例：川西牧道（旅行纪实）

这个案例走完整条链路：一段自然语言需求 → spec → 结构化提示词 → 出图 → 体检 → 调色 → 交付。
所有命令都可以直接复制运行。

## 一、需求拆解

原始需求是一段形容词：

> 复刻《国家地理》经典纪实摄影调色风格，主打真实、浓郁、立体、复古的人文自然质感，
> 全局色彩还原精准、饱和度适中偏高，原色通透扎实、真实耐看，无滤镜虚假感……

这段话里能直接进提示词的只有两三条，其余必须翻译。拆法：

| 原话 | 可执行条款 |
| --- | --- |
| 复刻《国家地理》调色风格 | 品牌名剔除，展开成光色条款 + 禁止边框字标 |
| 饱和度适中偏高 | `vibrance` 1.14；`sat_mean` 目标 0.26–0.56；单色块内部必须有层次 |
| 原色通透扎实 | 色相偏移 < 8°；`vibrance` 不用乘法而用窗口曲线 |
| 无滤镜虚假感 | 禁止整体色偏、橙青分离、暗角、HDR；`cast_conf` 监控 |
| 对比度高级硬朗 | `mid` 1.20（只动中间调，不动两端） |
| 光影层次立体分明 | 三层结构 + `clarity` 26（大半径局部对比） |
| 蓝天通透、绿植鲜活、大地醇厚 | 天空 200–218°、植被 85–125°、大地 20–42° |
| 肤色自然真实、质感立体 | 肤色 20–32°、S 0.28–0.50、排除法保护 |
| 暗部细节丰富、深邃干净 | 黑位落 5%–10%，`shadow_lift` 11，`shadow_open` ≥ 5 |
| 高光通透柔和、细节完整 | 白位落 96%–98%，`white_level` 248 |
| 动态范围充足、容错度高 | `contrast_p90_p10` 95–205，两端都留余量 |
| 复古大气、永不过时 | `vintage` 0.30（通道间差 1–3 级），颗粒 0.04 |

**注意「复古」这条**：它不是「做旧」。做旧是降饱和 + 加黄 + 加划痕；
纪实的复古是**暗部略冷、高光略暖**的分离，幅度小到看不出，只觉得「不像数码直出」。

## 二、spec

`specs/natgeo-ganzi.json` 的骨架：

```json
{
  "mode": "travel",
  "style_anchor": { "raw": "《国家地理》经典纪实摄影调色风格", "mapped": "" },
  "region": "四川甘孜 · 塔公草原东缘，雅拉雪山正北方向的一处牧道",
  "season": "十月末，草色由绿转金，雪线刚压到山腰",
  "weather": "晴，天顶无云，地平线附近有一层薄的高积云；能见度约 60 公里",
  "scene": "清晨七点前后的牧道：一条被踩实的土路从画面右下斜插进草原深处……",
  "subject": "逆光下正在赶牛的藏族牧民，走在牛群侧后方……",
  "people": { "count": 1, "desc": "…", "skin": "…" },
  "camera": {
    "lens": "35mm",
    "height": "略低于视平线，约与牧民腰部平齐，机位蹲低贴近草面",
    "layers": ["前景：…", "中景：…", "远景：…"]
  },
  "light": { "time": "日出后约 40 分钟", "direction": "侧逆光…", "ratio": "1:3.5" },
  "palette": { "elements": ["天空", "植被", "大地", "雪线", "服饰"], "accent": "…" },
  "tone": { "grain": 0.12, "klass": "晨光暖调，但阴影侧不被染暖" },
  "aspect": "3:2",
  "size": "2048x1365"
}
```

三个容易写错的地方：

1. **`region` 要具体到能推出光照与植被**。写「川西」不够，写「塔公草原东缘的牧道」才够——
   它决定了草是针茅、土路被踩实、远景是雅拉雪山的山体而不是任意一座雪山。
2. **`camera.layers` 三层都要有内容**，而且不能都是同一层。
   缺了它，画面会变成一张「所有东西都差不多清楚」的平片——这是 AI 风光图最常见的毛病。
3. **`tone.klass` 是自由文本**，用来写这套预设表达不了的东西。
   本例写的是「阴影侧不被染暖」——因为默认的复古分离会把阴影也带暖，而晨光片里
   山体阴影应该是冷灰的。**暖与冷同画面并存，才不是「整张罩了一层黄」。**

## 三、装配与质量门

```bash
python scripts/build_ng_prompt.py --spec specs/natgeo-ganzi.json --outdir out/demo
```

输出：

```
[info] 风格锚点「国家地理」已翻译成光色条款：品牌名只写进提示词会让模型去画边框和字标，
       所以提示词里只说「经典纪实摄影的调子」，不说杂志名
[warn] W310 有主要人物，但 palette.elements 里没有肤色条款：已自动补上「肤色与大地色分离」一段。
       土色都在 20°–42° 色相区，不单独约束的话模型会顺手把脸一起推饱和，出来是橘色的脸
[info] 已自动把「没有黄色矩形边框 / 没有杂志字标 / 没有白边」写进提示词与禁止项
[write] out/demo/prompt.txt（3506 字）
```

`W310` 是**自动修复型警告**：它不只是提示，还真的往提示词里加了一段。
留着这个消息是让你知道「原 spec 缺了这一条」，下次自己写上。

成品提示词的关键段落（节选）：

> **【色彩】** 饱和度适中偏高：天、草、土、水的本色还原准确，饱和度抬高但不改变色相，
> 没有滤镜式的偏色。分色要求如下（色相以 HSV 计）：天空（色相 200°–218°）：天顶深青蓝、
> 向地平线逐渐变浅并略降饱和，云的白是干净的暖白，云底有淡淡的蓝灰；植被（色相 85°–125°）：
> 鲜活的黄绿到深绿，受光面偏黄绿、背光面偏冷绿，深绿不发黑、不发荧光……肤色必须与大地色分离：
> 受光皮肤的饱和度和明度都低于同一画面里的土色，阴影侧的皮肤偏冷褐而不是偏绿，
> 不允许把脸推成砖红或橘黄。

> **【影调与动态范围】** 中高对比，光影层次立体分明，近中远三层各自成立；暗部深邃干净，有细节；
> 高光通透柔和，有细节。调色顺序必须是「先立动态范围、再给中间调对比」，反过来就是 HDR 的假亮。
> 黑位：最深的暗部落在 5%–10% 的亮度区间而不是 0，纯黑区域里仍然能读出纹理走向……

## 五、体检与调色

```bash
# 1. 先体检。压死/曝死会被拦下来（退出码 1）
python scripts/grade.py out/demo/raw/x.png --check

# 2. 没被拦就调色 + 8K 交付
python scripts/grade.py out/demo/raw/x.png --out out/demo/x_8k.jpg \
    --preset travel --target 8k --report out/demo/report.json
```

调色链跑完会打印「调色前 / 调色后」两组读数，直接看差值就知道这道链动了什么。

**合成图上的实测**（用 `scripts/selftest.py` 现场生成，故意做成低对比 + 抬黑的
「网红滤镜」观感，色阶只占 95–153）：

| 指标 | 调色前 | 调色后 | 判读 |
| --- | --- | --- | --- |
| `contrast_p90_p10` | 43 | 149 | 色阶铺满，中段打开 |
| `p5` | 95 | 18 | 黑位从「雾底」回到暗部 |
| `shadow_luma` | 118 | 71 | 暗部从「提亮成雾」回到暗部 |
| `shadow_open` | 4.7 | 9.7 | 暗部重新有结构 |
| `sat_mean` | 0.302 | 0.669 | ↑ 见下方说明 |
| `hue_sky` | 214 | 209 | 仍在 195–228 区间内 |

`sat_mean` 冲到 0.669 是**合成图特有的现象**：这张测试图的色块本身就是纯色（S≈1.0），
色阶一拉开就直接撞到饱和上限。真实照片的色块内部有连续变化，同样的参数只会推到 0.40 左右。

这条差距正好说明一件事：**`sat_mean` 不能跨题材套阈值**，只能同题材之间比较。

## 六、三个典型失败

### 失败一：出来一个黄色边框

**现象**：画面四周有一圈黄边，右下角或底部有白色字标，构图像是被塞进了杂志版面。

**原因**：提示词里直接写了杂志名，或者 `style_anchor.raw` 被原样塞进了 prompt。

**修法**：确认 `prompt.txt` 里**没有**品牌名；确认 `【禁止】` 一段里有
「黄色矩形边框、杂志排版、白边」。这两条都由脚本自动加，出现这个现象说明链条被绕过了。

### 失败二：天很蓝，草很绿，但一看就是假的

**现象**：饱和度很高，但色块之间没有层次，红衣服上没有褶皱，云是一块纯白。
体检读数会是 `sat_mean` > 0.6、`p99` ≈ 255、`clipped_ratio` 偏高。

**原因**：两条。「浓郁」被理解成了「加饱和」；以及影调顺序反了——先说对比，模型直接给 HDR。

**修法**：提示词里把「浓郁」写成「色块内部有层次、相邻色能分开、不亮到失去纹理」；
影调段把「先立动态范围，再给中间调对比」放在最前面。
后期救不回来——高光已经 255 的地方没有信息。

### 失败三：脸是橘色的

**现象**：场景里的土墙、路面都对，唯独人的脸偏橙红，和周围的大地色分不开。

**原因**：肤色（20°–32°）和大地色（20°–42°）色相重叠，模型把脸当成「暖色块」一起推了饱和。

**修法**：spec 的 `palette.elements` 里显式加一条「肤色」，
或者干脆让脚本自动补（`W310`）。后期用 `grade.py` 的排除法也只能救回一部分——
真正的问题是出图时就没分开，重出比后期划算。
