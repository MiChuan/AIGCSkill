# 提示词公式：把「纪实感」写成可执行的条款

## 一、先说最大的坑：不要只写品牌名

写「《国家地理》风格」，模型会给你四样东西：

1. **一个黄色矩形边框**（它见过的最强视觉关联）
2. **白色无衬线字标**，位置和字体都不对
3. 广角畸变的边角拉伸
4. 整体偏低的饱和 + 一层灰雾（它把「纪实」理解成「旧」）

结果是一张「杂志内页的仿制品」，而不是一张照片。

所以本 skill 的做法是：**品牌名只在 `style_anchor.raw` 里出现，进提示词时被翻译成光色条款**，
同时把边框、白边、字标、杂志版式写进禁止项。`build_ng_prompt.py` 会自动做这件事并打印一条
`[info]` 告诉你替换成了什么。

## 二、十五节的顺序

顺序不是随便排的，它对应模型做图的决策顺序：先定拍什么，再定怎么拍，最后定怎么洗。

| # | 段落 | 解决什么 | 漏了会怎样 |
| --- | --- | --- | --- |
| 1 | 任务 | 这是一张照片，不是插画/渲染 | 出来是概念图 |
| 2 | 风格定位 | 把品牌名翻译成光色条款 | 出来是杂志仿制品 |
| 3 | 场景 | 地点、季节、天气、发生了什么 | 出来是「随便一座山」 |
| 4 | 人物 | 人的状态、肤色、质感 | 出来是摆拍的游客 |
| 5 | 构图与镜头 | 焦段、机位高度、三层结构 | 出来是一张平片 |
| 6 | 光线 | 时段、光质、方向、光比 | 出来是正面平光 |
| 7 | 色彩 | 全局取向 + 分色锚点 | 出来通篇艳色 |
| 8 | 影调与动态范围 | 黑位/白位/中间调/局部对比 | 出来是 HDR |
| 9 | 质感与细节 | 材质的反射性质 | 出来是塑料 |
| 10 | 真实感红线 | 单一光源、材质属性、元素合理性 | 出来是拼贴 |
| 11 | 禁止 | 反向词表 | 出来带水印、带边框 |
| 12 | 输出 | 画幅与尺寸 | 出来比例不对 |

## 三、色彩：给锚点，不给形容词

「通透的蓝天」在模型里可以是任何蓝。给一个 HSV 区间，就只有一种蓝。

| 元素 | 色相 | 写进提示词的描述 |
| --- | --- | --- |
| 天空 | 200–218 | 天顶深青蓝、向地平线变浅并降饱和；云受光面暖白、云底灰蓝 |
| 植被 | 85–125 | 受光偏黄绿、背光偏冷绿；深绿不发黑、不发荧光 |
| 大地 | 20–42 | 红棕到土黄，明度中等偏低，带一点复古的暖，不是橙也不是灰 |
| 水体 | 185–210 | 深水偏青蓝且通透，浅水偏中性白，反光是碎高光而不是一片白 |
| 岩石 | 25–45 | 中性偏暖的灰褐，受光暖、背光冷，不是单一灰 |
| 雪线 | 200–220 | 雪不是纯白：受光暖白、阴影淡蓝，有细微蓝紫过渡 |
| 建筑 | 18–45 | 风化暖墙与冷阴影并存，砖石各有固有色 |
| 肤色 | 20–32 | 受光暖、暗面同色加深、高光是反光不是白斑 |

三条附带规则，缺一条就会翻车：

1. **暗部不参与「浓郁」**：阴影只降明度、不降到发灰，也不许整体染蓝染绿。
2. **高光不参与「浓郁」**：高光处饱和度自然衰减，否则高光边缘出现彩色镶边。
3. **肤色与大地色分离**：两者色相几乎重叠（20°–42°），不单独约束，模型会把脸和土墙一起推饱和。

## 四、影调：顺序比数值重要

必须写成「先立动态范围，再给中间调对比」。反过来的写法（先说「对比强烈」）会让模型
直接给你暗部压死 + 高光爆掉的 HDR。

可执行的写法：

- 黑位：最深的暗部落在 **5%–10%** 的亮度而不是 0，纯黑区域里仍能读出纹理走向
- 白位：最亮的高光落在 **96%–98%** 而不是被裁到 255，云雪水面高光内部有层层过渡
- 中间调：明暗交界过渡紧凑、斜率略陡
- 局部对比：靠光线的自然衰减产生体积感，**不靠锐化与清晰度滑块硬拉**

最后一句很关键。「立体」在摄影里来自光线，在修图软件里来自 clarity 滑块——这两者在成图上
看起来相似，但在细节上完全不同：前者有方向，后者在四周都有一圈亮边。

## 五、构图：三层与镜头习惯

纪实摄影的镜头习惯是「靠近了拍」，不是「拉长了拍」。

- 焦段优先 **28–50mm**。超长焦压缩空间、超广角拉伸边角，两者都会立刻暴露「不是纪实」
- 机位高度必须写。「蹲低贴近草面」和「站着平视」是两种完全不同的照片
- 三层结构必须写：前景（贴镜头、微虚）、中景（主体、全焦内）、远景（对比降低、偏冷）
- 层次靠**空气透视**分开，不靠虚化硬切

## 六、真实感红线

三条，写在提示词正文里，不是禁止项里：

1. 光线只有一个来源方向，所有物体的受光面与投影都服从它
2. 材质的反射性质不串：布不反光、石头不透明、水面必反光
3. 没有任何「为了好看」而存在的元素——每样东西都要能回答「它为什么在这里」

第 3 条是区分「照片」和「AI 图」最有效的判据。AI 图里总有一个说不清为什么在那里的东西：
一朵位置完美的花、一缕恰好飘过镜头的光、一个恰好站在黄金分割点上的路人。

## 七、高危词表

这些词写进 spec 会被质量门拦下（`E306`），因为它们会把画面推向相反的方向：

| 词 | 为什么 |
| --- | --- |
| HDR | 局部提亮 + 灰雾，正是「虚假感」的来源 |
| 去雾 | 把空气透视一起抹掉，远景失去纵深 |
| 暗角 / vignette | 短视频滤镜的标志 |
| 霓虹 / 赛博 | 与本风格的光色逻辑完全相反 |
| 橙青 / teal and orange | 电影海报的商业调色，会把真实肤色烧成橘色 |
| 动漫 / 插画 / 油画 | 丢掉全部材质与光学真实感 |
| 3D 渲染 / 塑料 | 塑料高光是本风格的头号反面 |
| 磨皮 | 抹掉皮肤质感，而纪实人像恰恰要留毛孔与皱纹 |
| 过度锐化 | 白边光晕，暗部细节看起来像噪点 |

另外，正午的硬光（`W305`）也会被提示：顶光把地形压平、阴影缩到脚下、天空发白，
是纪实风光最典型的翻车时段。
