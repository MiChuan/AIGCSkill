# 经典纪实调色：真实、浓郁、立体、复古

一句话：**这个 skill 卖的不是滤镜，是「一张看起来像真的拍到的照片」。**
所有参数都服务于一件事——让画面在噪点、色偏、裁切、塑料感的任何一项上都挑不出毛病。

四个 skill 的分工：`cinematic` 管人进场景，`lowkey-portrait` 管人被打光，`photo-seal` 管照片变符号，
本 skill 管**调子**——同一个场景，用什么光色关系呈现出来。

## 五条不可让的约束

### 1. 品牌名只能出现在 spec 里，不能出现在提示词里

「国家地理风格」这五个字进提示词，模型会给你：黄色矩形边框、白色无衬线字标、广角畸变、
一层灰雾。它给的是**杂志内页的仿制品**，不是照片。

所以本 skill 把品牌名翻译成光色条款，同时把边框/白边/字标/版式写进禁止项。
`build_ng_prompt.py` 会自动完成替换并打一条 `[info]` 说明。**不要关掉这个替换。**

### 2. 「浓郁」是纯度，不是亮度

新手调「浓郁」的方式是把饱和度拉高。结果是色块变亮、失去纹理、相邻色糊成一片——
那是「艳」，不是「浓郁」。

真正的浓郁有三个条件同时成立：

- 同色相**内部**有深浅层次（草地从黄绿到深绿，不是一片绿）
- 相邻色的**边界**能分开（土路和草地的交界不糊）
- 任何一块颜色都**没有亮到失去纹理**（红色衣服上还能看见褶皱）

数值上对应 `sat_mean` 0.26–0.56 且 `p99` 不顶到 255。见 `references/color-science.md`。

### 3. 顺序必须对：先立动态范围，再给中间调对比

反过来的写法会让模型直接给你暗部压死 + 高光爆掉的 HDR。这是「虚假感」最常见的来源。

同一个道理在调色脚本里也是一条硬顺序：**色阶归位必须在影调曲线之前**。
一张色阶只占 117–162 的图，不加归位就在 45 级里加对比，灰还是灰。

### 4. 肤色必须从「大地色」里摘出来

土墙、岩石、皮肤在色相上几乎重叠（大地 14°–46°，肤色 12°–42°）。
所以「先给大地加饱和，再给皮肤减一点」这种做法一定会让脸跟着走，出来是橘色的脸。

脚本用的是**排除法**：先把肤色区域从分色掩膜里减掉，再让它按比例回到原始饱和度
（`skin=0.88` 表示保留 88%）。提示词里对应的是「肤色必须与大地色分离」那一段。

### 5. 8K 是交付尺寸，不是原生分辨率

Hy Image3.5 preview 原生 2K，显式请求到 4096 就是上限。8K（7680×4320）是后期重采样出来的，
细节是插值出来的，不是拍出来的。**不要对外承诺「真 8K」。**

同一条也适用于「高分辨率」这个要求：真正的分辨率来自镜头的解析力和光线的质感，
不是来自放大算法。

## 流水线

### Step 0 — 收料

按顺序问清楚，缺一项都会返工：

1. **题材**：`mode` = `nature` 风光 / `street` 扫街 / `travel` 旅行。三者参数不同，
   扫街的肤色保护最强、对比最硬；风光的饱和给得最足。
2. **地点**：具体到能对应植被带与光照角度的程度。「川西高原」不够，「塔公草原东缘的牧道」够。
3. **时段与天气**：决定光线的方向与质感。正午顶光会被质量门提示（`W305`）。
4. **画面里有没有人**：有人的话必须给肤色与人物状态，否则出来是游客照。
5. **画幅**：3:2 最像杂志跨页，4:5 适合竖构图人像，16:9 适合宽幅风光。默认 3:2。
6. **要不要调色**：已有照片可以直接走 `grade.py`，不一定要重新出图。

出图消耗积分（一张约 5–10 积分），开跑前说明。

### Step 1 — 装配提示词

```bash
python scripts/build_ng_prompt.py --spec specs/natgeo-ganzi.json --outdir out/demo
```

产出 `prompt.txt`（约 3500 字）+ `meta.json`。

质量门会检查：场景为空、占位符没替换、画幅与尺寸比例不一致、尺寸超 4096、
高危词（HDR / 暗角 / 橙青 / 霓虹 / 磨皮 …）、人数过多、缺三层结构、正午硬光、
颗粒过强、有主要人物但没写肤色条款、`mode=nature` 却写了主要人物。

### Step 2 — 出图

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `prompt` | `prompt.txt` 全文 | |
| `image1` | 可选，参考照片 | 只用于参考构图/色彩倾向，不做锁脸 |
| `input_fidelity` | `high` | 有参考图时才需要 |
| `revise` | **`false`** | 开着会把分色锚点、禁止项改写掉 |
| `footnote` | **不传** | 这个字段就是水印文本，不传即无水印 |
| `size` | 按画幅：3:2 → `2048x1365`；4:5 → `1638x2048`；16:9 → `2048x1152` | 单边 ≤ 4096 |
| `quality` | `high` | |
| `output_dir` | `out/demo/raw` | |

### Step 3 — 体检

```bash
# 只体检，不出图
python scripts/grade.py out/demo/raw/x.png --check

# 体检 + 调色 + 8K 交付
python scripts/grade.py out/demo/raw/x.png --out out/demo/x_8k.jpg --preset travel --target 8k --report out/demo/report.json

# 只想看看「调色到底动了什么」，用 neutral 预设做 A/B
python scripts/grade.py out/demo/raw/x.png --out out/demo/x_neutral.jpg --preset neutral
```

体检输出六轴：

| 行 | 看什么 | 合理区间 |
| --- | --- | --- |
| `contrast_p90_p10` | 中段动态范围 | 95–205 |
| `p5` / `p99` | 黑位 / 白位 | 3–32 / 230–254 |
| `shadow_open` / `shadow_luma` | 暗部结构 / 暗部亮度 | ≥5 / 4–92 |
| `sat_mean` | 全局饱和度 | 0.26–0.56 |
| `hue_sky` / `hue_green` / `hue_earth` | 色相锚点 | 见 `references/color-science.md` |
| `cast_rg` / `cast_bg` | 色偏（**只作参考，不给判定**） | — |

`shadow_crushed` 和 `highlight_blown` 两行是组合判据，只有它们会让脚本返回 1：
- 压死：`p5 ≤ 1` 且 `crushed_ratio > 2%`
- 曝死：`p99 ≥ 254` 且 `clipped_ratio > 0.4%`

单独看比例会冤枉夜景，单独看分位数会冤枉高调片，所以用组合。

### Step 4 — 验收

**影调**
- [ ] 暗部里看得出东西：山体阴影有地形、牛腹下面有结构、墙角有砖缝
- [ ] 高光里看得出东西：云有层次、雪有蓝紫过渡、水面反光是碎的不是一片白
- [ ] 明暗交界紧凑，但过渡不硬（有 3–5 级的过渡带，不是一刀切）
- [ ] 没有 HDR 的假亮：每个区域的亮度都能用一个光源解释

**色彩**
- [ ] 蓝天是深青蓝，不是亮蓝也不是紫蓝
- [ ] 绿色不发荧光，深绿不发黑
- [ ] 大地色醇厚，不偏橙也不偏灰
- [ ] 肤色自然：受光面暖、暗面同色加深、高光是反光不是白斑
- [ ] 全画面找不到第二种「说不清来自哪里」的主色调（滤镜感）
- [ ] 没有彩色镶边（高光边缘的紫边/绿边）

**质感**
- [ ] 布、石、木、水、皮的高光形状各不相同
- [ ] 没有塑料感（过于均匀的反射、没有微小瑕疵的表面）
- [ ] 颗粒均匀细密，暗部没有糊成噪点块
- [ ] 没有锐化白边（沿高对比边缘的一圈亮线）

**纪实性**
- [ ] 光线只有一个来源方向，投影都服它
- [ ] 每样东西都能回答「它为什么在这里」
- [ ] 人是在生活里，不是在拍照
- [ ] 没有边框、字标、水印、杂志版式

任一条不过：**影调与色彩问题优先重出**，不要靠后期救。
后期只能把「对的画面」调得更对，不能把「错的光」调对。
