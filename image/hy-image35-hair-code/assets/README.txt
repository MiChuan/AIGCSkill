把正脸参考照放在这个目录，命名 `face.jpg`（或改 `specs/*.json` 里的 `ref.path` 指到你自己的路径）。

要求：

- **正脸**，头部不仰不俯：仰头会让下颌宽虚高，低头会让额头虚高，代码会判错
- **刘海拨开**，露出真实发际线；不戴帽子、不戴粗框眼镜（镜框会改变颧宽的读数）
- **光从左前方来**，不要顶光或底光：投影会盖住下颌角
- 长边 ≥ 1024px；不要重度美颜——滤镜会把皮肤纹理和脸型边缘一起锁进生成结果
- 背景越干净越好；两侧鬓角要能看见（量下颌宽需要）

要判断层次的话，再放一张 `face-side.jpg`（头部向左转 45 度），在 spec 里另出一张。
