# 只换头发：提示词公式与失败模式

一句话：**这是所有二创里最窄的一刀——改动面积最小、贴着最容易被认出的部位、而且模型天生想把整颗头重画一遍。**

大场景换背景，改错了还能看；只换头发，改错一点点就是「换脸」。

---

## 为什么必须锁发际线（这条最反直觉）

大多数人以为保脸靠「写清五官」。不够。

脸的辨识度有一半来自**比例**，而发际线是比例的起点：三庭的划分从发际线开始，额头的宽窄由它决定，脸的「长度」也是从它量下来的。发际线下压 1cm，同一个人的上庭就短了一截、脸短了一截，看起来像胖了五斤；上移 1cm，上庭变长、脸变长、显老。

所以：

> **头发可以换，发际线不能动。新发型是从这条既有的发际线上长出来的。**

这句话要单独成段、放在身份锁之后。它同时也是唯一一条「模型很容易违反、观众一眼能看出」的规则。

---

## 八段结构

| 段 | 在防什么 |
| --- | --- |
| 【任务】 | 模型默认任务是「生成一张人像」，要明确改成「改一张照片」 |
| 【身份锁定】 | 换脸。逐项写脸的比例、五官位置、细节特征、肤色 |
| 【发际线锁定】 | 比例漂移。见上 |
| 【目标发型】 | 款式理解偏差。六个数，见 `hair-structure.md` |
| 【发质呈现】 | 假发套。细软/硬直/自然卷的物理差异 |
| 【保持不变】 | 光、背景、构图、表情、衣物跟着一起变，三张方案就没法对比 |
| 【发丝质感】 | 头发糊成一片色块、边缘像刀切 |
| 【禁止项】 | 兜底。把上面所有「不要」集中成一行，模型的负面权重更集中 |

---

## 「保持不变」为什么比「改成什么」更关键

三张方案的价值在于**同一个人、同一束光、同一个构图下的差别只剩发型**。

一旦模型顺手把背景从灰墙换成灰蓝、把光从左上换成正面，你的对比就失效了——你不知道是自己更喜欢那个发型，还是更喜欢那张图的氛围。

所以 `keep` 里必须写全：光线（光位/光比/色温）、背景（同一面墙、同样的明暗）、构图（镜头距离、头部位置与大小）、表情、衣物。质量门 `E607` 会检查光线/背景/构图三项是否都写了，缺一项就报错。

---

## 多方案怎么出

**一次一张，同一张参考图，只换【目标发型】那一段。**

不要在一次生成里要「三个发型」——模型会给你三张脸，或者一个半中分半狼尾的东西。

推荐的三款出来后：

```bash
# 每款一个 spec，一个 outdir
python scripts/build_hair_prompt.py --spec specs/s1.json --outdir out/s1
python scripts/build_hair_prompt.py --spec specs/s2.json --outdir out/s2
python scripts/build_hair_prompt.py --spec specs/s3.json --outdir out/s3

# 出完图拼一张对比
python scripts/contact_sheet.py --ref assets/face.jpg \
    --img out/s1/raw/1.png out/s2/raw/1.png out/s3/raw/1.png \
    --labels "参考/现状" "1 自然中分" "2 轻层次中长" "3 三七分" \
    --crop head --out out/sheet.jpg
```

`--crop head` 很重要：三张图裁到同一个头肩比例，对比的才是发型；不裁的话，谁的脸大谁看起来就更「适合」某些款式。

**要判断层次，再加一张 45 度侧脸。**同一个 spec，只改构图说明（「头部向左转 45 度」），其它一字不动。正面看刘海和分缝，侧面看层次与后颈——两个角度都过，这个发型才成立。

## 出图参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `prompt` | `prompt.txt` 全文 | |
| `image1` | 参考照片 | 身份、光、背景、构图、衣物的唯一来源 |
| `input_fidelity` | `high` | 保脸的开关，这一项调低，前面写的全白写 |
| `revise` | `false` | 开着会把「发际线不动」「只改头发」改写掉 |
| `footnote` | 不传 | 这个字段本身就是水印文本 |
| `size` | `1536x2048`（3:4） | 竖构图，头肩留出空间；要更宽用 `1600x2000`（4:5） |
| `quality` | `high` | |
| `output_dir` | `out/<session>/raw` | |

## 失败模式

| 症状 | 原因 | 改法 |
| --- | --- | --- |
| 换了一个人 | 发际线被动过 / `input_fidelity` 不够 | 强化发际线段；`input_fidelity=high`；换一张更正脸的参考图 |
| 像戴了假发 | 发丝质感没写，或者发质写错 | 补【发丝质感】；核对 `references/hairtype.md` |
| 头发糊成一块 | 只写「发型」，没写发束 | 补「发束成组、发尾有空隙、边缘有飞散碎发」 |
| 背景变了 | `keep.background` 缺失或太笼统 | 写成「同一面墙、同样的明暗与颜色」 |
| 光线变了 | 同上 | 写明「光位、光比、色温」 |
| 表情变了 | 没写 `keep.expression` | 补一句「表情与参考图一致」 |
| 脸型变瘦/变立体 | spec 里混进了改形词 | 质量门 `W608` 会报；删掉那些词，只换头发不改骨相 |
| 模型给了正面证件照 | 参考图是侧脸，或构图段缺失 | 写明「保持参考图的机位与头部朝向」 |
| 头发体积往两侧走 | 体积参数只写了「蓬松」 | 改成「顶部加高 2cm，两侧收」这种带方向的 |
| 三张图无法比较 | 一次生成多个发型 / 光背景变了 / 没裁到同一比例 | 上面三条各自对症 |

## 和另外几个 skill 的分工

| | 改什么 | 不改什么 |
| --- | --- | --- |
| `hy-image35-cinematic` | 人进场景 | 人不改 |
| `hy-image35-lowkey-portrait` | 光与背景 | 人、头发不改 |
| `hy-image35-kr-school-id` | 服装、背景、光 | 五官不改 |
| **本 skill** | **只改头发** | **脸、发际线、光、背景、构图、衣服，一个都不改** |

本 skill 是这几个里改动面积最小的一个，所以它对「不变」的要求最严。别把它当造型大片来做——它的产出是**试发**，不是作品。
