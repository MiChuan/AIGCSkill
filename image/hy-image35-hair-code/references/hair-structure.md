# 发型结构语言：把「三七分」翻译成可执行的六个数

一句话：**款式名是给人看的，结构参数是给模型看的。前者只能唤起联想，后者才能画出同一个发型。**

「三七分」这三个字，在一百个人头上有一种样子：分缝偏左还是偏右、刘海到眉还是到颧、两侧盖耳还是推光、后颈收干净还是留狼尾。模型看到这三个字，只会给你「有个分缝」——其余全靠它自己发明，而它发明的每一次都不一样。

所以推荐可以给款式名，出图必须给六个数。

---

## 六个参数

| 参数 | 管什么 | 可写的值 |
| --- | --- | --- |
| `分缝` | 脸被切成几块 | 中分 / 3:7 / 4:6 / 自然侧分（无硬线）/ 侧分偏高 |
| `刘海` | 额头露多少 | 见下面的落点表 |
| `两侧` | 脸的宽度有没有被放大 | 耳上 / 耳中 / 耳下 / 盖耳 / 颌角上缘 / 颌下 / 过颌 2cm |
| `后颈` | 视觉终点停在哪 | 发际线上 2cm / 颈中 / 颈根 / 狼尾 |
| `层次` | 重量压在头顶还是发尾 | 低（重量在发尾）/ 中 / 高（顶部短、发尾长） |
| `体积` | 轮廓往上还是往两边 | 顶部压平 / +1–2cm / +2–3cm / 横向加宽 |

### 刘海落点表（必须落在解剖位置上）

| 落点 | 效果 | 适合 |
| --- | --- | --- |
| 眉上 1cm | 露额、干净 | 长脸、宽脸；三指/四指额头 |
| 眉 | 半遮，最稳 | 绝大多数组合 |
| 眉下–眼上 | 压额、显脸短 | 方脸；五指额头 |
| 眼尾 | 遮上庭下半 | 宽脸、五指额头 |
| 颧骨上缘 | 切断颧宽 | 颧骨最宽 |
| 颧弓 | **危险**：正好停在最宽处 | 几乎不适配 |
| 颌线 | 包住中下庭 | 宽脸、颧骨最宽 |

「颧弓」这一行是第一版最容易踩的坑：刘海长度正好停在最宽处，等于给颧骨画了一条下划线。

## 常见款式拆解

不是词典，是「这四个字到底是什么结构」的对照。写提示词时照抄右侧，别照抄左侧。

| 款式名 | 实际结构 |
| --- | --- |
| 开方 | 刘海中央开出一个 2–3cm 的方口露出额头，两侧薄片垂到眉上。**不是**「中间分开」 |
| 法式短发 | 碎刘海到眉上或眉，发尾参差、中间打薄，两侧斜扫；轮廓圆、不加高 |
| 短侧背 | 侧分，前额发片向斜后方梳起，额角保留碎发；顶部顺着后脑走，不吹高 |
| 侧背 | 同上，但发片更长，两侧也向后梳 |
| 碎盖 | 刘海到眉，发尾打散、不齐也不厚，露出额头的缝隙（厚了就成锅盖） |
| 空气感短发 | 高层次，发根立起、发尾之间有空隙；两侧去量，顶部留长 |
| 狼尾 | 高层次：顶部短、后颈留到颈根，发尾碎成几撮；两侧**不推光**（推了就成鲻鱼头） |
| 中分层次 | 中分，两片发片从分线垂到颌线，层次中长 |
| 卷鬓中长 | 两侧靠卷度盖住颧弓，鬓角留到颌下，层次中长 |
| 露颈长发 | 后颈到颈根、露出颈线，发尾长短不一 |

## 写法上的三条纪律

### 1. 长度只写解剖位置

写「稍长」「适中」「自然长度」，模型每次给你一个不同的长度，而且三张方案之间的差别会变成「长短不同」而不是「款式不同」——对比就白做了。质量门 `E605` 会直接拦这类词。

### 2. 「蓬松」「层次感」单独出现等于没写

- 「蓬松」→ 鼓起来的方向是随机的。要写**往哪蓬**：顶部压平 / 顶部 +2cm / 两侧加宽。
- 「层次感」→ 会给你一堆乱毛。要写**层次高低和重量位置**：高层次、重量在发尾。

### 3. 六个参数之间不能互相让步

它们是同一件事的六个面：分缝决定脸被切成几块，刘海决定额头露多少，两侧决定宽度有没有被放大，后颈决定视觉终点，层次决定重量落在哪，体积决定轮廓方向。

写不出某一条，通常不是这条不重要，而是这个款式本来就不成立——比如「两侧推光的狼尾」，那不是狼尾，是鲻鱼头。

## 失败模式

| 症状 | 真正的原因 | 改法 |
| --- | --- | --- |
| 发型对了，但人变了 | 发际线被改了 | 补 `keep.hairline`，并把「发际线不动」提到身份锁后面 |
| 头发像一顶帽子 | 只写了款式名，没写分缝与层次 | 六项补全 |
| 两侧炸开、头变大 | 两侧推太光（硬直发）或两侧加宽（宽脸） | 改成盖耳 + 发尾向内收 |
| 整头像被吹过 | 写了「蓬松」但没写方向 | 换成「顶部压平」「后脑饱满」这种带方向的词 |
| 发质不对：明明是细软，画成了浓密 | 没写发质呈现 | 补 `references/hairtype.md` 里的 `render` 段 |
| 三张方案看不出区别 | 一次生成了三款，或者只改了款式名没改结构 | 一次一张，每次只换 `style` 段 |
| 刘海糊在额头上 | 刘海长度写到「适中」，模型给了个压到眉下的长度 | 写死「眉上 1cm」或「到颧骨上缘」 |
