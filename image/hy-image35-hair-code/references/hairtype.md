# 发质：同一个款式，三种结果

一句话：**脸型决定剪什么，发质决定能不能成立。**

同一款「自然中分、轻层次中长」——细软发是贴着头皮的一片，硬直发是两侧支棱着的一片，自然卷是蓬成三角的一片。款式没错，错在没人问过头发答不答应。

原图把发质做成三条并列的列，这件事本身就是对的：**发质不是补充信息，是和脸型同级的一个维度。**

---

## 三种发质

### A 细软

**怎么认**

- 单根发丝细到在光下几乎透明，两指搓不出声音
- 干发时手指插进发根，头发不会自己立起来
- 洗完不吹，20 分钟内基本贴回头皮
- 发旋处容易分缝、露头皮

**剪裁逻辑**：敌人是长度和重量。越长，重量越往下拉，顶部越塌。要么短，要么用层次把重量拿走——没有第三条路。

**提示词里可以写**：发根立起、发束成组、发尾之间有空气感、发丝细、轻微光泽不油亮。

**不能写**：发量浓密、厚实、硬挺、大背头、羊毛卷。写进去模型会给你一个「发量旺盛的别人」。

**绝对不要**：大背头、厚重蘑菇头、长中分贴脸、齐刘海（会塌成一片）。

### B 硬直

**怎么认**

- 单根发丝能自己立住、有弹性，捏一下会弹回来
- 两侧不造型会向外翘
- 剪完发尾有刺手感，边缘生硬
- 烫了也容易回直，卷度维持不过一周

**剪裁逻辑**：靠长度压重量、靠打薄和点剪柔化轮廓。两侧推太光会像一堵墙，发尾齐剪会像一圈帽檐。

**可以写**：发丝有直线感、发尾齐整但带碎口、蓬松来自剪裁不是造型品、没有湿亮感。

**不能写**：柔软、服帖、空气感大波浪、蓬松卷曲。硬直发做不到「空气感」，写进去只会得到一块发胶。

**绝对不要**：两侧推到耳上、寸头、齐刘海一刀切、羊毛卷。

### C 自然卷

**怎么认**

- 湿发时有明显波纹，干后体积比湿发大一半以上
- 有飞散的短绒，发际线周围毛躁
- 剪短就炸，越剪越蓬
- 两侧和鬓角最容易先翘起来

**剪裁逻辑**：必须留长度让卷成形。短了会炸成一个三角，齐了会炸成一朵蘑菇。靠点剪、湿剪控制体积。

**可以写**：卷度不规则、卷径大小不一致、发尾有外翘和少量毛躁、发束分明但不整齐。

**不能写**：顺直、服帖、整齐的卷度、定型喷雾。写「整齐的卷度」，出来的是烫过的弹簧卷，不是自然卷。

**绝对不要**：齐刘海、一刀切短发、贴头皮的油头。

## 一张表：发质 × 结论

| | 细软 A | 硬直 B | 自然卷 C |
| --- | --- | --- | --- |
| 长度上限 | 颈中（再长就塌） | 不限 | 最少过颌（短了就炸） |
| 层次 | 中–高（把重量拿走） | 中–低（用重量压住） | 高（把体积打散） |
| 两侧 | 薄、贴 | 留长度，别推光 | 留长度，靠卷盖住 |
| 体积来源 | 剪裁 + 纹理 | 剪裁 + 长度 | 卷度本身 |
| 顶部 | 必须写「发根立起」 | 容易过高，注意别过 2cm | 天然高，反而要控制 |
| 最容易翻车 | 塌成一片 | 两侧炸成墙 | 蓬成三角 |

## 为什么发质比脸型更爱翻车

脸型判错，最坏结果是「款式不太适合你」——不好看，但还像个人。

发质判错，最坏结果是「头发不像头发」——一张贴着头的塑料片，或者一顶毛躁的头盔。观众一眼就看出来这是生成的，因为**发丝是有物理的**：细软的头发立不起来，硬直的头发贴不下去，自然卷不会长出整齐的边。

模型不知道这些。它只知道「头发」这个词对应一个大致形状，然后按「好看」去补。所以发质这一段必须写进去，而且必须写得跟脸型一样具体。

## 判断顺序

1. **湿发**看卷度（自然卷在湿发时波纹最明显）。
2. **干发不造型**看支撑（细软塌、硬直翘）。
3. **发根**看粗细（细软在光下透，硬直有实体感）。
4. 三种特征都像？按「最影响结果的那一条」定：塌 > 炸 > 卷。也就是：能塌就按细软，塌不了但翘就按硬直，卷得明显才按自然卷。

判不准就问用户一句「洗完头不吹，半小时后是趴着还是蓬着」——这一句比看照片准。
