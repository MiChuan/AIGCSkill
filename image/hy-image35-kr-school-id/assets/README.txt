把人物参考照片放在这个目录，命名 ref_male.jpg / ref_female.jpg（或改 spec 里的引用）。

要求（保脸精度直接由这几条决定）：
- 正面或轻微侧脸（偏转 < 15°），两只眼睛都能看清
- 平光或漫射光，脸上没有大面积高光、没有死黑阴影
- 不戴墨镜、不被头发遮住眉眼、不戴口罩
- 人脸区域至少 400x400 像素
- 表情自然，不要大笑（笑会改变眼型和法令纹，生成时也会延续）

如果这个人是固定戴眼镜的人设，**直接用戴眼镜的照片**——
参考图不戴、生成时要求戴，等于在眼睛前面压一层遮挡，保脸精度会明显下降。

多张照片时用 ref_01.jpg / ref_02.jpg 命名，一次最多 5 张；
第一张（image1）是身份主来源，其余只作为补充参考。

出于隐私与体积考虑，这个目录里的图片不会进版本库（见 ../.gitignore）。
