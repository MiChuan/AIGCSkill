# 示例：伦勃朗光 · 纯黑背景 · 横向拖影（3:2 / 8K）

## 原始需求

> 按上传照片二创，不改变本身长相和发色。低调电影感摄影（low-key cinematic photography），纯黑背景，人物位于画面右侧。
> 伦勃朗布光：仅一束强硬侧光照亮半张脸，另一半脸在深邃阴影中，光影对比强烈。
> 身后左侧加轻微横向动态拖影，范围不要太大，主体清晰锐利，拖影颜色必须与衣物颜色严格统一，营造高速移动的速度感和压迫感。
> 氛围硬朗冷酷帅气，高级电影海报质感。低饱和、低曝光、高质感，保留真实头发细节，20 岁感觉，脸部干净无胡须，背景完全纯黑无杂物。
> 3:2，8K，超写实原生摄影，sharp focus, cinematic, high detail, professional studio photography。

## 拆解（需求 → spec 字段）

| 需求片段 | 落到哪 | 处理 |
| --- | --- | --- |
| 不改长相 | `character.identity_locks` | 五项逐条写死 |
| 不改发色 | `character.hair_lock` | 加到"发根色 + 受光区只提亮不改色相" |
| 20 岁、无胡须 | `apparent_age` / `beard` | 显式写，否则模型默认加胡茬 |
| 伦勃朗 + 半脸阴影 + 强对比 | `lighting` | 45°/45° 方位 + 三角光斑 + 1:8 光比 |
| 纯黑背景无杂物 | `background` | #000000 + 无烟雾飞尘 + 不加背景光 |
| 人物在右侧 | `composition.subject_position` | 右侧三分之一线，左侧留负空间接拖影 |
| 轻微横向拖影、主体锐、色=衣物 | `trail` | ratio 0.4 + color_source 衣物 + 主体锐利条款 |
| 3:2 / 8K | `aspect` + `postcheck --target 8k` | 2048×1365 → 7680×5120 |
| 低饱和低曝光 | `grade` | 写死黑位、中间调、颗粒 |

**一处必须自己补的决定**：用户没说穿什么，但拖影色 = 衣物色，且背景纯黑 —— 纯黑衣物会让拖影彻底消失。
所以 spec 里定的是**深炭灰哑光外套**（仍是 low-key 暗调，但能在纯黑上读出轮廓）。这是有意为之，不是随意填的。


## 生成的提示词（可直接复制）

```
【任务】低调电影感人像摄影（low-key cinematic photography），超写实原生摄影，专业影棚布光，非插画、非3D渲染、非CG感。

【人物锁定】以参考照片中的人物为唯一身份来源：脸型骨相与颧骨-下颌线条、五官轮廓与比例、眼型、眼距与双眼皮形态、鼻梁高度与鼻头形状、唇形与唇厚必须与参考照片完全一致；不得换脸、不得改变脸型胖瘦、不得美颜磨皮、不得改年龄气质。

【发色锁定】严格沿用参考照片的发色：发根至发梢的明度与色相不变（黑发不得被提成棕灰，棕发不得被提成金），受光面仅提高亮度、不改色相饱和度；发型走向、分缝位置、发际线形状、鬓角长度与参考照片一致；碎发位置可随机，但发丝色泽统一。

【人物状态】年龄观感：20 岁左右；皮肤保留真实毛孔、细小绒毛与质感颗粒，无磨皮、无塑料感，暗部皮肤仍有细节；脸部干净无胡须，唇周与下颌无胡茬；表情：神情克制冷静，视线离开镜头看向画面左侧，嘴角放松不上扬，下颌线条收紧。

【服装】深炭灰色哑光修身外套，面料为细腻的羊毛混纺，缝线与拉链有极弱的冷调反光；内搭同色系低领，整体不做任何亮色点缀（深灰而非纯黑，保证拖影在纯黑背景上仍可辨识）。拖影颜色以此为准。

【光线】伦勃朗布光（Rembrandt lighting）：单一强硬侧光作为唯一主光，位置在人物前侧约 45°、高于眼位约 45°；主光照亮靠近镜头的一侧脸，在远侧脸颊形成标志性的三角形光斑（由鼻影与脸颊阴影交出一小块受光三角，这是伦勃朗光的识别特征）；另一半脸落入深邃阴影；明暗光比约 1:8；不使用补光、不使用蝴蝶光/环形光/大柔光、不加轮廓灯与背景灯；高光不溢出，暗部保留结构与皮肤质感，可压到接近死黑但不得糊成一片灰雾。

【背景】背景为完全纯黑的摄影棚背景（#000000），无杂物、无渐变、无光斑、无烟雾、无飞尘；人物与背景之间没有漏光边缘，轮廓靠光比自然收暗；背景与人物的分离完全依靠光比，不加任何背景光、不加轮廓光。

【构图】3:2 画幅；人物位于画面右侧三分之一线上，身体右侧略出画；胸部以上的半身像，头顶留少量空间，手部不入画；画面左侧保留大块纯黑负空间用于承接拖影，留白比例约三分之一。

【动态拖影】在人物身后左侧添加轻微的横向动态拖影（horizontal motion blur trail）：拖影自人物轮廓水平向左延展，长度约为人物宽度的 40%，随距离逐渐消散、不留硬边；拖影颜色与人物衣物的颜色严格统一（同一色相、同一明度，取衣物受光面的颜色），不得出现彩虹色散、不得发光、不得出现第二种颜色；人物本体保持清晰锐利，拖影只存在于身后轮廓之外，不得覆盖脸部、头发与身体。

【质感与调色】低饱和、低曝光、高质感：整体冷调中性，肤色去暖留灰、不橙不红；黑位压实到接近死黑但保留轮廓过渡，中间调收紧、对比强烈；细腻均匀的胶片颗粒（不结块、不糊细节）；不加深色暗角以外的任何滤镜感，呈现高级电影海报的克制影调。

【画质】8K 级超写实原生摄影质感：sharp focus, cinematic, high detail, professional studio photography；真实头发丝与碎发（受光处可见单根发丝的高光）、睫毛、毛孔与皮肤纹理、布料纤维与缝线清晰可辨；焦点落在近镜头那只眼睛上，景深自然过渡；无涂抹感、无过度锐化 halo、无 AI 塑料感。

【禁止】水印、logo、签名、署名、文字、字幕、画框、反光板痕迹、硬阴影边缘发蓝、皮肤油亮、眼神光过亮、胡须、发色改变、脸型改变、正面平光、蝴蝶光、环形光、大柔光、背景灰雾、背景渐变、光斑、杂物、拖影覆盖人物或脸部、彩色拖影、发光拖影、多种颜色并存、磨皮塑料感、过度 HDR、卡通化、CG 渲染感、AI 涂抹。
```

## 验收重点（这个场景特有的坑）

1. **有没有三角光斑**——没有就是分割光，不是伦勃朗。这是第一眼要看的。
2. **暗侧是不是被轮廓灯勾了边**——有一条亮边就废，"压迫感"会变成"证件照"。
3. **拖影是不是实心色带**——应该是从轮廓向左逐渐消散的拉丝，不是一块灰色方块。
4. **拖影颜色有没有跑偏**——放大看有没有青色/紫色色散。
5. **脸有没有被拉丝**——主体必须完全锐利，模糊只能出现在身后轮廓外。
6. **发色有没有被提亮**——对比参考图看发根，伦勃朗光容易把整头头发"提亮一档"。
7. **背景是不是真纯黑**——下载后用取色器点几个角，应该是 #000000，不是 #0A0A0A。

## 变体

| 想要 | 改 spec |
| --- | --- |
| 竖版海报 | `aspect` → `"2:3"` 或 `"4:5"`，人物位置改"画面下三分之一横线" |
| 换分割光（更硬的对比） | `lighting.scheme` → `"split"`（质量门会提示三角光斑不再出现） |
| 拖影更长更有速度感 | `trail.length_ratio` → `0.5`（别超过 0.6） |
| 换侧（人物在左、拖影向右） | `composition.subject_position` + `trail.side` 同步改 |
| 加环境元素（雨、尘） | 别加——和"背景完全纯黑无杂物"冲突，只能加在光里（丁达尔光束） |
