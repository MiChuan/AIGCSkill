# 低调电影感人像二创

一句话：**同一个人，换光、换背景、加一道速度线，做成电影海报。**

和 `hy-image35-cinematic` 是姊妹 skill：那个管"人物进场景"，这个管"人物本人被重新打光"。场景类需求不要往这里塞。

## 四条不可让的约束

用户说的"不改变本身长相和发色"，落到可执行的只有四件事，缺一件就废：

1. **身份锁**：脸型骨相、五官比例、眼型、鼻、唇，逐项写死"与参考图一致"。
2. **发色锁**：发色 + 发根色 + 受光区色泽 + 发型走向 + 发际线。只写"发色不变"不够——伦勃朗光会在头发上打出一条高光带，模型很容易顺手把整头头发提亮/改浅。
3. **不对称光**：伦勃朗光的识别特征是**远侧脸颊的三角形光斑** + 明暗交界线清晰 + 一半脸进阴影。不写三角光斑，模型只会给你"一侧亮一侧暗"的普通侧光。
4. **拖影三条铁律**：范围小、主体锐、颜色等于衣物色。少一条就变成廉价特效。

## 流水线

### Step 0 — 收料

1. **参考照片路径**（越正、越清晰、发色越准越好）
2. **衣物**：拖影颜色要跟衣物严格统一，所以衣物必须写明；**纯黑衣物 + 纯黑背景 = 拖影不可见**，这是最常见的翻车点（见 `references/lighting-and-trail.md`）
3. **画幅**：默认 3:2；要竖版海报就 2:3 或 4:5
4. **年龄/胡须**：用户写了就照抄（本例：20 岁左右，脸部干净无胡须）

出图消耗积分（一张约 5–10 积分），开跑前说明一句。

### Step 1 — 装配提示词

```bash
python scripts/build_portrait_prompt.py --spec specs/lowkey-rembrandt.json --outdir out/lowkey
```

产出 `prompt.txt` + `meta.json`。质量门会检查：发色锁是否缺失、光比是否写了、拖影长度是否过量、拖影色源是否等于衣物、背景是否真纯黑、黑衣 + 黑底的可见性冲突。

### Step 2 — 出图

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `prompt` | `prompt.txt` 全文 | |
| `image1` | 参考照片 | 身份与发色的唯一来源 |
| `input_fidelity` | `high` | 保脸的开关 |
| `revise` | `false` | 开着会把"发色不变""一半脸进阴影"改写掉 |
| `footnote` | 不传 | 不请求水印 |
| `size` | `2048x1365`（3:2）；报错降 `1536x1024` | |
| `quality` | `high` | |
| `output_dir` | `out/lowkey/raw` | |

### Step 3 — 体检 + 收尾

```bash
python scripts/postcheck.py out/lowkey/raw/x.png --out out/lowkey/lowkey_8k.jpg --target 8k
```

做三件事：

1. **背景纯黑校验**：采样画面左/上/下边带（人物在右，右边带会被主体干扰，不采），报 `bg_mean`、`bg_p99`。`p99 > 40` 或 `mean > 14` 判为背景不纯（有灰雾、杂物、漏光），要重出或手修。
2. **右下角水印**：检测 + 镜像补片（纯黑背景上水印对比度高，检测很稳）。
3. **8K**：按画幅等比放到长边 7680（3:2 → 7680×5120）+ 轻锐化。

### Step 4 — 验收

**人**
- [ ] 长相与参考图一致：脸型、眼型、鼻、唇；没有变年轻/变油腻/变网红脸
- [ ] 发色、发根色、发型走向一致；头发受光有高光但颜色没被改浅
- [ ] 20 岁感、脸部干净无胡须、皮肤有纹理（没有磨皮塑料感）

**光**
- [ ] 只有一侧脸被照亮，远侧脸颊能看到**三角形光斑**
- [ ] 另一半脸在阴影里，但仍能看清轮廓（死黑 = 过曝控制失败，重出）
- [ ] 明暗交界线清晰，不是柔光渐变
- [ ] 没有补光、没有背景光、没有轮廓灯（都会破坏 low-key）

**背景与拖影**
- [ ] 背景纯黑，无杂物、无灰雾、无渐变、无飞尘
- [ ] 拖影只出现在人物**身后左侧**，长度不超过人物宽度一半
- [ ] 拖影颜色 = 衣物颜色，没有彩虹色、没有发光边
- [ ] 人物本体（脸、发、衣）**清晰锐利**，拖影没有糊到人身上

**成品**
- [ ] 3:2，长边 7680，100% 查看时头发丝、睫毛、布料纤维还在
- [ ] 无水印、无文字、无 logo

任一条不过就重出，不要靠"后期能修"糊过去——low-key 的暗部几乎没有信息量，后期救不回来。
