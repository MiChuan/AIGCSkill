# postcheck.py：背景校验 / 水印清除 / 8K

跑 `--out` 一次拿到报告 + 成图。报告的三个区块对应三件事。

## 一、背景纯黑校验（`background`）

采样**该纯黑的三个边带**（人物在右、拖影在中部，右侧与中部不采）：

| 边带 | 区域 |
| --- | --- |
| left | x 0–6%，全高 |
| top | y 0–5%，x 0–50% |
| bottom_left | y 96–100%，x 0–30% |

每带算 `mean` / `p99` / `max` / `dark_ratio`，取最差值判等级：

| 指标 | 合格线 | 超了说明 |
| --- | --- | --- |
| `bg_mean` | ≤ 6 | 灰雾、环境光漏入、背景没压死 |
| `bg_p99` | ≤ 30 | 飞尘、光斑、杂物、轮廓漏光 |
| `black_ratio` | ≥ 0.90 | 背景被雾化（整片 #101010 这种） |

`verdict: impure` 时加 `--strict` 会返回退出码 2，方便批处理拦掉废图。

**为什么要量化**：暗图在普通显示器上，#000 和 #0A0A0A 肉眼分不出来，压进 JPEG 后再放大就露馅（出现色块和噪点）。取色器点一下比眼睛可靠。

## 二、水印清除（`watermark`）

### 检测

右下角取 25%×14% 窗口，切成 12×5 块，算每块边缘能量：

- 阈值 = max(中位数×2.2, 8)，中位数做基线（不被少量高亮块拉高）
- 打分 = 热块数/9 + min(0.5, 近白像素占比×60)

第一项解决"贴角小 logo 占面积太小被漏掉"，第二项解决"低照度图里连成一片的亮区被误判"。
两项都低（< 0.30）就判无水印，不补片——**宁可漏，不可错**，错补会在干净画面上糊一块。

### 修复（暗调专用）

先判断场景明暗：外框 8px 环的中位色 < 10 → 暗调场景，走专用路径：

1. 取区域内 **≥ 背景亮度 + 20** 的像素做掩膜（覆盖水印本体 + 抗锯齿边缘），膨胀 7px
2. **沿行、沿列各做一次线性插值**，取平均
3. 找插值锚点时跳过仍比背景亮的像素（水印光晕），否则会拿光晕当端点，插出一条横贯画面的亮带
4. 用羽化后的掩膜贴回

效果：只修水印那几个字，周围像素一个都不动——所以不会出现"补了一个比周围更黑的方框"或"镜像进来一块灰"。

掩膜没抓住（淡水印）时退回兜底：取四条边界条带里**最暗**的一条，整块铺平。

循环补片：补完重测一次，若还有残留（半个字）再补一次，最多 3 轮。

**局限**：水印正好压在主体边缘（肩线、发梢）时，插值会把那条边缘抹平一小段。这类图建议重出，或 `--watermark off` 后手修。

### 非暗调场景

走镜像补片（取左侧等宽区域镜像 + 三通道均值对齐 + 羽化），和 `hy-image35-cinematic` 里的是同一套。

## 三、8K

| 画幅 | 8K 输出 |
| --- | --- |
| 3:2 | 7680×5120 |
| 2:3 | 5120×7680 |
| 4:5 | 6144×7680 |
| 16:9 | 7680×4320 |
| 1:1 | 7680×7680 |

分级 2× Lanczos 放大（避免一次大倍率糊成团）→ 终尺寸 → `UnsharpMask`（radius 1.2–3.6，percent 85，threshold 3）。
源图比例在 0.8% 内贴近常见画幅时，输出尺寸会对齐到标准比例（避免出现 7680×5119 这种）。

**再强调一次**：放大不增加信息量。8K 是交付尺寸，不是"真 8K 细节"。要印刷级细节得接超分模型。
