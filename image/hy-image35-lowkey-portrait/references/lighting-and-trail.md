# 伦勃朗光与动态拖影：怎么写成可执行条件

## 一、伦勃朗光不是"一半亮一半暗"

"一半亮一半暗"是 split lighting（分割光）。伦勃朗光的识别特征是**远侧脸颊上的三角形光斑**：
鼻影与脸颊阴影在暗侧脸颊上围出一小块受光的三角，尖角朝向鼻翼，底边贴着颧骨。

所以提示词必须同时写四件事，缺一个模型就退化成普通侧光：

| 条件 | 写法 |
| --- | --- |
| 主光方位 | 前侧约 45°、高于眼位约 45°（这是产生三角光斑的几何条件） |
| 光斑位置 | 远侧脸颊、由鼻影与脸颊阴影围出的受光三角 |
| 光比 | 1:8 左右（1:4 太软像环境光，1:16 暗部会死） |
| 排除项 | 不用补光、不用蝴蝶光/环形光/大柔光、不加轮廓灯与背景灯 |

**轮廓灯是 low-key 的隐形杀手**：它会沿着暗侧勾一条亮边，瞬间把"压迫感"变成"棚拍证件照"。所以【禁止】里要单独点名。

## 二、暗部要有细节，不是纯黑一块

low-key 的暗部是**压而不死**：能看到眼窝、颧骨转折、耳廓轮廓，只是层级很低（L 值 8–30）。

写法上给两端约束：

- 上端：「高光不溢出」（避免额头、鼻梁爆成白块）
- 下端：「暗部保留结构与皮肤质感，可压到接近死黑但不得糊成一片灰雾」

只写"低曝光"会得到一张要么灰、要么死黑的图，因为模型不知道你要的是哪种暗。

## 三、动态拖影的三条铁律

用户原话是三条，正好对应三个最容易崩的地方：

### 1. 范围小

`length_ratio` 建议 0.3–0.5（拖影长度 / 人物宽度）。

- 超过 0.6：拖影抢戏，人物变成"特效展示品"
- 低于 0.15：看不见，等于没加

提示词里要写"随距离逐渐消散、不留硬边"，否则模型会给你一条**实心色带**，像贴纸。

### 2. 主体锐

必须在同一句里说清"拖影只存在于身后轮廓之外，不得覆盖脸部、头发与身体"。

模型对"运动模糊"的默认理解是**整幅画面都糊**。不写这句，你会得到一张人脸被拉丝的废片。

### 3. 颜色 = 衣物色

这是三条里最容易被忽略、也最影响"高级感"的：

- 拖影一旦变成彩色光带（橙/蓝/品红），立刻掉到"短视频特效"档位。
- 写"同一色相、同一明度，取衣物受光面的颜色"，比写"和衣服一个颜色"有效得多。
- 再加"不得出现彩虹色散、不得发光、不得出现第二种颜色"三条兜底。

## 四、黑衣 + 黑底 = 拖影消失（这道题的隐藏坑）

需求里"拖影颜色必须与衣物严格统一"和"背景完全纯黑"会打架：**如果人物穿纯黑，拖影也是纯黑，那它在纯黑背景上根本不存在。**

三种解法，按推荐度：

1. **衣物改成深炭灰 / 深藏青**（仍是 low-key 的暗调，但在纯黑上能读出轮廓和拖影）——`specs/lowkey-rembrandt.json` 用的是这个
2. **拖影取衣物受光面的高光色**（比衣物本体亮 1–2 档，同一色相）
3. 给衣物一个极弱的冷调反光材质（拉链、缝线、羊毛表面的方向性反光）

`build_portrait_prompt.py` 的质量门会在检测到"衣物描述含黑 + 背景纯黑"时告警（W104），别忽略它。

## 五、失败模式 → 改哪里

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 一半亮一半暗，没有三角光斑 | 只写了"侧光" | 【光线】补三角光斑描述与 45°/45° 方位 |
| 暗侧发灰没层次 | 光比太低或加了补光 | 光比拉到 1:8，【禁止】点名补光 |
| 暗侧死黑成剪影 | 光比过高 / 曝光过低 | 光比降到 1:8，加"暗部保留结构" |
| 脸上有轮廓光 | 模型默认补了 rim light | 【禁止】点名轮廓灯、背景灯 |
| 人物整张脸被拉丝 | 没写"主体保持锐利" | 【动态拖影】补"只存在于身后轮廓之外" |
| 拖影是实心色块 | 没写"逐渐消散" | 补"随距离衰减、边缘不留硬边" |
| 拖影出现青色/橙色 | 模型把"速度感"理解成霓虹 | 【禁止】加"彩虹色散、发光、第二种颜色" |
| 背景有灰雾 / 飞尘 | 模型默认给"电影氛围感" | 【背景】写死 #000000 + 无烟雾无飞尘 |
| 发色被提亮/改浅 | 没锁发根色与受光区 | 【发色锁定】写"受光面只提亮度不改色相" |
| 变网红脸 / 变年轻 | "帅气""少年感"类词生效 | 删掉"精致""嫩""仙"，补"不改年龄气质" |

## 六、验收的量化标准

`postcheck.py` 会把背景纯度量化，别靠肉眼：

| 指标 | 合格线 | 含义 |
| --- | --- | --- |
| `bg_mean` | ≤ 6 | 左/上/左下三条边带的平均亮度；纯黑应为 0–3 |
| `bg_p99` | ≤ 30 | 99 分位亮度，超了就是有飞尘、光斑或漏光 |
| `black_ratio` | ≥ 0.90 | 接近全黑（L<9）像素占比，低了说明背景被雾化 |

这三条都过，才叫"背景完全纯黑，无杂物"。
