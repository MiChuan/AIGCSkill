# 为什么是这些数

这份文档只回答一个问题：`SKILL.md` 里那些比例、阈值、区间是怎么来的，
以及什么时候可以不听它们。

## 纸色：#F4EFE4

米白（ivory / off-white）在屏幕上的常见取值是 `#F2EDE3` 到 `#F7F2E7`。
`#F4EFE4` 落在中间，三个量都对得上：

| 量 | 值 | 意义 |
| --- | --- | --- |
| luma | 0.938 | 比纯白（1.0）暗 6%，眼睛能感到「纸」 |
| R−B | +16 | 偏暖；中性白是 0，冷白是负 |
| HSV 饱和 | 0.066 | 极低，但非 0——这是「米」的来源 |

三个量缺一个就变味：

- luma 到 0.99 以上 → 死白，变成 PPT 背景，插画的色块会显得脏
- R−B 到 0 附近 → 中性白，冷感，学术但不温润
- 饱和到 0.15 以上 → 米黄，变成仿古纸，和「克制」冲突

所以 `printcheck.py` 用这三个量联合判定，而不是只比 hex。**不要用纯白当纸**，
这是本风格最容易被忽略、又最容易被一眼看穿的地方。

## 留白：52% 是怎么来的

这类版面（艺术图录扉页、展览说明页、诗集内页）的经验区间是：

- 纯纸白 **50%–65%** 是「从容」
- 40%–50% 是「紧凑」，还能看，但版面的呼吸变短
- 低于 40% 就成了一张满幅插画——它已经不需要版面了，只需要画框
- 高于 76% 会失衡：插画小到像一个 logo，观众会以为主体还没画完

52% 是「插画块占 68% 宽 × 50% 高，扣掉面与面之间的纸缝」的结果，不是拍出来的数字。
实际出图常在 55%–65%，都算合格。所以判定区间给的是 40%–76%，不是 52%±2%。

**连续整块**这一条比数值更重要。同样 55% 的留白，如果被切成十几条白缝，
观感是「满」的；如果是一整块，观感是「空」。这就是为什么提示词里要写
「留白是连续的整块，不是被色块切碎的白缝」。

## 重心 22%–56%

非纸像素的质心高度。这类版面必然是上重下轻：

- 插画块 10%–60%，本身质心约在 38%–42%
- 下方两行字只占不到 3% 的面积，几乎不拉动质心

所以正常值就是 35%–45%。给到 22%–56% 是为了容忍：
上方留白多一点（质心偏低）或者插画画到了 12%（质心偏高）。

质心掉到 60% 以下（数值更大）意味着画面上多了一块不该有的东西——通常是模型
自己加了一条底边、一块色带，或者把水面画满了。这时候看图就能看出来。

## 两种「柔」

这是本 skill 最核心的一条区分，单独说清楚。

**平面的柔**：印刷品在纸上的油墨边缘不是数学直线，有 0.5–1 像素的毛边和极轻微
的扩散。这是「印」出来的痕迹，方向是**沿着边缘**的。

**墨的柔**：笔蘸墨落在纸上，水带着墨往外渗，形成一个从中心到边缘的浓度梯度。
方向是**垂直于边缘向内**的，宽度 2–4 毫米，而且**每一处都不一样**（水分不均匀）。

模型分不清这两者。它只有两个档位：全锐（矢量硬边，没有纸感）和全糊（高斯模糊，
色块边界消失）。

所以提示词里必须把它们分开写，并且给出相反的方向词：

| | 边缘形态 | 有效描述 |
| --- | --- | --- |
| 色块 | 利落的线，交界无过渡灰带 | 「交界是一条干净的线」「面与面叠压，不拼接」 |
| 淡墨 | 中心实、边缘虚、有毛边水痕 | 「墨的边界是靠水分渗出来的」「虚的宽度 2–4 毫米」 |

`printcheck.py` 的 `edge_peak` 抓的就是第一种：Sobel 幅值 99.5 分位。
干净版面在 400–500，整体高斯模糊（半径 3.2 / 819px）掉到 150 左右。
阈值 220 是从这两个实测值中间取的，留了余量给 AI 生成的抗锯齿柔化。

## 解构粒度：4–9 个面

这个区间不是美学偏好，是**读数上限**。

一张图如果没有文字标注，人一眼能记住的独立形状大约 4–7 个；超过 9 个，
眼睛开始把它们归组（格式塔的相似性/邻近性），这时候「每一个面都能被指名」
就不成立了——而「能被指名的面」正是这套风格的语法。

低于 4 个面则相反：它退化成「一个大色块 + 一个点缀」，读起来像 logo 或图标，
不像一处景物。这时候观者不会去找「原图在哪」，重构的意义就没了。

所以质量门在 4 和 9 上卡：`W103` / `W104`。

**面的排序也重要**。提示词里按视觉权重从大到小写，模型会照着这个顺序分配面积。
如果顺序乱了，最后会得到「三个一样大的块」——平均分配，没有主次。

## 文字：为什么必须有两条路线

图像模型对拉丁字母的处理方式是「按视觉模式画字形」，不是「取字形、按字距排」。
后果是可预测的：

| 现象 | 机制 |
| --- | --- |
| 长句漏字 | 注意力在整块文字上，不是逐字 |
| 字距不匀 | 没有 advance width 的概念 |
| 多出一行 | 模型把描述句当成「一段文本」自动折行 |
| 汉字必错 | 汉字的结构复杂度远超字母，画不出来就造字 |

所以本 skill 的策略是：

1. **默认路线**：标题 2–4 词、描述 ≤ 14 词，一次出图，出完**逐字核对**。
2. **保底路线**：`settype.py`。出图时不要文字（或让模型随便排），后期把文字带
   用纸色刷掉，逐字排上去。

路线 2 的字是 100% 正确的，字号比、字距、居中都是算出来的。它比路线 1 更像
「设计稿」，但少了一点模型排版时那种轻微的呼吸感（字距会有一点点不均）。
这个取舍看用途：要交付文件走路线 2，要一张图走路线 1。

中文没有路线 1。

## 六轴指标的定义

`printcheck.py` 的所有量都在 **760 像素宽** 的缩略图上算，为的是够快且不受原图尺寸影响。

| 量 | 定义 | 备注 |
| --- | --- | --- |
| 纸色 | 画布边缘带（3.5% 宽）像素按亮度排序，取 40%–80% 分位的中位色 | 不用四角：插画可能贴边；不用最亮 4%：会被噪点抬高 |
| 留白率 | 与纸色的曼哈顿距离 ≤ 54 的像素占比 | 阈值宽，是为了容忍淡墨与极浅的色层 |
| 重心 cy | 文字带以上所有「非纸像素」的 y 加权平均 | 只看插画，不看文字 |
| 文字行数 | 文字带的水平投影，连续 3 行空白算断行 | 断行间隙 3 行，能容忍字母的升部/降部 |
| 字高比 | 最高的行段 / 第二高的行段 | 用像素高度，不用字号（拿不到） |
| 间距 | 第一行文字顶部 − 插画最低墨行 | 负数说明文字压在色块上 |
| 纸面噪声 | 24×24 网格中「均值接近纸色」的格子，其亮度标准差的中位数 | 网格法不依赖主体位置 |
| 边缘陡度 | Sobel 幅值和（0–1020）的 99.5 分位 | 不用 PIL FIND_EDGES：它被截到 255，糊了也分不出来 |

### 已知误判

- **文字贴到插画上但颜色相同**：如果标题正好压在深色块上、且字色接近色块，
  墨像素连成一片，行数会被数成 1。这种情况肉眼看得出，别只看报告。
- **淡墨大面积铺开**：淡墨与纸的距离可能刚过阈值，留白率会被低估几个百分点。
  读数偏保守是好事，不用修。
- **极小号的描述行**：小于 6% 画幅高的行段会被当作碎片丢掉（`min_h`），
  这时会报「只有 1 行」。这通常意味着字确实太小了，报告是对的。
- **水印**：右下角有水印时，会被算进「墨」并拉低留白率。Hy Image3.5 不传
  `footnote` 就没有水印；如果有，先用别的方式裁掉再体检。

## 复盘：三种最常见的翻车

### A. 出来像「一张彩色矢量插画」，没有纸感

原因：色块的边太硬 + 纸白太纯 + 没有淡墨层。

改法（按有效性排序）：
1. 在 spec 里补 `wash.places`（两处，贴着结构）
2. 纸白改成 `#F4EFE4`（如果原来没写）
3. 提示词的「承载与质感」段里加一句「油墨落在纸上有极轻微的边缘柔化」

### B. 出来像「水墨山水画」，有题款感

原因：`style_anchor.raw` 里写了「水墨」而没被翻译（或手写 mapped 时自己写了国画词）。

改法：把 raw 交给脚本翻译，不要手写 `mapped`。禁止项里的「国画题款、朱印、卷轴、
宣纸毛边」这四项一个都不能删。

### C. 版面塌了：文字被色块托着，或者只有一行

原因：`block_bottom` 太靠下（超过 0.64），或描述句太长被模型折行合并。

改法：`block_bottom` ≤ 0.62、`gap` ≥ 0.07；描述压到 12 词以内；
出图后跑 `printcheck.py --annotate`，看间距带是不是被色块吃掉。

这三种占了实际返工的绝大多数。遇到新问题，先跑体检拿到读数，再决定是重出还是叠字——
凭感觉调参数通常会把问题从 A 变成 B。
