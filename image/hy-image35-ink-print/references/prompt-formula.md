# 提示词公式与词库

`build_print_prompt.py` 输出的提示词是固定 12 段。段序不是排版习惯，是**因果顺序**：
先说清「这是什么媒介」，再说「取什么」，再说「怎么解构」，最后才是「怎么排」。
顺序反了，模型会先抓文字与装饰，再往里面塞色块。

## 12 段

| # | 段 | 写什么 | 不写什么 |
| --- | --- | --- | --- |
| 1 | 任务 | 一句话定性：平面设计作品 / 印刷品 / 信息量砍掉一个数量级 | 不说「插画」「海报」「水墨画」（三个词都带错误的先验） |
| 2 | 风格定位 | 平涂 + 淡墨 + 编辑版面三件事的可执行条款 | 不写品牌名、不写流派名 |
| 3 | 取景与重构 | 只取哪一段、保留什么、丢弃什么、参考图只给结构不给内容 | 不写「参考图的构图」（那是照抄） |
| 4 | 几何骨架与平面 | 一条骨架线 + 4–9 个面（形状 + 作用）+ 接缝方式 | 不写「细节」「纹理」「层次丰富」 |
| 5 | 色彩 | 纸白 hex + 4–6 个色 hex + 面积配比 + 改写说明 | 不写「色彩柔和」这类形容词 |
| 6 | 笔触与晕染 | 只在哪几处、浓度、笔势、渗化半径 | 不写「水墨风格」「国画感」 |
| 7 | 承载与质感 | 纸的物理属性 + 无光照无投影无纹理 | 不写「纸张质感很好」 |
| 8 | 版面 | 留白占比、块位置、边距、重心 | 不写「留白很多」（必须给数字） |
| 9 | 文字 | 两行内容 + 字体气质 + 字高比 + 墨色 + 排版纪律 | 不写具体字体名（会被画成 logo 字标） |
| 10 | 克制红线 | 四条：每块颜色能解释、面数上限、墨只在该在的地方、只有一组色两行字 | — |
| 11 | 禁止 | 40+ 项，见下 | 不要把禁止项写成「避免…」（模型会读到那个词） |
| 12 | 输出 | 画幅、尺寸、单张完整作品、无画框无样机 | 不写「8K」（那是重采样，不是原生） |

## 关键词翻译表

这些词在提示词里**不能单独出现**，必须被翻译成参数。脚本会自动替换并打 `[info]`。

| 用户说的 | 模型会做什么 | 应该翻译成 |
| --- | --- | --- |
| 水墨风 | 宣纸、卷轴、题款、朱印、皴法 | 淡墨层：浓度 8%–25%、一笔横拖、渗化 2–4mm |
| 扁平插画 | 色块糊成一片、失去层次 | 分层平涂：每层均匀、层间靠明度差分开、不描边 |
| 海报 | 加边框、加色块、加装饰线 | 编辑版面：留白比例、基线位置、两行小字 |
| 高级感 | 金色、渐变、光影、装饰 | 减法：少色、少面、大留白、无装饰 |
| 学术感 | 衬线字、双栏、页眉、图表 | 图录扉页：大留白 + 衬线标题 + 细体注脚 |
| 参考原图色彩 | 自己编一套色 | 实测 hex 写进提示词，且经过印刷化改写 |
| 边缘自然柔和 | 整图高斯模糊 | 色块边界利落，只有墨接触纸的那一圈渐隐 |

## 词库

### 有效词（写进提示词会起作用的）

平涂 / 均匀油墨 / 叠压 / 交界干净 / 骨架线 / 折线 / 梯形 / 斜切 / 缓弧 /
留白 / 连续整块 / 纸白 / 哑光 / 微暖 / 上重下轻 / 基线 / 边距 /
淡墨 / 半透明 / 渗化 / 起笔重收笔轻 / 墨分五色 / 纸白即高光 /
居中 / 字高比 / 字距 / 衬线手写笔势 / 细体无衬线

### 高危词（出现在 spec 自由文本里会直接拦）

`渐变` `水彩` `纸纹` `纤维` `褶皱` `阴影` `投影` `立体` `3d` `写实` `照片`
`细节丰富` `精细` `泼墨` `飞溅` `splash` `题款` `印章` `卷轴` `宣纸`
`边框` `发光` `光效` `霓虹` `赛博` `装饰` `复杂`

它们各自对应一个 100% 复现的失败模式，理由写在 `build_print_prompt.py` 的
`HIGH_RISK_WORDS` 里（每条都有一句「为什么」）。

### 禁止项（自动生成，可追加）

固定项分六组：

1. **照片残留**：照片贴图、写实细节、摄影光影、光源方向、投影、环境光遮蔽
2. **色与面**：渐变、色彩溢出、荧光色、彩虹色、紫蓝渐变、描边、双线、发光
3. **纸**：纸纹、纤维、颗粒、暗角、折痕、卷边、纸张反光
4. **笔触**：水彩花朵、泼墨、溅点、盐粒效果
5. **国画伴生物**：国画题款、朱印、印章、卷轴、宣纸毛边
6. **版式污染**：画框、白边、样机、桌面、手指、装饰线、圆点、序号、副标题、
   第二段文字、中文字、多格拼接、九宫格、元素堆叠、满幅构图

## 色板口径

`extract_palette.py` 的规则：

| 步骤 | 规则 | 为什么 |
| --- | --- | --- |
| 裁切 | 默认只取画面上半 55% | 下半部通常是地面/倒影/杂物，会把色板拉脏 |
| 聚类 | k-means，k=6（5–8 最佳） | 超过 8 个簇，面积都不到 10%，模型只会挑几个用 |
| 合并 | 加权 RGB 距离 < 22 的簇合并 | 天空/水面/雾会被切成三四段同色，写进提示词是噪音 |
| 排序 | 按面积降序 | 提示词里的顺序就是视觉权重的顺序 |
| 剔除 | 占比 < 3% 标 `drop` | 这些就是「细碎纹理」 |
| 改写 | HSV：S 乘 0.55，上限 0.42（只降不升），V 抬到 0.34–0.96 | 纸白只有 0.94 亮度，0.15 的深绿在纸上是脏的 |
| 墨色 | 最暗簇的色相 + S≤0.12 + V=0.155 | 文字不用纯黑：纯黑在米白纸上像屏幕像素 |

面积配比写死成一句话：「最大的色相占插画面积一半以上，第二层占三成，其余不超过两成」。
不给这个比例，模型会平均分配——平均分配就没有主次，没有主次就没有「克制」。

## 质量门全表

### 硬错误（`error`，返回码 1，不要拿去出图）

| 码 | 条件 | 为什么要拦 |
| --- | --- | --- |
| `E101` | `source` 既无 path 又无 keep | 本 skill 是「基于原图」，没有来源就是自由创作 |
| `E102` | `structure.skeleton` 为空 | 没有骨架，色块会并排成一排，形不成结构神韵 |
| `E103` | `structure.planes` 为空 | 至少 4 个面才有层次 |
| `E104` | `block_top` ≥ `block_bottom` | 版面几何矛盾 |
| `E105` | `whitespace` 不在 0–0.9 | 比例非法 |
| `E106` | 插画下缘 + 空档 > 标题位置 | 文字被色块托着，这是最常见的排版事故 |
| `E107` | `title_y` ≥ `desc_y` | 行序矛盾 |
| `E110` | 标题/描述含占位符 | 模型会把占位符原样排进画面 |
| `E111` | 标题为空 | 底部第一行是语义锚点 |
| `E112` | 标题/描述含中文字符 | 汉字是画形状不是排字，4 字以上必错 → 走 `settype.py` |
| `E120` | `palette.from` 指向的文件不存在 | 色板没提就装配 |
| `E121` | manual 色板 hex 不合法 | 写成 `#RRGGBB` |
| `E122` | 画幅与尺寸比例不一致 | 出图后会被拉伸 |
| `E123` | size 单边 > 4096 | 超过模型上限 |
| `E124` | 没有可用色板 | 「色彩参考原图」是无效指令 |
| `E130` | 自由文本里有高危词 | 见上表 |

### 警告（`warn`，可以出图，但要确认是有意的）

| 码 | 条件 | 建议 |
| --- | --- | --- |
| `W101` | 自定义 style_anchor | 检查有没有反向词 |
| `W102` | 没写 style_anchor | 按「平涂+淡墨+编辑版面」默认处理 |
| `W103` | 几何面 < 4 | 会退化成「一个色块 + 留白」 |
| `W104` | 几何面 > 9 | 砍掉后 1/3，并进上一层 |
| `W105` | 没写晕染位置 | 墨会铺满全图，变成灰雾 |
| `W106` | 留白 < 40% | 会读作一张满幅插画 |
| `W107` | 上边距 < 6% | 纸的承托感消失 |
| `W108` | 描述行贴边 | 下边距至少 6% |
| `W110` | 没写描述句 | 版面缺一口气 |
| `W111` | 标题 > 4 词 | 会缩字号、漏字；压到 2–4 词 |
| `W112` | 描述 > 14 词 | 小字号长句是糊字高发区 |
| `W113` | 描述 < 3 词 | 第二行会像标签，不成句 |
| `W114` | 画幅不在推荐集 | 确认版面 |
| `W121` | 色板两个色距离 < 25 | 平涂后会糊成一片，层次没了 |

## 出图参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `image1` | 参考原图 | 必需 |
| `input_fidelity` | `high` | low 会变成自由创作，原图的结构就断了 |
| `revise` | `false` | 开着会把色板 hex 与禁止项改写掉 |
| `footnote` | 不传 | 这个字段就是水印文本 |
| `size` | `1638x2048`（4:5） / `1365x2048`（2:3） / `2048x2048`（1:1） | 单边 ≤ 4096 |
| `quality` | `high` | |

竖版是默认。横版（3:2 / 16:9）也能做，但底部居中的两行字在宽画幅里会显得很空，
要么把 `title_y` 提到 0.86，要么改成左对齐——那已经是另一种版面了，不在本 skill 范围内。
