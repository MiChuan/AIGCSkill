# 案例：湖畔（Still Water）

一条从高到低的斜折线、一条水平的水岸线、左岸两株树。三层山，五个面，两行字。

这个案例的价值在于它**可以零素材跑通**：`make_demo_ref.py` 合成一张同样构图的原图，
所以下面每条命令都能直接复制执行。换成你自己的照片时，只改 `source` 与 `structure`。

## 命令序列

```bash
cd hy-image35-ink-print

# 1. 合成演示原图（或把你自己的照片放进 assets/）
python scripts/make_demo_ref.py --out assets/demo-ref.png

# 2. 提色板：只取上半 62%，6 个簇
python scripts/extract_palette.py assets/demo-ref.png --outdir out/pal --k 6 --top 0.62

# 3. 装配提示词
python scripts/build_print_prompt.py --spec specs/ink-print-lake.json --outdir out/demo

# 4. 出图（见下表的参数），产出 out/demo/raw/x.png

# 5. 体检 + 标注图
python scripts/printcheck.py out/demo/raw/x.png --layout out/demo/meta.json \
    --palette out/pal/palette.json --annotate out/demo/check.png --json out/demo/report.json

# 6. 文字糊了 / 要排中文时
python scripts/settype.py out/demo/raw/x.png --title "Still Water" \
    --desc "a quiet study of mountains and their reflection" \
    --meta out/demo/meta.json --out out/demo/typed.png
```

## 色板：原图给了什么，纸拿了什么

```
[crop] 画面上半部分 0–62%   [5 簇，保留 4]
  1. #DEE3DF → #D6E3D9   56.0%  ground    青绿系
  2. #6C756E → #969F98   21.5%  secondary 青绿系
  3. #BAC0BA → #C1CEC1   11.6%  support   青绿系
  4. #96A098 → #AFBAB1    9.3%  support   青绿系
× 5. #4A574F → #818D86    1.6%  drop      青绿系
   ink #242825（取自 #6C756E）
```

三条读数值得注意：

- **第 5 簇被 drop 了**。1.6% 的面积、最深的绿——它对应原图里山脊的暗部。
  平涂重构时不需要它：那个暗部会被「山脊下缘的淡墨带」代替。
- **第 1 簇占 56%**，在提示词里就写成「占插画面积一半以上」的主色。
  它其实是天空与水面的混合色——两张皮，但在纸上是一层，这正是「砍信息量」。
- **改写幅度最大的是第 2 簇**：`#6C756E → #969F98`。原色明度只有 0.42，
  直接印在 0.94 的纸上会像一个洞；抬到 0.60 之后才是「墨绿」，不是「黑绿」。

第 3、4 簇的色值很接近（`#C1CEC1` / `#AFBAB1`），加权距离 55，刚好过 `W121` 的
25 门槛。真实照片里这两个通常会被合并成一个——合成图的层次太少。

## spec 的关键三处

**骨架**——只有一句话，但整张图靠它立住：

> 一条从左高向右低的斜折线贯穿画面上部，折点落在画幅宽度的三分之二处，
> 山的重量全部压在这条线以上。

为什么要写「折点在三分之二处」：不写，模型会画一条对称的、居中的山——
那是图标，不是景物。拐点的位置是这块地方的身份。

**五个面**（按视觉权重排序，不能乱）：

| # | 面 | 形状 | 作用 |
| --- | --- | --- | --- |
| 1 | 远山主脊 | 上缘折线、下缘平直的梯形，坡度 11° | 主面，占一半以上 |
| 2 | 第二层山 | 更窄的带，主脊的平行回响 | 第二层 |
| 3 | 水岸线 | 几乎水平的细带，比纸深一两级 | 分割山与水 |
| 4 | 左岸两株树 | 两根竖线 + 两片扁椭圆 | 点缀，很小 |
| 5 | 水面 | 最浅的大矩形，不画波纹 | 底 |

**取景与丢弃**——「丢弃」这栏比「保留」更能约束模型：

> 丢弃：水面上的粼光、岸边的碎石与杂草、天空的渐变、树叶的细碎边缘、远处几处不明建筑

这五项正好是原图里「看起来很多细节、其实全是噪音」的部分。写出来，模型才不会
把它们画成一片碎点——碎点是这套风格最直接的杀手。

## 提示词节选

装配结果 3529 字，12 段。三段的实际样子：

**【风格定位】**

> 以淡墨晕染作为唯一的笔触层：墨分五色，只用最淡的两三级，墨色始终是半透明的，
> 能看见底下的色块；墨的边界靠水分自然渗开，中心浓、边缘淡，一笔之内有浓淡变化；
> 分层平涂的几何色块：每一层的颜色是均匀的，没有渐变、没有笔触纹理、没有噪点，
> 层与层之间靠明度差分开而不是靠描边。……它有印刷品的物理属性（纸、油墨、无光照），
> 有版面的属性（留白、基线、边距），但没有场景的属性（没有光源、没有景深、没有环境）。

**【色彩】**

> 纸白：#F4EFE4（米白、微暖、哑光，接近象牙白但不是米黄）。全画面只有这一种纸色，
> 纸白同时承担「高光」的角色……配色只用下面这几个色相，一个不多：
> #D6E3D9（原图实测 #DEE3DF，已压到纸上）占插画面积约 56%，底色/大面积浅色；
> #969F98（原图实测 #6C756E，已压到纸上）占插画面积约 22%，第二层；……

**【笔触与晕染】结尾那句是关键**

> 关键的区分：**色块的边缘是干净的，墨的边缘才是柔的**。几何面之间的交界是一条
> 利落的线（这是平面的清晰），只有淡墨接触纸白的那一圈是渐隐的。两者不能混——
> 混了就是整张图糊掉，或者整张图变成硬边矢量图。

## 体检读数

下面这组读数来自**合成图**（`out/demo/mock.png`，即验收流程里用来校验脚本的那张），
不是真实出图。它的作用是证明流水线是通的、指标落在区间内；你拿到真实出图后重跑一次，
读数会不一样——真实出图的留白通常更大、纸面噪声更高（模型爱加纸纹）。

```
[paper] #F4EFE4  luma 0.938  sat 0.066  R-B 16  OK
[layout] white 71.5%  ink 28.5%  centroid_y 0.4429  body 0.1716–0.6295
[text]   lines 2  share 2.71%  cx 0.448  size_ratio 2.2  gap 0.1589  contrast 238.1
[clean]  paper_noise 0.0 (367 cells)  sharpness 5.73  edge_peak 502
[hue]    off_palette 4%  (2014 px)
[ok] 版面、纸色、文字、干净度全部落在区间内
[score] 100.0
```

怎么读这六行：

| 行 | 看什么 | 本例 | 说明 |
| --- | --- | --- | --- |
| `[paper]` | 三个量全 OK | OK | 纸色是这套风格的身份证 |
| `[layout]` | white / centroid | 71.5% / 0.44 | 留白偏多，因为合成图的插画块只占 50% 高 |
| `[text]` | lines / ratio / gap | 2 / 2.2 / 0.159 | 间距 15.9% 偏大，合成图的下缘在 63% |
| `[clean]` | noise / edge_peak | 0.0 / 502 | 合成图没有纸纹，边缘是纯阶跃 |
| `[hue]` | 跑偏比例 | 4% | 只有边缘抗锯齿的过渡像素跑出色板 |
| `[score]` | 扣分结果 | 100 | 没有触发任何减分项 |

`--annotate` 出的标注图能一眼看出检测到的四条带：绿框（插画带）、黄框（间距带）、
红框（文字带）、蓝框（每一行）。间距带被吃掉就是排版事故，不用看数字。

## 三种常见返工

| 症状 | 读数长什么样 | 改法 |
| --- | --- | --- |
| 出来像彩色矢量插画，没纸感 | `edge_peak` 600+、`paper_noise` 0 | 补 `wash.places`，纸白确认 `#F4EFE4`，加「油墨边缘极轻微柔化」 |
| 出来像水墨山水，有题款感 | 无读数异常 | 删掉手写的 `style_anchor.mapped`，让脚本翻译；禁止项四项不能删 |
| 文字被色块托着 | `gap` < 0.045 | `block_bottom` ≤ 0.62、`gap` ≥ 0.07，重出 |
| 只有一行字 | `lines` = 1 | 描述压到 12 词以内重出，或直接 `settype.py` 补 |
| 满幅、没有留白 | `whitespace` < 0.40 | `structure.planes` 砍到 6 个以内，`block_bottom` 压到 0.58 |
| 纸面有颗粒 | `paper_noise` > 7 | 禁止项加上「纸纹、纤维、颗粒」，重出 |

## 换自己的照片时改什么

只改三处：

1. `source.crop` / `keep` / `drop` —— 取哪一段、留什么、丢什么
2. `structure.skeleton` + `planes` —— 这是唯一必须人工判断的地方
3. `type.title` / `desc` —— 2–4 词 + ≤14 词

色板永远重跑 `extract_palette.py`，不要手抄。手抄的 hex 一定会偏——
你抄的时候看的是屏幕，纸上要的是改写后的值。
