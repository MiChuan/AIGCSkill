# 参考照片 → 水墨平涂印刷品

一句话：**这不是给照片套一个水墨滤镜，是把照片的信息量砍掉一个数量级，再重新排版。**

和同目录另外几个 skill 的分工：`cinematic` 管人进场景，`lowkey-portrait` 管人被打光，
`photo-seal` 管照片压成符号，`nationalgeo` 管调子。本 skill 管**照片变成一张版面**——
内容被重构，承载从「相纸」换成「米白哑光特种纸」，并且多了文字这一层。

## 六条不可让的约束

### 1. 「水墨」是笔触，不是画种

「水墨风」三个字直接进提示词，模型给你的是一幅**传统国画**：宣纸毛边、卷轴、
题款、朱印、皴法、远山淡影。它给的是一张「画出来的山水」，不是一张**设计过的版面**。

本 skill 要的水墨只有一件事：**淡墨作为一层半透明的笔触，盖在平涂色块之上**。
所以「水墨」必须被翻译成三个可执行参数——浓度（墨与纸 8%–25%）、笔势（一笔横拖、
起笔重收笔轻）、渗化半径（2–4 毫米相对画面）。同时把国画的伴生物全部写进禁止项：
题款、朱印、卷轴、宣纸毛边。

`build_print_prompt.py` 会自动做这个翻译并打一条 `[info]`。**不要关掉。**

### 2. 「边缘柔和」说的是墨，不是整张图

用户原话里的「边缘自然柔和，避免锐利硬边」，是本风格最容易被执行错的一条。

模型的两种误读都很稳定：

| 误读 | 结果 | 怎么防 |
| --- | --- | --- |
| 理解成整体柔焦 | 全图高斯模糊，色块边界糊成灰带 | 提示词里明写「色块边缘是干净的，只有墨接触纸的那一圈是渐隐的」 |
| 理解成矢量硬边 | 变成 AI 矢量插画，一点纸感都没有 | 保留淡墨层 + 油墨边缘 1px 的柔化 |

正确的分工是：**几何面之间的交界是利落的线**（那是平面的清晰），**只有墨的边缘是渗开的**。
`printcheck.py` 用 Sobel 梯度 99.5 分位量这件事——低于 220 就是被整体糊掉了。

### 3. 留白是版面结构，有比例、有基线、有边距

只写「大面积留白」，模型会填满画布，然后在四边留一圈白——那不叫留白，那叫白边。

本 skill 把留白拆成四个数字（占画幅高的比例）：

| 量 | 默认 | 为什么是这个数 |
| --- | --- | --- |
| 纯纸白占比 | ≥ 52% | 低于 40% 就成「一张满幅插画」；高于 76% 插画小到像个 logo |
| 插画块上缘 | 10% | 上边距不能小于 8%，否则纸的「承托感」消失 |
| 插画块下缘 | 60% | 留出 8% 的空档给文字，文字必须**完全落在纸白上** |
| 标题 / 描述中心 | 80% / 87.5% | 底部留 6% 下边距；两行整体压在下缘三分之一内 |

重心必须在上半部（非纸像素质心 22%–56%），下半部只有两行小字——**上重下轻**，
这是这类版面的呼吸方式。重心掉到 60% 以下，画面立刻变得像一张「图配文」的宣传单。

### 4. 色彩必须从原图测出来，而且必须被改写

「色彩严格参考原图」是无效指令：模型拿不到原图的色值，它会自己编一套。

所以有 `extract_palette.py`：只取画面上半部分（下半部通常是地面、倒影、杂物），
k-means 聚 5–8 个主色，按面积排序，占比低于 3% 的簇直接标 `drop`——那些就是
「细碎纹理」，正是要剔除的东西。

拿到之后还要**改写**，这一步不能省：

| 量 | 原图 | 印到纸上 |
| --- | --- | --- |
| 饱和度（HSV） | 常见 0.4–0.9 | 压到原值的 55%，上限 0.42（淡彩） |
| 明度（HSV V） | 常见 0.1–1.0 | 抬到 0.34–0.96 |
| 色相 | — | **一个不动** |

为什么：纸白本身只有 0.94 的亮度，原图里 0.15 的深绿搬过去不是「浓」，是「脏」；
屏幕上的纯黑搬到纸上像一块屏幕像素。色相不动，是为了让画面仍然读得出是原图那处景物。

### 5. 文字是本风格最大的风险点

图像模型排字是**画形状**，不是**排字**。失败模式极稳定：

| 情况 | 结果 |
| --- | --- |
| 标题 2–4 个英文词 | 基本正确，偶尔字距不匀 |
| 标题 5 个词以上 | 会自动缩字号、加装饰线，或者漏字 |
| 描述句 8–12 个词 | 大体可用，但小字号容易糊 |
| 描述句 15 个词以上 | 糊字率高，且会自己断行成三行 |
| 任何中文 | 4 字以上几乎必有错字（画字不是写字） |

所以：标题 2–4 词、描述 ≤ 14 词（质量门 `W111` / `W112` 会提醒），
中文一律走 `settype.py` 叠字。**不要指望「多抽几次就好了」。**

### 6. 它是印刷品，不是「一张纸的照片」

这是区分「设计图」和「摆拍样机」的一条线。要写死：

- 没有光源方向、没有环境光、没有投影、没有景深、没有高光反射
- 纸面**均匀**：无纹理、无纤维、无颗粒、无折痕、无卷边、无暗角
- 色块是均匀平涂的油墨：内部无颗粒、无笔刷纹理、无厚涂立体感
- 唯一的「手感」只来自淡墨那一层

模型很爱加的三样东西正好全在这条线的反面：纸张纤维噪点、四角暗角、纸边投影。
`printcheck.py` 的纸面噪声（网格法，≤ 7）和纸色三判据就是拦它们的。

## 流水线

### Step 0 — 收料

按顺序问清楚，缺一项都会返工：

1. **原图**：一张照片。人像、风景、建筑、静物都行，但要有**清晰的上半部结构**
   （山脊、屋檐、树冠、天际线）。纯纹理照（比如一整面墙）没有可重构的骨架。
2. **取哪一段**：默认画面上半 55%–62%。判断标准是「这一段里有没有一条能立住的轮廓线」。
3. **保留什么 / 丢掉什么**：这是本 skill 唯一需要人工判断的地方。写清 3–5 个「保留」，
   3–5 个「丢弃」，比写十句形容词有用。
4. **画幅**：竖版 4:5（默认，最像图录扉页）、2:3（更像书页）、1:1（方版）。
5. **标题与描述**：英文，标题 2–4 词，描述 ≤ 14 词。没有就让用户给，别自己编——
   标题是这张图的语义锚点。
6. **要不要叠字**：要中文、或标题必须 100% 正确 → 出图时不要文字，走 `settype.py`。

出图消耗积分（一张约 5–10 积分），开跑前说明。

### Step 1 — 提色板

```bash
python scripts/extract_palette.py assets/ref.jpg --outdir out/pal --k 6 --top 0.62
```

产出 `palette.json` + 色卡 `palette.png`（左原色、右改写色，人眼一比对就知道改写幅度）。

读数看两件事：
- `kept_share` ≥ 0.80：保留的色簇覆盖了足够多的面积。低于 0.80 说明原图太碎，
  把 `--k` 调小或 `--top` 再往下裁。
- `drop` 的那几个簇：它们就是原图里的杂物，进提示词时要明写丢弃。

### Step 2 — 写结构

spec 里最值钱的是 `structure`，不是形容词：

- `skeleton`：一句话说清「画面靠哪一条线立起来」。斜折线、横带、竖直、对角——只选一条。
- `planes`：4–9 个面，按视觉权重大小排序，每个面给**形状**（梯形/矩形/椭圆/斜切）和
  **作用**（主面/第二层/点缀/底）。超过 9 个人眼就不读作「极简」了（`W104` 会拦）。
- `seam`：面与面怎么收口。多数翻车是「拼接」而不是「叠压」，一句接缝说明能救回来。

判断重构到不到位，看一条：**遮住文字，还能不能认出原图是同一处景物？**
能，就是重构；不能但形状很漂亮，就是重新画了一张。

### Step 3 — 装配提示词

```bash
python scripts/build_print_prompt.py --spec specs/ink-print-lake.json --outdir out/demo
```

产出 `prompt.txt`（约 3500 字，12 段）+ `meta.json`（版面预期值，给体检脚本用）。

质量门会检查：没色板、标题/描述含中文、占位符、插画压到文字、画幅与尺寸不一致、
几何面过少过多、留白不足、高危词（渐变/纸纹/阴影/水波/泼墨/宣纸…）、
色板区分度不足、标题过长。

### Step 4 — 出图

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `prompt` | `prompt.txt` 全文 | |
| `image1` | 参考原图 | 必需。这是「基于原图」的唯一锚点 |
| `input_fidelity` | `high` | 保结构；调到 low 会变成自由创作 |
| `revise` | **`false`** | 开着会把色板 hex、禁止项改写掉 |
| `footnote` | **不传** | 这个字段就是水印文本，不传即无水印 |
| `size` | 4:5 → `1638x2048`；2:3 → `1365x2048`；1:1 → `2048x2048` | 单边 ≤ 4096 |
| `quality` | `high` | |
| `output_dir` | `out/demo/raw` | |

### Step 5 — 体检

```bash
# 量版面
python scripts/printcheck.py out/demo/raw/x.png --layout out/demo/meta.json \
    --palette out/pal/palette.json --annotate out/demo/check.png --json out/demo/report.json
```

`--annotate` 会画一张标注图（文字带、每一行、插画带、间距带），肉眼对照最快。

| 量 | 合理区间 | 超出说明什么 |
| --- | --- | --- |
| 纸色 luma / R-B / sat | 0.855–0.985 / 4–26 / ≤0.13 | 死白、灰了、或者被染色 |
| 留白率 | 40%–76% | 低于 40% 是满幅插画，高于 76% 像 logo |
| 重心 cy | 22%–56% | 偏低说明插画下坠或多了一块色 |
| 文字行数 | 2 | 1 行 = 描述被漏；>2 行 = 多排了内容 |
| 标题/描述字高比 | 1.6–4.8 | 按墨迹高度量（非字号比）；小于 1.6 是两个标题，大于 4.8 是标题配免责声明 |
| 插画到文字间距 | ≥ 4.5% | 小于 4.5% 文字被色块托着，版面变挤 |
| 文字带水平中心 | 44%–56% | 没居中 |
| 纸面噪声 | ≤ 7 | 加了纸纹/颗粒/明暗不匀 |
| 边缘陡度（99.5 分位） | ≥ 220 | 整体被高斯模糊了 |

`score` 是扣分制，100 起扣。低于 80 就有明显问题，低于 60 建议直接重出。

### Step 6 — 验收与保底

全过就走交付；文字糊了、漏了一行、或者要排中文：

```bash
python scripts/settype.py out/demo/raw/x.png --title "Still Water" \
    --desc "a quiet study of mountains and their reflection" \
    --meta out/demo/meta.json --out out/demo/typed.png
```

它先用纸色把文字带刷干净，再逐字排上去——字号比、字距、居中都是算出来的精确值，
比模型排的还整齐。中文要指定字体（`--title-font`）。

## 验收清单

**纸**
- [ ] 底色是米白（微暖），不是纯白、不是米黄、不是灰
- [ ] 纸面每一处都一样，没有颗粒、纹理、暗角、折痕
- [ ] 找不到「纸的边缘」——它不是一张被拍下来的纸

**版面**
- [ ] 留白是连续的整块，不是被切碎的白缝
- [ ] 插画不顶边，左右各留 12% 以上
- [ ] 重心在上半部，下半部只有两行字
- [ ] 插画与文字之间有一道明确的空档，文字没有压在色块上

**结构**
- [ ] 遮住文字还能认出原图那处景物
- [ ] 一条骨架线能一眼读出来，低饱和也没消失
- [ ] 色块数量在 4–9 之间，面内没有切碎
- [ ] 面与面是叠压关系，交界干净；没有描边、没有双线

**笔触**
- [ ] 平涂色块内部均匀，没有笔刷纹理、没有渐变
- [ ] 淡墨只在指定的一两处，能看见下面的色块
- [ ] 墨的边缘是渗开的，色块的边是利落的——两者没有混
- [ ] 没有水彩花朵、没有泼溅点、没有盐粒效果

**文字**
- [ ] 两行，居中，只有两行
- [ ] 标题是衬线（带一点手写笔势），描述是细体无衬线、字距略宽
- [ ] 字号比 2.2–2.5（视觉上线高比会是 3–4.5，这是正常的），两行之间空一个描述行高
- [ ] 字是「排出来的」：字重、字距、基线一致，没有手绘感
- [ ] 没有装饰线、圆点、序号、副标题、第二段

任一条不过：**先重出，再考虑叠字**，不要用后期硬修色块——色块修不圆，纸色修不匀。

## 已知局限

- Hy Image3.5 preview 原生 2K，`1638x2048` 是甜点尺寸；要更大只能重采样，
  而重采样不会让色块边缘变干净。
- 色板是继承原图色相的，原图偏黄（黄昏、暖灯）时整张图会偏暖。要中性就换一张原图，
  不要在提示词里加「色温」——那会和色板 hex 打架。
- 文字仍可能糊，尤其描述行的 `ff` / `tt` / `rn`。这不是参数问题，用 `settype.py`。
- 淡墨的「渗化」在 2K 下只有几个像素宽，放大后看得出是「柔边」而不是真的水墨扩散。
  这是分辨率的上限，不是提示词的问题。
