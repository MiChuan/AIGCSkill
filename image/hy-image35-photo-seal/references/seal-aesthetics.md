# 篆刻的硬知识，与"照片→印"的翻译规则

这一篇解决两个问题：提示词里那些词（朱文、白文、冲刀、缪篆）到底指什么；以及照片里的东西怎么落成印面上的东西。

## 一、朱文与白文

这是篆刻最基础的一对概念，**写反了整个印面就反了**。

| | 石面上 | 钤出来 | 视觉重心 |
| --- | --- | --- | --- |
| **朱文**（阳刻/阳文） | 笔画与图案凸起 | 线条是**印泥色**，底是纸白 | 红少白多，线条是主体 |
| **白文**（阴刻/阴文） | 笔画与图案凹陷 | 底是**大片印泥色**，字是纸白 | 红多白少，红块是主体 |

选哪个：

- 有图案（山水、人物、建筑）→ **朱文**。图案要"读"得出来，红线条最省空间。
- 纯文字、要庄重 → **白文**。汉印的官印多是白文，红底压得住。
- 图案 + 文字 且印面小 → 朱文。白文的红底会把图案和字一起吃进去。

**白文的坑**：字是"空"出来的，所以字与字之间必须有足够的红（底），字与边框之间也要留红。红底连成一片、白线被挤没，就是废印。质量门 `W311` 专门拦这个（白文 + 图案占比 > 0.75）。

## 二、边框

| 类型 | 特征 | 适合 |
| --- | --- | --- |
| 细边 | 宽度约为笔画的 1/2，四边略有粗细变化 | 朱文最常用，秀气 |
| 粗边 | 宽度约为笔画的 1.5 倍，边与内容留间隙 | 白文、古玺味 |
| 残边 | 不闭合，1–2 处断裂，或与图案相接（借边） | 有年代感、有刀味 |
| 无边 | 不画外框，靠内容自身轮廓围合 | 现代感、图案印 |

"四边粗细略有变化"这句必须写进提示词。不写，模型给你一个 CAD 画的等宽圆环，一眼假。

## 三、刀法：印章的"细节丰富"在这里

真实印章的线条不是画出来的，是刻出来的，所以有两个必然特征：

**冲刀**：刀一路推过去，线条**一侧光洁、另一侧有细微毛边**，末端有速度感的收尖。
**切刀**：一刀一刀切，线条呈**节节顿挫的方折**，边缘有锯齿状小崩口。

再加上石材本身的**崩口**（笔画末端、转折处的米粒大缺口）和**印泥颗粒**（吃墨不匀留下的细碎白点）。

这些才是"细节丰富"该指的东西。提示词里写"线条粗细有呼吸变化，起笔略重、收笔略提，不是等宽的矢量描边"，比写"细节丰富、高清"有用得多。

## 四、印面分区

印面是"方寸之地"，图文关系就三种：

1. **图文并列**：图案占 60–70% 在一侧，文字占 30–40% 在另一侧的一列。最常见，也是本 skill 的默认。
2. **图案居中 + 文字上下**：适合方形印、图案较方正时。
3. **纯文字**：2 字竖排、4 字 2×2。没有图案，全靠字形与留白。

**文字方向是硬的**：竖排、自上而下、字组自右向左。**不是**横排从左到右。写错这条，"印章感"立刻没了——横排中文会读成招牌。

4 字 2×2 的读序：右上 → 右下 → 左上 → 左下。

## 五、印泥色档案

| 名称 | 色值 | 气质 |
| --- | --- | --- |
| 朱砂红 | `#B23A2E` | 最经典，偏暖正红，明度中等偏暗 |
| 朱膘 | `#C4553A` | 偏橘，暖调重，像旧年画 |
| 仿古 | `#8C3B2B` | 偏褐暗红，带陈土味 |
| 西洋红 | `#A02B3C` | 偏洋红深红，冷调，近现代 |
| 墨 | `#2B2622` | 近乎黑，带极弱暖褐 |

**不要用鲜红**。`#FF0000` 那种是电商红，钤在纸上会像贴纸。判据很简单：印泥的明度 V 一般落在 0.55–0.72，饱和度 S 在 0.65–0.80。质量门 `W303` 就是按这个拦的。

另外印泥与纸的对比度要 ≥ 4:1，低于 3.2 会"发虚"（`W310`）。朱砂配宣纸的对比度约 4.7:1，是安全区。

## 六、照片 → 印面：翻译规则

这一步是本 skill 最容易被做错的地方。**照片的每一个维度几乎都要被扔掉**，只留"可辨认的最小结构"。

| 照片里的 | 印面上的 | 扔掉 |
| --- | --- | --- |
| 建筑 | 几根柱 + 一条屋檐折线 + 一个门洞 | 砖瓦、窗棂、材质、透视 |
| 树 | 主干 + 2–3 层分枝 + 点簇针叶 | 每一片叶、树皮质感、投影 |
| 山 | 一条有节奏的折线 | 云雾、积雪层次、远近虚实 |
| 水 | 2–3 条横线或几道波浪折线 | 波纹细节、反光 |
| 人 | 侧影/剪影/半身轮廓 | 五官细节、衣纹、表情 |
| 花 | 一朵正视花 + 一两片叶 | 花瓣层次、花蕊 |
| 器物 | 外形轮廓 + 1–2 条结构线 | 花纹、高光、材质 |

**主次靠线宽区分**，不靠明暗：主体线粗（30–40px @2048），次体线细（14–20px），点缀最细。这是印章表达层次的手段，因为印章没有灰阶。

**元素数量上限 3**。第 4 个元素开始在方寸之间就碎了（`W305`）。如果照片元素多，选"最能代表这张照片"的那一个当主体，其余全丢。

## 七、失败模式表

| 症状 | 原因 | 怎么改 |
| --- | --- | --- |
| 像"照片套了个圆框" | 提示词没写"双色化"，模型的连续调没被消掉 | 补【双色化规则】那一段；`forbidden` 加"连续调灰阶" |
| 印面糊成一团 | 图案塞太满 / 白文红底连片 | 降 `pattern_ratio` 到 0.55–0.65；白文 ≤ 0.70 |
| 字是错的 | 模型画字，字数超了 | 压到 2–4 字；或走 `stamp_text.py` 路线 |
| 字压在图案上 | 没写"文字只在留白区" | 提示词【刻字】末句已含；仍不行就调 `text_position` |
| 边框像 CAD 圆环 | 没写"四边粗细略有变化" | 已内置在 `BORDER_DESC` |
| 边缘一圈均匀噪点 | 模型理解成"加个噪点滤镜" | 磨损要写"不对称、不均匀、局部"（已内置） |
| 出现了第三种颜色 | 印泥+纸之外混入橙/紫/绿 | `sealcut.py` 的色相集中度会量化出来，重出 |
| 印章外有桌面/投影 | 模型默认给了场景 | 掩膜净化会清掉；提示词里【纸面】已写死"纸表就是全部背景" |
| 圆形被压成椭圆 | 画布不是 1:1 | `size` 必须是 `2048x2048` |
