# 中文字的渲染：为什么"刻字"是整个需求里最脆的一环

## 一、模型不是"排字"，是"画形状"

图像模型没有字形表。它看到"刻「山亭晚照」"时，是在生成一张**看起来像汉字**的图案。字越少，它见过的样本越多，越准；字越多，它越容易进入"随便画几个方块"的模式。

失败模式非常稳定，按字数走：

| 字数 | 期望结果 | 实际 |
| --- | --- | --- |
| 1 字 | 正确 | 基本正确 |
| 2 字 | 正确 | 多数正确 |
| 3–4 字 | 正确 | 常见 1 个字缺笔/结构走形，偶尔错字 |
| 5–6 字 | 正确 | 大概率 1 个字错 |
| 7+ 字 | 正确 | 几乎必错，且会**造出不存在的字** |

其他常见崩法：

- **笔画粘连**：篆书笔画密，"間""聽""寶"这类字糊成一团黑块。
- **镜像反转**：古代印有"回文印"，模型见过，偶尔会整列反过来。
- **繁体/简体串味**：写"云"变成"雲"的一半，写"听"变成"聽"的残体。
- **缺字**：要求 5 字只给你 4 字，还排得挺整齐。

所以质量门的 `E401` 在 7 字时直接判定为硬错误——不是保守，是实测几乎必错。

## 二、两条路线的取舍

### 路线 A：让模型直接写（默认）

**适用**：2–4 字，且能接受"重出 2–3 次"。

要点：

1. **逐字列出**。提示词里已经写成"第1字「山」、第2字「亭」、第3字「晚」、第4字「照」"，这个格式比只写"刻山亭晚照"准确得多——它把"有 4 个字"和"每个字长什么样"分开说了。
2. **优先选繁简同形的字**。山、水、云（雲）、松、雪、月、林、石、亭、春、秋、风（風）——同形的字绕开一半风险。
3. **出图后逐字核对，错一个字就重出**。不要试图局部修图：印章的字与周围的刀痕、印泥浓淡是连在一起的，贴一个字补丁会比错字更显眼。
4. 重出时**换随机种子**比换措辞更有效。措辞改动会牵动整个构图。

### 路线 B：无字底 + 叠刻（保底）

**适用**：5 字以上、字数不能减、或必须 100% 正确。

分两步：

```bash
# 1) 出图时提示词里把【刻字】整段删掉，只描述图案和"右侧留一列空白"
# 2) 叠字
python scripts/stamp_text.py out/seal/raw_blank.png \
    --text "山亭晚照" --out out/seal/seal_text.png \
    --font C:/Windows/Fonts/simkai.ttf --shape round --rough 1.0
```

脚本做的事：

1. **按印面实际位置算文字区**。圆形印退到**内接正方形**（直径 × 0.70）再切右侧一列——直接用"右侧 30%"这种固定比例，矩形四角在圆外，字会被圆环切掉。
2. **字号取"每格高度"与"列宽"的较小值**，多列时字不会压叠。
3. **质感模拟**：腐蚀出实心核心 + 膨胀出边缘带 → 边缘带用噪声筛掉一部分（崩口）→ 随机擦几个小圆（磕碰缺口）→ 叠一层缓变浓淡（印泥厚薄）→ 0.6px 微模糊（纸纤维洇开）。
4. **印泥色从原图采样**（高饱和像素的中位色），所以叠上去的字和原印章同色。

参数：

- `--rough 0` 光洁的现代字体；`1.0` 默认；`2.5` 很破，适合仿古印。
- `--cols 2` 两列（2×2 布局），但**需要留白足够宽**，否则会压到图案——这种印在出图时就要把图案压到左侧。
- `--box x,y,w,h`（0–1 相对坐标）手动指定文字区，自动定位不准时用。

**路线 B 的代价**：字是系统字体的形状（楷体/宋体），不是真正的缪篆。想要古味，得装一个篆书字体（如"汉仪篆书""方正小篆"）并用 `--font` 指过去。没有篆书字体时，楷体的方折感也能接受——`--rough` 拉高一点，崩口会盖住一部分"太规整"的感觉。

## 三、验收：逐字核对怎么做

不要整体看一眼"感觉对"。**逐字**过一遍：

1. 数一遍字数，和要求的字数对上没有。
2. 每个字单独看：笔画有没有缺、有没有多、结构有没有走形。
3. 检查顺序：竖排是不是从上到下、字组是不是从右往左。
4. 检查有没有镜像（整列或单字反过来）。
5. 检查有没有被图案压住（露出的笔画不够，等于缺字）。

这条清单在 `SKILL.md` 的 Step 4 里，每次都要走完。印章是符号，符号错了，整张图就废了——不像人像，脸差一点还能叫"艺术加工"。
