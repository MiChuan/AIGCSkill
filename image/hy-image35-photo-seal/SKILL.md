# 照片 → 专属印章

一句话：**把照片"翻译"成一枚盖在纸上的印，不是给照片套一个圆框。**

三个 skill 的分工：`cinematic` 管人进场景，`lowkey-portrait` 管人被重新打光，本 skill 管**照片被压缩成符号**。

## 四条不可让的约束

### 1. 提取是翻译，不是描边

照片是连续调（有几万级灰度），印章只有两级（印泥色 / 纸色）。所以必须做一次**降维翻译**：把建筑压成几根柱子和一条屋檐线、把树压成主干加三层分枝、把山压成一条折线。

判断有没有翻译到位，看一条：**遮住文字后，这枚印还能不能让人认出原照片的地方？** 能，就是翻译；不能但画面很像照片，就是套框。

提示词里"详细的建筑细节""砖瓦纹理""树叶层次"这类词一旦写进去，模型必然退款成照片贴图。它们应该出现在 `forbidden` 里，不是 `keep` 里。

### 2. 文字是最大的风险点

图像模型渲染汉字是**画形状**，不是**排字**。失败模式很稳定：

| 字数 | 结果 |
| --- | --- |
| 1–2 字 | 基本正确 |
| 3–4 字 | 常有单字缺笔、结构走形 |
| 5–6 字 | 大概率有 1 个字错 |
| 7 字以上 | 几乎必错，且会造字 |

所以有两条路线，**不要指望"多试几次就好了"**：

- **路线 A（首选）**：字数压到 2–4 字，一次出图，出完**逐字核对**。错一个字就重出（换种子 / 换措辞），不要靠后期修。
- **路线 B（字多或必须 100% 正确时）**：出图时**不要文字**，只要图案 + 留白，再用 `scripts/stamp_text.py` 把字刻进去。字 100% 正确，质感由脚本模拟崩口与浓淡。

质量门里 `E401` 会在字数 ≥7 时直接拦下来，就是逼你走路线 B。

### 3. "细节丰富"指的是刀痕，不是照片细节

用户常说"细节丰富、高分辨率"。在印章语境里这句要翻译成两件事：

- **刻痕细节**：笔画边缘的崩口、冲刀的速度感、米粒大的缺角、印泥颗粒 → 这是印章的"细节"。
- **像素细节**：每一根线条、每一颗印泥颗粒清晰可辨 → 这是分辨率的"细节"，2048–4096 就够，**不需要 8K**。

反过来，**照片细节**（纹理、光影、透视、层次）越丰富，印章越废。这是本 skill 最常被误解的一条。

### 4. 单色是真的只有两色

画面里只允许存在两种颜色：印泥色、纸色。没有第三种色相，没有渐变，没有半调网点，没有阴影。模型的默认行为是给你"红色的照片"——那里面有几百种红。质量门的 `W303` 会拦过亮的电商红（`#FF0000` 这种），`sealcut.py` 会用色相集中度量化"到底是不是单色"。

## 流水线

### Step 0 — 收料

按顺序问清楚，缺一项都会返工：

1. **参考照片**（放 `assets/photo.jpg` 或给路径）。
2. **主题文字**：照片的"主题"，2–4 字最佳。**优先选繁简同形的字**（山、亭、水、云、风→風、松、雪、月、林、石），能绕开一半的字形风险。
3. **形状**：圆形（最常见）/ 方形（汉印风格）。默认圆形。
4. **朱文还是白文**：朱文 = 红线条、红少白多，适合有图案的印；白文 = 红底白字、红多白少，庄重，适合纯文字印。默认朱文。
5. **印泥色**：朱砂红（默认）/ 朱膘 / 仿古 / 西洋红 / 墨。
6. **纸色**：宣纸米黄（默认）/ 净白 / 古纸。

**先看图再定元素**：读参考照片，判断"哪 1–3 个元素能代表这张照片"，写进 `subject.keep`；把不能代表的东西（天空云层、地面碎石、人物衣纹）写进 `subject.drop`。这一步是本 skill 唯一需要人（或视觉模型）判断的地方，脚本替不了。

出图消耗积分（一张约 5–10 积分），开跑前说明。

### Step 1 — 装配提示词

```bash
python scripts/build_seal_prompt.py --spec specs/photo-seal.json --outdir out/seal
```

产出 `prompt.txt` + `meta.json`。质量门会检查：占位符没替换、形状/类型不合法、没写提取元素、字数超限、印泥过艳、印泥与纸对比不足、图案占比过高没留白可刻字、白文配大块面、简体字入印。

### Step 2 — 出图

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `prompt` | `prompt.txt` 全文 | |
| `image1` | 参考照片 | 元素来源 |
| `input_fidelity` | `high` | 尽量贴近参考图的结构 |
| `revise` | `false` | 开着会把"双色化""不要灰阶"改写掉 |
| `footnote` | 不传 | 不请求水印 |
| `size` | `2048x2048`；要更大的刀痕细节用 `4096x4096` | 正方形，绝不能给非 1:1 |
| `quality` | `high` | |
| `output_dir` | `out/seal/raw` | |

**画布必须 1:1**。给 3:2 的话圆形会被压成椭圆，`sealcut.py` 会在体检里报出来。

### Step 3 — 体检 + 收尾

```bash
# 只体检
python scripts/sealcut.py out/seal/raw/x.png --check-only

# 净化 + 4K + 透明底
python scripts/sealcut.py out/seal/raw/x.png --shape round --seal-type zhuwen \
    --out out/seal/seal_4k.png --size 4096 --crop --alpha

# 要纯白底素材（贴到任何地方都不带纸色）
python scripts/sealcut.py out/seal/raw/x.png --shape round --paper white --out out/seal/seal_white.png
```

做四件事：

1. **定位印面**：先用高饱和掩膜（朱砂这类印泥），失败再退回"与纸色的差异"。找不到或框不合理时提示用 `--box x,y,w,h` 手动框。
2. **掩膜净化**：圆/方掩膜以外的一切统一成纸色——模型爱画的桌面、投影、纸角、水印都在这一步被带走。**这也是水印的主要解法**：不用单独去水印，只要印面外的水印会被掩膜清掉。
3. **量化三项**：印泥覆盖率、色相集中度、灰阶渗漏（判据见 `references/sealcut.md`）。不达标就重出。
4. **导出**：裁正方形、放缩、可选透明底 PNG（印泥浓处不透明、淡处半透明，贴任何底都不出纸色白边）。

**印面内还压着阴影/灰雾**时加 `--flatten-paper on`：只动"低饱和 + 暗于纸色"的像素，饱和的印泥不受影响。

### Step 4 — 验收

**符号**
- [ ] 遮住文字后还能认出原照片的什么地方
- [ ] 元素是块面/折线，不是照片轮廓的描边
- [ ] 只剩 1–3 个主体，印面没有塞满
- [ ] 没有砖瓦纹理、树叶层次、透视关系这类照片细节

**文字**
- [ ] 逐字核对：笔画正确、没有缺笔、没有造字、没有镜像
- [ ] 字在留白区，没有压到图案、没有越出印面
- [ ] 竖排、从上到下、字组从右往左
- [ ] 字形是方折缪篆意，不是宋体/黑体

**印**
- [ ] 朱文：红线条、留白通透；白文：红底白字、白线干净
- [ ] 边框粗细有变化，不是机械等宽的圆环
- [ ] 边缘磨损**不对称**：1–2 处磕碰缺角、印泥外溢晕边、一侧偏淡
- [ ] 印面内纸白干净，没有灰雾或投影

**色**
- [ ] 只有印泥色与纸色两种颜色，没有第三种色相
- [ ] 没有渐变、半调网点、发光
- [ ] 印泥浓淡不匀，有颗粒感

**成品**
- [ ] 正方形，长边 2048–4096
- [ ] 无水印、无文字、无 logo、无桌面背景

任一条不过就重出。印章是符号，符号画歪了没有后期可救。
