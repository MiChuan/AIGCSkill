# 案例：一张山间小亭的照片 → 圆形朱文印「山亭晚照」

这个案例对应 `specs/photo-seal.json`，可以直接跑：

```bash
python scripts/build_seal_prompt.py --spec specs/photo-seal.json --outdir out/seal
```

## 一、需求拆解

原始需求是这么一句：

> 将这张照片转化为专属印章，提取核心元素（如人物/建筑/植物），单色复古印泥质感，边缘自然磨损，留白处刻字："[照片主题]"，印章形状：圆形/方形，细节丰富，高分辨率

每个词落到参数上的过程：

| 需求原文 | 落到哪 | 怎么定的 |
| --- | --- | --- |
| "这张照片" | `ref` | 假设是半山腰有座小亭、前景有松树的风景照 |
| "提取核心元素" | `subject.keep` | 3 个：亭、松、山脊。**不超过 3 个**，第 4 个开始就碎 |
| "（如人物/建筑/植物）" | — | 这是举例，不是都要。本例是建筑（亭）+ 植物（松） |
| "单色复古印泥" | `ink` | 朱砂红 `#B23A2E`。**"复古"体现在明度偏暗、饱和度中等**，不是加一个 sepia 滤镜 |
| "边缘自然磨损" | `wear` | 磕碰缺角 + 印泥外溢 + 压力不匀三项都开 |
| "留白处刻字：[照片主题]" | `theme` | 占位符必须替换。本例取「山亭晚照」4 字 |
| "圆形/方形" | `shape` | 选圆形。方形要另出，参数改一下 |
| "细节丰富" | 刀法 + 画质 | 翻译成刀痕细节（崩口/颗粒），**不是**照片细节 |
| "高分辨率" | `size` | 2048 起步，交付放大到 4096 |

两处需要判断的地方：

1. **"细节丰富"是本需求最容易做反的词**。见 `SKILL.md` 约束 3：它指的是刻痕，不是照片纹理。所以 `forbidden` 里明确列了"砖瓦纹理""树的写实枝叶""透视关系"。
2. **未知的主题文字**。用户写的是 `"[照片主题]"`，这是占位符。质量门 `E103` 会直接把它拦下来——这不是可选项，填错了整枚印就是废的。

## 二、spec 关键字段

```json
{
  "theme": "山亭晚照",
  "shape": "round",
  "seal_type": "zhuwen",
  "border": "thin",
  "subject": {
    "keep": ["半山腰那座四角小亭的轮廓", "前景斜出的一棵松树", "远处山脊的折线走向"],
    "drop": ["天空的云层层次", "地面的碎石、草叶与土路", "光线、阴影与整体色调"],
    "style": "亭子取四根柱、一个翘檐顶，屋面只留一条斜线；松树取主干加两三层分枝，针叶缩成短促的点簇；山脊拉成一条有节奏的折线"
  },
  "layout": { "pattern_ratio": 0.62, "text_position": "right_column", "text_columns": 1 }
}
```

`subject.style` 是**唯一必须手写**的字段。前面那些 `keep`/`drop` 只说了"要什么、不要什么"，这里说"具体怎么画"——它是把照片翻译成篆刻语言的施工图。写得越具体，模型越不会退款成照片贴图。

## 三、成品提示词的结构

全文见 `out/seal/prompt.txt`，共 12 节。骨架：

```
【任务】      照片 → 印章，明确"不是套框、不是染红"
【元素提取】  要什么（keep）+ 怎么翻译（style）+ 不要什么（drop）
【双色化规则】 连续调 → 两色，消掉所有中间灰阶
【印章类型】  朱文 / 白文，以及红少还是红多
【边框】      细边/粗边/残边/无边
【刀法】      冲刀 + 切刀 + 崩口 + 颗粒
【刻字】      逐字列出 + 位置 + 方向 + 字形 + 不得错字
【边缘磨损】  磕碰 / 外溢 / 压力不匀，且强调"不对称"
【印泥】      色值 + 浓淡 + 单色约束
【纸面】      色值 + 无桌面无阴影
【构图】      1:1 + 留纸边 + 图案区/刻字区比例
【画质】      刀痕与颗粒清晰，不是照片细节
【禁止】      30+ 条反例
```

三个值得注意的写法：

- **`【刻字】` 逐字列出**：`第1字「山」、第2字「亭」…`。比"刻山亭晚照"准确得多，因为把"有 4 个字"和"每个字长什么样"拆开说了。
- **`【边缘磨损】` 强调"不对称"**：不写这句，模型给你沿整圈均匀铺开的噪点，像加了 filter。
- **`【双色化规则】` 单独成节**：这是"印章"和"照片套框"的分水岭。塞在【任务】里一两句话不管用。

| --- | --- |

**画布必须是 1:1。** 给 3:2 圆形会被压成椭圆。

## 五、验收要点（针对本例）

在通用清单之外，这一张要特别看：

- [ ] **亭子还认得出来吗**：四根柱 + 翘檐顶 + 一条屋面斜线，够不够让人说"这是个亭子"？如果模型加了瓦片、栏杆、台阶，就是过度了。
- [ ] **松树有没有变成"写实的树"**：应该是主干 + 三层分枝 + 短促点簇，不是一棵有枝叶细节的松。
- [ ] **山脊是不是一条线**：不能有云雾、积雪层次、远近虚实。
- [ ] **"山亭晚照"四个字**：逐字核对。"照"字笔画多，最容易糊成一团。
- [ ] **字有没有压到亭子的屋脊**：刻字区在右，亭子在左，两者之间要有间隙。
- [ ] **圆环上有没有 1–2 处磕碰缺口**，且不对称。
- [ ] **纸面只有米黄 + 朱红两色**。

## 六、体检与收尾

```bash
python scripts/sealcut.py out/seal/raw/x.png --shape round --seal-type zhuwen \
    --out out/seal/seal_4k.png --size 4096 --crop --alpha
```

预期报告：

```json
{
  "seal_box_source": "saturated",
  "seal_box": [220, 220, 1561, 1561],
  "ink_coverage": 0.15,
  "hue_concentration": 0.99,
  "grey_leak": 0.0,
  "verdict": "clean"
}
```

判读：

- `ink_coverage 0.15`：朱文典型值，正常。
- `hue_concentration 0.99`：真单色。
- `grey_leak 0.0`：没有把照片灰阶搬进来。
- `seal_box_source: saturated`：印面靠高饱和掩膜定位成功。如果这里是 `fallback`，且画面里有灰色背景，要用 `--box` 手动框。

## 七、三个真实失败案例

### 案例 1：占了位符没换

`theme` 留着 `"[照片主题]"` 直接跑。

```
[error] E103 刻字内容「[照片主题]」是占位符或过短：请把「[照片主题]」替换成真实主题
```

退出码 1，不写文件。这是设计上的硬拦截——印章的刻字是核心，留着占位符等于没做。

### 案例 2：刻了 7 个字

`theme: "雪山飞狐夜归人"`。

```
[error] E401 刻字「雪山飞狐夜归人」共 7 字：图像模型渲染 6 字以上的汉字几乎必出错字/缺笔。
        建议压到 2–4 字，或改用 sealcut.py 的无字底 + stamp_text.py 叠字路线
```

怎么办：要么压成 4 字（如"雪山夜归"），要么走路线 B：

```bash
python scripts/stamp_text.py out/seal/raw_blank.png --text "雪山飞狐夜归人" \
    --out out/seal/seal_text.png --shape round --cols 2 --rough 1.2
```

### 案例 3：印面糊成一片

`pattern_ratio: 0.9`，图案几乎占满印面。

```
[warn] W304 pattern_ratio=0.9 偏高：留白不足，刻字会挤在边缘，建议 0.55–0.72
```

出图后 `sealcut.py` 会给出 `ink_coverage: 0.72`，超过朱文上限 0.60，`verdict: check`。

这是"塞太满"，不是色值问题，只能调 `pattern_ratio` 到 0.6 左右重出。

## 八、换成你自己的照片

1. 看图，选 1–3 个"能代表这张照片"的元素，写进 `keep`；其余写进 `drop`。
2. 给每个元素写一句"具体怎么画"（几根线、什么形状），放进 `style`。**这一步最费脑子，也最决定成败。**
3. 定主题字：2–4 字，优先繁简同形。
4. 改 `specs/photo-seal.json`，跑 `build_seal_prompt.py`，看质量门有没有报错。
5. 出图 → 体检 → 收尾。
