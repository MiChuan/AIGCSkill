# 示例：云端御剑 / 昆仑雪山 / 白玉天宫

原始需求（一句话，字段散落在里面）：

> 用我上传的图里的人物生成，不改变脸部特征，8K，剧集画风。
> 人物在云端御剑飞行，身穿青色汉朝修士服，腰间别白色玉葫芦酒壶，手持青色玉笛闭目吹奏，笛上系红色玉坠带红色流苏；
> 从左边俯拍，与人体方向成 135°；14mm 焦段；
> 右上角是巍峨华丽的纯白色天宫，左下角是云层下露出的皑皑昆仑雪山。

## 拆解（需求 → spec 字段）

| 需求片段 | 落到哪一节 | 处理 |
| --- | --- | --- |
| 用我上传的人物、不改脸部特征 | 【人物锁定】+ `character.ref` | visibility 设 `partly_occluded`（笛子贴唇） |
| 8K | Step 3 `--target 8k` | 模型原生 2K，8K 是重采样交付尺寸 |
| 剧集画风 | 【风格锚点】 | 《参考剧集》是占位符 → 换成可执行的画面语言 |
| 御剑 / 云端 / 服饰 / 玉笛 | 【情节场景】【服装道具】 | 加材质与接触关系 |
| 左上方 135° 俯拍 + 14mm | 【镜头】 | 视角+方位角+焦段+景别+纵深 |
| 右上角天宫 / 左下角雪山 | 【构图·画面四角】 | 加体量与受光 |

`specs/yujian-kunlun.json` 就是拆完的结果。

## 运行

```bash
cd image/hy-image35-cinematic
python scripts/build_prompt.py --spec specs/yujian-kunlun.json --outdir out/yujian-kunlun
```

产出 `out/yujian-kunlun/prompt.txt` 与 `meta.json`。

## 验收重点（这个场景特有的坑）

1. **笛子挡住半张脸**——闭目吹笛最容易把眼睛和鼻子吃掉。看露出的眉眼能不能和参考图对上，对不上就改"笛身贴唇但不遮眉眼"。
2. **135° 俯拍 ≠ 侧身背影**——要能同时看到脸的一侧和背部动势；如果只看到后脑勺，说明方位角写成了 160°+。
3. **14mm 的畸变必须可见**——衣袂、笛子在前景被放大，天宫与山脉被压缩。没有近大远小 = 焦段没生效。
4. **天宫不能压人物**——右上角是天宫，但人物是主体；天宫若占了画面 40% 以上，改"体量远大于人物"为"远景中偏右上的剪影"。
5. **云与剑要有接触**——脚下没有气浪或云被破开的痕迹，人物就是贴上去的。
6. **玉不能反光成玻璃**——羊脂玉是柔和的次表面散射，不是镜面高光。
