# 保脸：能做到什么，做不到什么

## 先说边界

Hy Image3.5 preview 的图生图是**参考图条件生成**，不是人脸 ID 注入（不像 InstantID / IP-Adapter FaceID 那样有独立的身份编码器）。
所以"不改变脸部特征"的真实含义是：

- **能保证**：不会换成另一个人；五官类型、脸型倾向、年龄感、发型走向稳定在同一人身上。
- **不能保证**：像素级一致。眼距、鼻头宽度、唇形细节会有几个百分点的漂移；光照极端或脸部过小时漂移更大。

要 100% 还原（比如影视定妆、需要与真人对得上），只能走后续换脸或人工修图。**对用户如实说明这一点，不要承诺"完全不变"。**

## 三个开关

| 开关 | 取值 | 作用 |
| --- | --- | --- |
| 参考图 | `image1` | 身份的唯一来源，必须有 |
| `input_fidelity` | `high` | 图生图贴近原图；`low` 会"自由发挥"，保脸必崩 |
| `revise` | `false` | 提示词改写开关。**开着会删掉保脸条款和机位约束**，所以必须关 |

## 参考图怎么选

- 单人、正脸或微侧 ≤30°、睁眼、五官完整
- 长边 ≥ 1024px；低于这个尺寸，放大后五官信息不够模型对齐
- **不要重度美颜/滤镜**：滤镜会被一起锁进结果里，而且模型会把磨皮当成真实皮肤
- 背景尽量干净：脸旁边的强对比图案会污染生成
- 光线均匀（不要强侧光/单侧阴影），否则新光影下容易"换了个气质"

需要锁定服装/道具时，追加 `image2`（服装参考图），不要和参考人物塞进同一张图——模型分不清哪个是身份、哪个是服装。

## 提示词里的三条硬约束

`build_prompt.py` 会自动写入，手改时别删：

1. **身份不变项清单**：脸型骨相、眉眼间距、眼型与双眼皮形态、鼻梁鼻头、唇形唇厚、发际线、肤色年龄感。
2. **禁改项**：不得换脸、美颜、改脸型比例、改眼型、增减年龄感。
3. **可验证项**：脸部高度占比 ≥ 8%；遮挡不得压住整张脸。

第 3 条最容易被忽略，也最常是失败原因——**脸只占画面 3% 时，模型没有足够 token 去还原五官**。

## 场景与保脸的冲突表

| 场景要求 | 对保脸的影响 | 处理 |
| --- | --- | --- |
| 闭目 / 低头 / 侧脸 >45° | 中→重度削弱 | 允许，但要求"露出的眉眼鼻唇可与参考图对应"；同时出一张睁眼正脸版对照 |
| 道具遮住口鼻（笛、面具、酒壶） | 重度 | 提示"笛身贴唇但不遮眉眼"，并保证眼部完整受光 |
| 逆光 / 剪影 | 重度 | 改为侧逆光，保留脸部补光 |
| 远景小人 | 重度 | 拉近到中景，或缩小画幅比例让人物更大 |
| 群体 / 多人同框 | 中 | 明确"仅人物 A 使用参考图身份，其余人物不得相似" |
| 水下 / 烟雾 / 雨幕 | 中 | 保留"面部清晰、无遮挡"条款，否则会被当成氛围遮罩 |

## 排查表

| 现象 | 最可能原因 | 改法 |
| --- | --- | --- |
| 完全换了个人 | `revise` 开着，或 `input_fidelity` 不够高 | 关 revise、fidelity 设 high |
| 像但明显不像 | 参考图带强滤镜 / 光线差 | 换一张参考图 |
| 变年轻/变了性别气质 | 年龄感、性别描述与参考图冲突 | 在【人物锁定】补"保持参考图年龄感与性别气质" |
| 脸型被削瘦 | "唯美/精致/仙气"类词把脸往网红脸拉 | 删掉这类词，加"保留原始脸型宽度与下颌角" |
| 五官糊 | 脸占比太小 | 改景别或画幅，让人物更大 |
| 表情僵硬 | 只写了情绪词 | 写具体：视线方向、嘴部状态、肌肉紧张度 |
| 手/耳朵比例崩 | 遮挡处没有像素依据 | 简化手部动作，或让手出画 |

## 一轮只改一件事

保脸失败时不要同时改提示词、换参考图、调尺寸——那样你无法判断哪个改动起了作用。按 **参考图 → fidelity → 遮占比 → 提示词** 的顺序逐个排除。
