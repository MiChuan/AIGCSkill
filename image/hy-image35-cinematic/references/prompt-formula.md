# 提示词公式与词库

## 一、为什么用分节结构

模型对「带标题的中文分节」比长段落更敏感：每一节是一个可独立检查的约束组，出问题时能定位到节，而不是重写整段。
`build_prompt.py` 固定输出 11 节，顺序不要随意调：

| 节 | 作用 | 缺了会怎样 |
| --- | --- | --- |
| 【任务】 | 定品类：剧照 / 海报 / 概念图 | 模型按"插画"默认审美走，塑料感 |
| 【风格锚点】 | 把剧名翻译成光比、色调、颗粒 | 画风飘，像通用 AI 图 |
| 【人物锁定】 | 身份不变项 + 禁改项 | 换脸、美颜、脸型走样 |
| 【人物表现】 | 姿势、表情、脸部占比、遮挡 | 脸太小 / 被道具吃掉 |
| 【服装道具】 | 材质、结构、纹样、配饰 | 汉服变成影楼装，玉器变塑料 |
| 【情节场景】 | 干什么、在哪、空间关系 | 人物悬空，缺少接触与气流 |
| 【构图·画面四角】 | 方位化构图 | 天宫跑到中间挡住人物 |
| 【镜头】 | 视角 + 方位角 + 焦段 + 景别 + 纵深 | 透视随机，画面没有电影感 |
| 【光影与大气】 | 光源位置 + 光型 + 空气透视 | 平光，无体积感 |
| 【质感与调色】 | 主色、高光、暗部、颗粒 | 过饱和 / 过度 HDR |
| 【画质】 | 具体到什么纹理要清 | 4K 尺寸、720p 信息量 |
| 【禁止】 | 排除项 | 水印、乱码文字、多指 |

写法要点：

- **每个形容词都要能落到像素**。"华丽"没用，"多重飞檐、玉阶、悬空廊桥层层叠叠"有用。
- **方位词用画面坐标系**：右上角 / 左下角 / 画面中部偏左，不要用"背景里""远处"。
- **数量与体量要写**："天宫体量远大于人物"比"巨大的天宫"可控。
- **正向描述优先于否定**。禁止项只兜底，不要指望"不要糊"能让画面变清。

## 二、焦段词库（视觉后果，不是参数）

| 焦段 | 视觉后果 | 适合 |
| --- | --- | --- |
| 8mm | 鱼眼，边缘拉扯 | 极端主观、梦境 |
| 14mm | 超广角，近大远小强烈，边缘轻微桶形畸变 | 大场景 + 人物同框，御剑、崖顶、宫阙 |
| 16–24mm | 空间被撑开，环境信息量大 | 建筑、群像、环境叙事 |
| 28–35mm | 临场感强，畸变可读 | 纪实、跟拍、市井 |
| 50mm | 接近人眼，不夸张不压缩 | 对话、正剧 |
| 85mm | 背景压缩，焦外柔 | 人像特写、情绪 |
| 135mm | 空间被压平，背景化色块 | 孤立主体、大虚化 |
| 200mm | 极度压缩 | 压缩层叠山峦、偷窥感 |

超广角（≤16mm）必须同时声明"近大远小/边缘畸变"，否则模型会画成普通广角，失去冲击力。

## 三、视角词库

| 写法 | 模型理解 | 常见坑 |
| --- | --- | --- |
| 高位俯拍 | 镜头朝下压，地面/云海成背景板 | 容易变成"卫星图"，人物太小 → 必须补景别 |
| 平视 | 与视线齐高 | 最稳，但最平 |
| 低角度仰拍 | 主体压向观众 | 脸容易变形，慎用于保脸任务 |
| 鸟瞰 | 近垂直向下 | 人物成坐标点，不适合看脸 |
| 过肩 | 前景肩部虚化块 | 需要指定"前景虚化占画面 1/5" |

方位角写"机位在人物 X 侧、与人体朝向夹角 N°"，比"从左面拍"精确。135° ≈ 侧后方 3/4，能同时看到脸的一侧和背部动势。

## 四、四角构图法

模型对"某角有什么"的服从度远高于"背景里有什么"。原因很实在：位置是最容易验证的约束。

- 2–3 个角最有效，4 个角会互相打架。
- 主角所在的角落留给"体量压迫"（天宫、巨像、瀑布），对角留给"纵深延伸"（山脉、海面、道路）。
- 角落元素要写**体量关系**（"体量远大于人物"）和**受光方式**（"被逆光镀上淡金边"），否则会贴成一张平面贴纸。

## 五、风格锚点映射

`STYLE_ANCHORS` 只是起点。占位符（《参考剧集》《XX剧》）必须换掉，否则等于没写。

| 锚点 | 可执行的画面语言 |
| --- | --- |
| 长安十二时辰 | 唐风写实，暖金赭红，高光略溢，镜头贴身，颗粒明显 |
| 琅琊榜 | 宋式清雅，低饱和青灰，柔光留白，构图端正 |
| 庆余年 | 明快偏暖，光线干净，面部平光 |
| 流浪地球 | 冷蓝灰，硬光与机械高光，尘雾体积感 |
| 繁花 | 霓虹强色偏，浅景深，皮肤油润，暗部噪点 |
| 卧虎藏龙 | 青绿色阶，柔雾，衣袂飘动，动静对比 |
| 影 | 水墨黑白灰，宣纸质感，极简构图 |
| 沙丘 | 土黄石灰，硬边逆光，极简几何，尘埃颗粒 |

写不出映射？退化成三段：**主色 + 光型 + 颗粒/质感**。"青金双色 + 侧逆光 + 轻微胶片颗粒"永远比"电影感"有用。

## 六、失败 → 改提示词

| 现象 | 改哪里 |
| --- | --- |
| 人物像贴上去的 | 【情节场景】补接触关系（脚踏剑身、袖被气流鼓起、云絮掠过） |
| 画面没有冲击力 | 【镜头】降焦段到 14–16mm，补"近大远小/边缘畸变" |
| 角落元素糊成一片 | 【构图·画面四角】补体量、材质、受光 |
| 整体发灰发脏 | 【光影与大气】写死光源方位与光型；【质感】限"暗部保留层次不压死" |
| 过度 HDR / 塑料感 | 【禁止】加"过度 HDR、塑料皮肤、CG 渲染感"；【任务】强调"非3D渲染" |
| 出现文字乱码 | 【禁止】加"文字、字幕、招牌文字"（Hy 3.5 文生字能力强，会主动加） |
