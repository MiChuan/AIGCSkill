# 空泛词 → 可执行参数

一句话：**每个空泛词背后都是一组具体的量，把量找出来写进去，把形容词扔掉。**

质量门 W201 拦这些词，不是因为它们「不好」，是因为模型会按自己的理解乱填——
你写的「电影感」和它理解的「电影感」之间差着一整套参数。

---

## 对照表

| 空泛词 | 实际对应的量 | 正确写法 |
| --- | --- | --- |
| 电影感 | 画幅 2.39:1 + 青橙分离 + 高光柔化 + 浅景深 | `2.39:1，青橙调色，高光柔化，f/2.8 浅景深` |
| 高级感 | 低饱和 + 大面积留白 / 单一材质 + 精确对齐 | `低饱和，大面积留白，单一材质，严格网格对齐` |
| 氛围感 | 光比 + 色温 + 颗粒 + 暗角的组合 | `暖调，R-B 0.10，轻微暗角，胶片颗粒` |
| 艺术感 | 媒介 + 笔触 / 工艺特征 | `水彩纸上平涂，边缘渗化 2mm` |
| 唯美 | 柔光 + 浅景深 + 暖调 + 过曝高光 | `柔光，f/1.8，暖调，高光轻微溢出` |
| 质感 | 材质细节 + 锐度 + 光的角度 | `砂岩表面，侧光 45° 凸显纹理，锐利` |
| 细节丰富 | 焦距 + 光圈 + 锐度 | `35mm f/8 全景清晰，从前景到远景都在焦内` |
| 大片感 | 画幅 + 光比 + 主体占比 | `2.39:1，光比 8:1，主体占画面 15%` |
| 治愈感 | 低饱和 + 暖调 + 柔光 + 低反差 | `低饱和，暖调，柔光，反差 0.28` |
| 赛博朋克 | 青品双色 + 高反差 + 夜景 + 霓虹高光 | `青蓝阴影品红高光，夜景，反差 0.72` |
| 胶片感 | 颗粒 + 色偏 + 低反差 + 暗角 | `胶片颗粒 RMS 4，暖偏，反差 0.35，轻微暗角` |
| 通透 | 低反差 + 高光不溢出 + 蓝青阴影 | `低反差，高光留细节，阴影偏蓝青` |

## 怎么展开一个新词

遇到表里没有的空泛词，按这三步拆：

1. **它改变的是哪个维度？**画幅 / 光 / 色 / 镜头 / 材质 / 风格？
2. **这个维度上具体的量是多少？**跑 probe 拿数。
3. **这个量在提示词里叫什么？**写标准名（光比 8:1，不是「对比很强」）。

举例：「这张图像新海诚」。
- 维度：风格（媒介）+ 色（高饱和蓝绿）+ 光（逆光 + 空气透视）。
- probe 量：饱和度 0.65（浓艳）、色温微冷、反差 0.55、全景清晰、干净（渲染特征）。
- 写法：`日式动画电影风格，高饱和蓝绿天空，逆光，空气透视，远景全景清晰，干净的数字渲染`。
- 「像新海诚」五个字一个字都没出现，但出的图会比写了这五个字的更像。

## 反面：这些词模型认

不是所有形容词都无效。模型**认**的词有一个共同特征：它们对应训练数据里的稳定视觉模式。

| 可用 | 为什么 |
| --- | --- |
| 写实摄影 / 水彩 / 油画 / 像素艺术 | 媒介，训练数据里有明确视觉模式 |
| 黄金时刻 / 蓝调时刻 / 正午 | 时间，对应稳定的光色组合 |
| 35mm / 85mm / 微距 | 焦段，对应稳定的透视与景深 |
| 浅景深 / 全景清晰 | 光学特征，模型懂 |
| 低饱和 / 高饱和 / 单色 | 色彩量，模型懂 |
| 颗粒 / 胶片颗粒 / 噪点 | 纹理特征，模型懂 |

判据：**这个词能不能翻译成一组 probe 能测出来的量。**
能，就是有效词；不能，就是空泛词，拆开再写。
