# 逆向常见失败模式

一句话：**反推的错误分两类——量错了（probe 能拦住），和想错了（只有 verify 能拦住）。**

---

## 量错了

| 症状 | 原因 | 改法 |
| --- | --- | --- |
| 光位判成「中心聚光」 | 渐变天空 + 暗地面，四角天然暗 | 看九宫格数值分布：中排整体亮于上下两排就是「水平带状光源」，不是聚光 |
| 暗角判成「明显」 | 四角本身是暗部（地面 / 阴影 / 边框） | 对照原图：角上的暗是内容还是后期压的 |
| 主体候选框很大 | 渐变背景（天空 / 水面）与边带色差异大，被算成前景 | 候选面积 >40% 时直接人眼定，不信 probe |
| 噪声判成「极干净」 | 图是截图 / 二次压缩 | 注明「量测基于压缩图」，噪声一项忽略 |
| 锐度判成「极锐」 | 图带胶片颗粒 / 高 ISO 噪点 | probe 已做中值滤波，仍判高就是真锐 |
| 色板缺了主色 | 主色占比 <5% 被过滤 | 把 `--k` 调大，或接受「这色不重要」 |

## 想错了

| 症状 | 原因 | 改法 |
| --- | --- | --- |
| 重出图内容对了，氛围不对 | 光 / 色温 / 反差三段没写，模型自由发挥 | 三段补齐，verify 的明暗分布与色温项会告诉你差多少 |
| 重出图氛围对了，内容不对 | 主体段太抽象，「一个人」「一座山」 | subject.what + detail 补到「能认出是谁 / 什么」的粒度 |
| 重出图像但构图歪了 | 只写了「居中构图」，没写三分法位置 | composition.subject_position 用 probe 给的三分命名 |
| 重出图比原图「精致」 | 把「看起来精致」当成了目标，其实原图是「粗糙但准确」 | probe 的噪声 / 锐度 / 颗粒读数会告诉你原图的真实画质 |
| 重出图比原图「脏」 | negatives 没写全，模型自己加了水印 / 文字 / 杂物 | negatives 补「watermark / text / logo / 多余人物 / 边框」 |
| verify 分数卡在 70 | 每次改多个字段，不知道哪项生效 | **一次改一处**，重出再验 |
| 四档都试了都不像 | spec 本身错了：主体判断错 / 风格判断错 | 回到 Step 1 重新读 probe.md，别在 build 层打转 |

---

## 一个判断标准

反推到位的标志不是「提示词写得很长」，而是：

> **把原图遮住，只读提示词，能不能在脑子里复现这张图的 80%。**

能，说明提示词承载了足够的信息；不能，说明还在写「好看」「电影感」这种无效词。
verify 的分数是这个过程的量化版。
