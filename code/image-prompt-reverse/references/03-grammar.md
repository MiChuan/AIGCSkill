# 四档提示词语法与各模型差异

一句话：**同一个 spec，四种写法；选哪一档看目标模型吃什么，不看哪档最长。**

---

## 四档对比

| 档 | 结构 | 长度 | 给谁 |
| --- | --- | --- | --- |
| short | 一句话，主体 + 动作 + 环境 + 光 + 镜头 + 风格 | ≤45 词 | 检索 / 快速重出 / 库存档 |
| natural | 六段整句：主体 / 环境 / 光 / 镜头 / 材质 / 风格与画幅 | ≤130 词 | Hy Image / GPT-image / 豆包 / 即梦 |
| mj | 逗号短语堆叠 + `--ar` 参数后缀 | ≤60 短语 | Midjourney |
| sd | 逗号标签 + 独立 negative prompt | 各 ≤75 标签 | SD 1.5 / SDXL / Flux |

---

## natural：整句，给吃自然语言的模型

```
【主体】独行旅人剪影，长风衣下摆被风吹起；双肩背包；仰头望向天顶，静立于沙丘脊线上。
【环境】黄昏时的沙漠，近处沙丘表面有风蚀纹理，无云天空，从地平线向上由橙转靛。
【光】水平带状光源，中性光比，黄金时刻最后十分钟，暖调，中等反差。
【镜头】远景全身，35mm，平视略低机位，全景清晰。
【材质】沙的细密颗粒。
【风格与画幅】写实摄影，轻微暗角，主色：棕 #956a46、暗深灰 #1d223c，画幅与构图：3:2，左三分 / 下三分。
```

要点：
- **段序不能乱**：主体永远第一段。模型对段首的权重最高。
- 每段内部按「从大到小」排：环境里先地点再前景再背景。
- 中文模型（豆包 / 即梦）直接给这段；英文模型把内容翻成英文，结构不变。

## mj：短语，给 Midjourney

```
独行旅人剪影, 长风衣下摆被风吹起, 静立于沙丘脊线上, 黄昏沙漠, 水平带状光源,
黄金时刻, 远景全身, 35mm, 平视, 全景清晰, 写实摄影, palette 棕 #956a46 --ar 3:2
```

要点：
- 逗号分隔，不写完整句子；MJ 对语序不敏感，对关键词密度敏感。
- `--ar` 只接受整数比（3:2、16:9），不给小数。
- `--v 6` 之后 MJ 吃自然语言更好了，但短语版仍然是上限最稳的写法。
- 色板 hex 直接写进 `palette` 前缀，MJ 6+ 认。

## sd：标签 + 负面

```
写实摄影, 独行旅人剪影, 长风衣, 静立沙丘, 黄昏沙漠, 水平带状光源, 暖调,
远景全身, 35mm, 全景清晰, palette 棕 #956a46
```
negative：`文字, 水印, logo, 多人, 帐篷, 车辙, watermark, text`

要点：
- SD 对正向里的「不要」「没有」免疫——否定词进 negative，不进正向。
- negative 里 `watermark / text / logo` 是默认三件套，除非 spec.text_in_image 非空。
- 标签之间无语法权重，靠前优先；风格词放最前。

## short：一句话，给检索

```
独行旅人剪影，静立于沙丘脊线上，黄昏时的沙漠，黄金时刻，水平带状光源，远景全身，35mm，写实摄影
```

要点：
- 这是「这张图是什么」的最小可复现描述，不是提示词的全部。
- 用途：存库检索、快速重出验证 spec 大方向对不对、给别的 agent 传上下文。
- 超过 45 词质量门 W203 会报——short 的价值就是短。

---

## 各模型的脾气

| 模型 | 吃什么 | 忌讳 |
| --- | --- | --- |
| Midjourney | 短语 + 参数后缀 | 长整句、中文、否定词 |
| SD 1.5 / SDXL | 逗号标签 + negative | 正向里写「不要」、标签超过 75 个 |
| Flux | 自然语言整句 | 过短的标签串 |
| GPT-image | 完整自然语言段落 | 参数后缀（不认 --ar） |
| Hy Image | 中文整段 + 明确参数 | 空泛词、缺少画幅 |
| 豆包 / 即梦 | 中文整段 | 英文参数后缀 |

**拿不准目标模型时先出 natural**——它的信息密度最高，其他三档都能从它退化出来。
