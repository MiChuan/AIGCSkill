# 看图顺序与八维判据

一句话：**从大到小看，从客观到主观看；先锁画幅和构图，再谈光和色，最后才是风格。**

反着来的后果：风格词写了一堆，画幅错了——verify 扣 20 分的那一项往往就是画幅。

---

## 八维，按这个顺序填 spec

| 序 | 维度 | 先问 | probe 给什么 | 人眼补什么 |
| --- | --- | --- | --- | --- |
| 1 | 画幅 | 这张图是横的还是竖的、多宽？ | `aspect`（标准比） | 无 |
| 2 | 构图 | 主体在哪、多大、什么线条主导？ | 主体候选位置 / 水平线占比 / 对称性 | 主体是什么 |
| 3 | 光 | 光从哪来、多硬、什么颜色？ | 光位 / 光比 / 色温 | 时间（黄金时刻 / 正午 / 夜景） |
| 4 | 色 | 主色是哪几个、各占多少？ | 色板 hex + 占比 | 角色（这个蓝是天空还是衣服） |
| 5 | 镜头 | 离多近、什么焦段、景深多浅？ | 景深比 / 锐度 | 景别（特写 / 中景 / 远景）与机位 |
| 6 | 材质 | 表面是什么触感？ | 噪声 RMS / 锐度 | 材质名（砂岩 / 丝绸 / 旧木） |
| 7 | 风格 | 写实还是插画、渲染还是照片？ | 锐度 + 噪声（渲染图特征） | 媒介判断与参考 |
| 8 | 文字 | 图里有没有字 / 水印？ | 边带与角落梯度嫌疑 | 定性：内容还是叠加物 |

**第 1、2 维错，后面全白写。**画幅错是结构性错，风格再对也救不回来。

## probe 读数速查

| probe 字段 | 读法 | 进提示词的写法 |
| --- | --- | --- |
| `aspect` | 直接抄 | `composition.aspect` |
| `light.direction` | 括号前是主词，括号里是判读依据 | `light.direction` |
| `light.key_fill_ratio` | <2.5 软光，2.5–6 中性，6–15 硬光，>15 剪影 | `light.quality` |
| `light.backlit_suspect` | true 时主体正面要补光，否则剪影成黑影 | 补「主体正面补光」 |
| `brightness.contrast` | <0.30 低反差，0.30–0.55 中，0.55–0.75 高 | `light.contrast` |
| `palette[].hex/share` | 占比 ≥5% 的进 spec | `color_palette` |
| `temperature.warmth` | >0.03 暖，<-0.03 冷，之间中性 | `light.temp` |
| `dof.center_edge_ratio` | >1.3 浅景深，<0.85 反向（移轴 / 径向模糊） | `camera.dof` |
| `sharpness.score` | >88 像渲染 / 过锐化，<25 像虚焦 | `camera.sharpness` |
| `noise.rms` | <1.2 干净（渲染 / AI 特征），>3 明显颗粒 | `material` |
| `subject.position` | 三分法命名 | `composition.subject_position` |
| `text_suspect.flag` | true 时先定性再决定进哪段 | `negatives` 或 `text_in_image` |

## 三个「人眼必须接管」的点

1. **主体是什么**：probe 只给位置和面积，不给语义。「左三分的深色块」是人还是岩石，
   只有看图才知道。
2. **风格判断**：「写实摄影」和「高度仿真的 3D 渲染」在 probe 读数上几乎一样
   （都干净、都锐），靠材质细节和内容合理性区分。
3. **文字性质**：底部一行高对比小字，是海报标题（内容，进正向）还是平台水印
   （叠加物，进 negatives），决定了重出图像不像。

这三项在 spec 里都有明确字段，不要混进 probe 的自动填充里。
