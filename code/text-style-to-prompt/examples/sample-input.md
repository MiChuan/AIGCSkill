# 良率不上发布会

一颗芯片有多快，发布会会告诉你。一颗芯片有多难造，发布会不告诉你。

3nm 是节点名。不是尺寸。晶体管的栅极早就不止 3 纳米，它只是被这么叫。

这是行业里最公开的秘密：命名是市场部的活，不是工艺的活。

我们习惯把制程当成刻度尺，每隔两年往前挪一格。可刻度尺不会告诉你，挪这一格要烧掉多少钱。

一条先进产线的报价在百亿美元量级。设备进场之后，还要等良率爬坡。爬坡期以季度计。头三个季度，每片晶圆的成本都高于售价。

所以真正的门槛不是能不能做出来。是能不能用做出来的东西赚钱。

有人会说，那就降价。降价能让客户进来，不能让良率上去。良率是工艺的函数，不是价格的函数。

我们看到的是参数。看不到的是报废。报废不上台面，因为它不产生叙事。

一台机器可以买到。一支能把它调到良率的队伍，买不到。这支队伍要十年。十年里，人会被挖走，会被裁掉，会退休。

这就是为什么追赶很难。不是差一代设备。是差一代人。

算力也一样。峰值算力是标称值，实际吞吐取决于内存带宽。

一块卡标称多少 TFLOPS，写在参数表第一行。内存带宽写在第七行。真正决定训练时间的是第七行。

于是有了一个反直觉的现象：模型变大之后，瓶颈从算力移到搬运。数据在显存和计算单元之间来回跑，跑得比算得慢。

这就是所谓的存储墙。墙不是比喻，是延迟。一次访存的代价，是几百个时钟周期。

工程师对此的回应很朴素：少搬一点。把数据切块，让它在缓存里多待一会儿。听起来不像突破，像节约。

所有的性能优化，最后都长得像节约。

还有一个被忽略的变量：工具。设计一颗先进芯片，要跑完一整套签核流程。流程不是软件，是几十年累积下来的规则库。

规则库的特点是，你说不出它哪里对。它只是让芯片能过签核。换一家工具，同一份设计报告会多出几百条违例。

所以替代不是把软件换掉。是把几千条没写下来的经验重新踩一遍。

资本能买设备，买不到规则库。政策能建厂，建不了良率曲线。这两件事都需要时间，而时间不接受加速。

我们常说要补短板。短板这个词有误导性，它暗示只要把板子补齐，桶就能装水。可这里的板子之间是焊死的。动一块，旁边三块跟着变形。

写到这里，应该给个结论。可结论是：没有捷径。这四个字在任何一份 PPT 里都卖不出去。

那就换个说法。慢一点，也是一种快。
