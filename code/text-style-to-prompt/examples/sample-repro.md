# 电池不看标称

一块电池能跑多远，参数表会告诉你。一块电池五年后还能跑多远，参数表不告诉你。

续航是标称值。不是承诺。测试工况是一段循环，不是一条路。

我们看到的数字，来自实验室。实验室恒温，无风，载重为零。

真实的路面不讲这些条件。冬天电池内阻上升，可用容量下降。下降的幅度，取决于温度曲线，不取决于宣传口径。

有一个指标很少被提起：衰减率。头两年每年掉 2% 到 3%，之后趋于平缓。这条曲线不是线性的。用线性去推五年后的容量，一定会算错。

所以二手车的估值逻辑，和车况关系不大，和电池健康度关系很大。

有人会说，那就换电。换电能解决补能时间，解决不了电芯一致性。一组新旧混装的电池，短板会拉低整组。

这就是木桶效应的老问题。只是这里的桶板是焊死的。换一块，整组重新配平。

材料路线也一样。磷酸铁锂便宜，三元能量密度高。便宜和高，很少有同一个答案。

一个常见的误解，是把能量密度当成唯一目标。密度决定装得下多少，热管理决定敢不敢用满。后者不上发布会，因为后者不好讲。

我们看到的是化学体系。看不到的是制造一致性。同一批浆料，涂布厚度差 2 微米，循环寿命就差一个档。

设备可以买。调设备的人买不到。一条产线的良率，靠三年的试错攒出来。

这就是为什么扩产比研发难。不是缺图纸。是缺时间。

充电网络也有同样的账。桩的数量是分子，可用率是分母。分子容易上新闻，分母不容易。

一座充电站的瓶颈，往往不是功率，是电网容量。增容要报批，报批要排队。排队的时间，比建站的时间长。

所以补能体验的短板，最后落在配电侧，不在车端。

回收也是一样。退役电池不是废料，是品位不低的矿。可拆解的经济性，取决于一致性。

同一型号的包，拆起来是流水线。混装的包，拆起来是手工活。手工活的成本，写不进商业计划书。

写到这里，应该给个结论。可结论是：没有便宜的快。

那就换个说法。慢，也是一种成本控制。
