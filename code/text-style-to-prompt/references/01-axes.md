# 六轴：风格到底是什么

「风格」是读后感，没法直接传给另一个写作者。能传的是 **结构化的可执行规格**——
每一条都能指回原文，每一条都能写出一个 pass / fail 判据。

这六轴是骨架，每条 spec 必落在一个轴上。轴之间允许有重叠（句法影响语用），
但每条 spec **只填一个主轴**——填两个就没人执行了。

## 六轴一览

| 轴 | key | 量的是 | 典型问题 | style_probe 对应字段 |
| --- | --- | --- | --- | --- |
| 结构 | `structure` | 段落是怎么组织的 | 一段几句？单句独立成段的比例？ | `paragraph.*` |
| 句法 | `syntax` | 句子是怎么长的 | 句均多长？是否短句为主？并列还是从属？ | `sentence.*` |
| 词汇 | `lexicon` | 在用哪些词 | 字种比？虚词密度？高频二元组？禁用词？ | `lexicon.*` |
| 意象 | `imagery` | 在用哪类象 | 比喻落在什么域？身体／自然／工程／抽象？ | （无，需人读） |
| 语用 | `pragmatics` | 作者对读者什么姿态 | 用第几人称？设问？让步？直接对话？ | `person.*` `dialog.*` |
| 排版 | `typography` | 在版面上长什么样 | 一段一行？空行率？有标题？有列表？emoji？ | `layout.*` |

`tone`（语气）是兜底轴：写不进前六轴的收尾性判断放这里，但**不要把整篇都堆到 tone**——
「冷静」是结果，原因散在前六轴里。

## 每条 spec 的三件套

```
axis:  落在哪个轴（只填一个）
rule:  要求长什么样（必带数字或对照）
evidence: 原文里哪句能印证（4–200 字引文）
check: 怎么算过了（不含糊的可验收判据）
```

**evidence 必须是原文照抄**，不是改写。check 必须能交给另一个人去数——
「短句率不低于 27%」「感叹号 0 个」「至少 2 处单句独立成段」算合格，
「读起来有节奏」不算。

## 各轴的反例

### structure
- ❌ 「段落清晰递进」——递进是怎么递？数字呢？
- ✅ 「每段 2–3 句，最多不超过 4 句；至少 2 处单句独立成段」

### syntax
- ❌ 「句子长短结合」——结合的比例是多少？以谁为主？
- ✅ 「单句 8–22 字，全文句均不超过 16 字；短句率不低于 25%」

### lexicon
- ❌ 「用词精准克制」——精在哪儿？克制了什么？
- ✅ 「禁用词：赋能、闭环、生态、颠覆、革命性；『的地得』密度不超过 40 / 千字」

### imagery
- ❌ 「比喻生动形象」——生在哪？取的什么象？
- ✅ 「比喻只取工程与制造业的物：刻度尺、墙、桶、板子；不用自然景物与身体隐喻」

### pragmatics
- ❌ 「人称恰当」——对谁恰当？
- ✅ 「第一人称只用『我们』，不用单数『我』；不向读者设问，疑问句 0 个」

### typography
- ❌ 「版面清爽」————清爽怎么量？
- ✅ 「一段一行，段间空一行；空行率不低于 40%；不用小标题、不用列表、不用加粗」

## 轴的优先级

写不全六轴时，按这个顺序补：

1. **syntax + structure**（决定一篇长什么样）
2. **lexicon**（决定紧不紧）
3. **pragmatics**（决定作者是谁）
4. **typography**（决定在版面上像不像）
5. **imagery + tone**（决定读者读完留下的印象）

少于 3 条的 spec 不接受——少于 3 条不足以构成风格。多于 12 条也不接受——
多于 12 条没人能执行。

## 与 style_probe 的关系

style_probe 给六轴里的五个轴产出可比较的数字（imagery 除外，意象要人读）。
写 spec 时**反过来用**：先看 `style_probe --summary` 的输出，找偏离普通文本最远
的那几个指标——它们就是这篇文本的风格核心；然后把指标翻成人话写进 rule，把
判据写进 check，把原文照抄进 evidence。

不要从「我觉得这篇风格像 XX」开始写 spec。从数字开始，再用人的话补语感和意象。
