# 复刻协议：写完之后怎么算数

写完提示词不算完。把提示词交给模型，让它按规格写一段新文本，再用
`style_compare.py` 比对——比不过就是规格没写对，回去改规格，不是改判据。

这是整个 skill 唯一一个「不许自说自话」的环节。specs/selfcheck/anchors 都是
人写人审，会有偏；只有两份指纹的客观差值不带情感。

## 三步

1. **取参照指纹**
   ```bash
   python scripts/style_probe.py --text 原文.txt --out out/ref.json
   ```

2. **用提示词重写**
   把 `prompt-anchored.md`（或 standard）交给模型，让它按规格写新文本。
   主题换成新主题——原文本讲芯片，新文本就讲电池 / 房价 / 任何主题，
   不要让它复述原文内容。

3. **取复刻指纹并比对**
   ```bash
   python scripts/style_probe.py --text 新文本.txt --out out/cand.json
   python scripts/style_compare.py --ref out/ref.json --cand out/cand.json
   ```

退出码 0 = 过线，1 = 没过。prints 出七轴打分表，最偏的三项列在最右边。

## 阈值

默认：总分 ≥ 75，每轴 ≥ 55。这是**像不像**的门槛，不是**好不好**的门槛——
比 75 高不代表写得好，只代表像。想严格一点用 `--min 80 --axis-min 60`。

**别把阈值调到 90 / 80 以上**。指纹有抽样噪声，特别是 < 800 字的样本：
短文本的句均长、字种比、标点密度都会随机波动。强行追高分会导致规格过度拟合
原文的局部特征，换主题就崩。

## 七轴权重

| 轴 | 权重 | 重的理由 |
| --- | --- | --- |
| 句法节奏 | 0.22 | 最像 fingerprint，换主题也稳 |
| 用词密度 | 0.20 | 词级习惯很难模仿，权重要给足 |
| 段落推进 | 0.16 | 段构决定「读起来什么节奏」 |
| 标点习惯 | 0.16 | 标点是最容易量、最不容易骗自己的 |
| 人称姿态 | 0.10 | 受主题影响大，权重压低 |
| 版面形态 | 0.10 | 形态稳定但区分度低 |
| 引语占比 | 0.06 | 没对话的全是 0，对话型才进入 |

权重不是审美排序，是「换主题后这个轴稳不稳」的排序。称得稳的权重大。

## 没过线怎么办

按轴看，从分最低的开始改 spec：

- **句法节奏低** → 检查句均长和短句率规格，把范围收窄
- **段落推进低** → 加段均句数和单句成段率规格
- **标点习惯低** → 看是哪类标点偏，加禁用 / 强制规则
- **人称姿态低** → 大概率是复刻文本换了主题，没引第三方；把「人称由主题决定」
  这点写进 spec，让模型自己按要求引
- **用词密度低** → 加禁用词和虚词密度上限
- **引语占比低** → 原文无引语的话这条不影响，0 vs 0 是满分
- **版面形态低** → 加段间空行、不用列表、不用加粗规格

**不要为了冲分去改原文本**。原文本是参照系。改规格，让模型按更好的规格生成。

## 警告

`style_compare` 会在以下情况出 warnings（不影响判定，但要看一眼）：

- `两份文本语料口径不同`——一份中文一份英文，句长类指标本来不可比
- `参照文本不足 800 字`——分数仅供参考，阈值放低
- `复刻文本不足 800 字`——同上

短样本是常态——很多用户上传的就 500 字左右。这种情况能做但不强求高分。
spec 写得对、复刻比随机写的文本接近原文，就算合格。

## 不该用复刻协议做什么

- **不评原创性**。两份指纹接近只能说明「同一种风格」，不能说明「没抄」。
  抄袭检测在另一条赛道。
- **不评质量**。风格可以很烂但是统一，复刻也会过关。好不好的判断在产品层。
- **不许用复刻分调整原文本**。原文本是 ground truth。看到分数低，
  改 spec、改 prompt，不是改源文本去凑分。
