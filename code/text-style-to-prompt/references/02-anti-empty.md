# 反空话：判据不许只有形容词

这个 skill 唯一容易翻车的一步，就是把「读后感」当成「风格规格」直接交给模型。
读后感是「文笔细腻」「富有张力」「行云流水」——读者读完会有，但写作者无法执行。

`build_prompt.py` 在校验阶段会把这些词挡掉，挡不掉的会在 stderr 出警告。这一篇
说明为什么挡、挡哪些词、被挡之后怎么改。

## 空话黑名单

下列词不是风格，是读后感。如果一条 rule 里出现它们，**必须**同时满足下面任一
条件才放过：

- rule 里带数字（句均 13 字、短句率 27%）
- rule 里带对照结构（用 A 不用 B、是 X 不是 Y、避免 Z）

否则 `SpecError` 直接退出：

```
优美  细腻  生动  感染力  文采  流畅  大气  高级感  有深度  耐读
雅致  灵气  张力  功底  行云流水  娓娓道来  引人入胜  回味  共鸣
独特  丰富  精准  恰到好处  别具一格  匠心  鲜活  自然  朴实
深刻  有力  克制  高级
```

这份名单不是完整答案——它会漏。所以校验之外还有第二道防线：每条 rule 必须配
一个 `check`，check 写不出来就说明 rule 没说清楚，回去改 rule，不是改 check。

## 怎么把形容词改成规格

四个套路，按好用度排：

### 1. 给对照（最稳）

把形容词翻成「用 A，不用 B」。

- ❌ 「风格克制」
- ✅ 「不用感叹号、不用破折号、不用省略号；强调靠句号断开短句，不靠标点」

### 2. 给数字

把「多 / 少 / 长 / 短」翻成具体量。量从 style_probe 取，不要凭感觉编。

- ❌ 「句子偏长」
- ✅ 「单句 8–22 字，全文句均不超过 16 字」

### 3. 给清单

把「用词讲究」翻成可枚举的词表。禁用词比允许词好用——允许的太多列不完，
禁用的一列就够。

- ❌ 「用词克制专业」
- ✅ 「禁用词：赋能、闭环、生态、颠覆、革命性、极其、非常、十分」

### 4. 给反例

把「不要啰嗦」翻成具体会被否的写法。

- ❌ 「表达简洁」
- ✅ 「禁用结构：不在段首用『首先/其次/最后』编号；不用三个以上形容词修饰
     同一个名词；不用『随着……的到来』开场」

## 三档等效

同一条风格规格可以写成强 / 中 / 弱三档，**优先用第一档**：

| 档 | 形式 | 例子 |
| --- | --- | --- |
| 强 | 数字 + 单位 | 句均 13.2 字 |
| 中 | 对照 + 范围 | 单句 8–22 字 |
| 弱 | 形容词（不放行） | 句子偏短 |

弱档过校验的情形只有一条：rule 里同时出现对照或数字兜底。否则一律打回。

## 易混淆的合法用法

下面这些不在黑名单里，但要小心——单独用仍然不合格：

- 「短促」「绵长」「轻盈」——这是节奏的弱描述，得落到句长数字上
- 「第一人称」「对话体」——这是语用标签，得落到「我们不用我」「疑问句 0 个」
- 「并列复句」——这是句法标签，得落到「不写从句」「一个判断不在一个句子」

判据很简单：**能不能把这个标签交给另一个写作者，让他按字照搬就能产出同样风格的文本？**
不能就改。

## 校验通过 ≠ 不是空话

`is_empty_claim` 是机械检查，挡不住伪装的高级空话。下面这条会过校验，但仍然是空话：

```
rule: 文笔富有张力的同时保持克制
```

「张力」和「克制」都在黑名单，但「富有」是多字、rule 自带「保持」对照——
按机械规则放行。这种漏网要靠人审：写完 spec 后回头读一遍，把每条 rule
替换成陌生主题，看还成不成立。能改成陌生主题仍然成立的，才是真规格。

## 写不出来就承认

遇到读得出、写不出规格的轴——常见是「意象」和「语气」——别硬填形容词。
两个选择：

1. 留空，等读完原文之后再补。spec 不强求六轴填满。
2. 改写成反向约束：「不用 XX 类象」「末段不许总结」——禁令比形容词容易执行。

写不出规格的轴，不是风格没抓住，是这一段还说不清。说不清的部分交给
语感锚点（anchors，最多 3 句原文）兜底，不要试图用形容词蒙混。
