# 判据库：测量 → 标签

改判据只看这一篇。`derive_traits()` 里每个阈值为什么是这个数、什么时候会失效，都写在这里。

## 1. 有没有节拍（第一道关）

| 量 | 算法 | 门槛 | 说明 |
|---|---|---|---|
| `tempo_strength` | 起音包络自相关的峰值（归一化到 0–1） | ≥ 0.45 | 有多大比例的起音能量是周期性的 |
| `beat_clarity` | 峰值相关 ÷ 平均绝对相关 | ≥ 3.2 | 这个峰是否真的突出于背景，而非噪声随机堆出来的 |

**两个必须同时用，缺一个就会出错：**

- 只看强度：一段**持续 55 Hz 正弦**能拿到 0.95 的强度、报出 75 BPM。原因是分析窗（64 ms）
  与信号周期（18 ms）的相位差会周期性抖动，产生假周期。
- 只看清晰度：白噪能凑到 2.9。

**为什么用低频段包络**：250 Hz 以下那一路对应「脚会跟着跺」的东西（底鼓、贝斯）。反拍有镲的
素材，全频段包络会被镲拉到倍速——自测里「80 BPM 底鼓 + 反拍踩镲」会被读成 160 BPM，切到低频
包络才稳。用了哪一路，会写进 `tempo_source` 字段。

**八度歧义是真歧义，不许假装没有**：80 与 160、60 与 120 在数学上是同一个周期网格。脚本把结果
折进 70–170 BPM（人实际数拍子的区间）当主解，另一个解放进 `tempo_alt_bpm`，提示词里写成
「120 BPM（或按 60 BPM 数，半速 / 倍速听感都成立）」。两个解都要交给生成模型。

## 2. 亮度：`centroid_hz`（谱质心）

| 标签 | 阈值 |
|---|---|
| very_dark | < 500 Hz |
| dark | 500–1200 |
| neutral | 1200–2500 |
| bright | 2500–4500 |
| glass | > 4500 |

**会失效的地方：**

- 有损压缩砍掉高频 → 系统性偏低。6–8 kHz 占比 < 0.5% 时脚本会警告，亮度标签要打折扣。
- 纯音色的质心等于它自己的基频。1 kHz 正弦的质心就是 1000 Hz，会被判成 dark。
  数值是对的（能量确实只在这一点），但不能据此说它是「暗色的音乐」。
- `centroid_slope_hz_s` > 300 说明亮度随时间上扬（扫频、滤波器打开）。这时候单一亮度标签会误导，
  应该用「逐渐打开的滤波器」这类动态描述。

## 3. 纹理：`flatness`（谱平坦度）

几何平均 ÷ 算术平均，取全帧均值。

| 标签 | 阈值 | 典型素材 |
|---|---|---|
| tonal | < 0.15 | 正弦、干净的人声长音 |
| mixed | 0.15–0.40 | 大部分真实音乐 |
| noisy | > 0.40 | 白噪、风声、磁带嘶声、镲片 |

**反向判据很有用**：一段号称是完整编曲的音乐，flatness 却 < 0.15，
大概率只是一件乐器的持续音，不是「交响编制」。

## 4. 人声：`voiced_ratio`

单帧「有谐波」说明不了任何事——一记底鼓的谐波比人声还干净。所以脚本只统计**连续 ≥5 帧
（160 ms）、相邻帧半音差 < 1.5** 的段落。

| 标签 | 阈值 | 含义 |
|---|---|---|
| instrumental | < 0.08 | 判为纯器乐，并据此生成「不要人声」的负向词 |
| some | 0.08–0.25 | 灰区，必须列为待答问题，不许直接下结论 |
| prominent | > 0.25 | 有人声，但仍需用户确认语种 |

`f0_hz` 只给粗略音区（< 140 低、< 220 中、其余高），**不能**用来判性别——录音里的基频与性别
没有这么干净的对应关系。

`pitch_std_semitones` > 2.5 是「说话 / 念白」的强证据（旋律线不会抖这么厉害）。

## 5. 其他量的失效边界

| 量 | 失效场景 |
|---|---|
| `key` / `key_mode` | 置信 < 0.55 时当作无调性。无调性音乐、采样拼贴、音效都会随机排出一个主音 |
| `lra_db` | 短于 10 秒的素材不可靠，起止两段本来就可能完全不同 |
| `reverb_tail_ms` | 经过压缩 / 限幅的素材会把尾音压住，读数偏短；尾巴被硬切也偏短 |
| `stereo_corr` | 单声道源返回 1.0，靠 `side_ratio` 双确认，两边都没差异才报 mono |
| `band_ratios` | 看 `air` 占比前先确认素材不是低码率有损——那是有损压缩最明显的痕迹 |
| `onset_rate` | 副歌密集加花会把平均密度拉高，密度标签要结合 `tempo_bpm` 一起看 |

## 6. 类型与情绪：三道过滤

`genre_bank` / `mood_bank` 里每条规则最多三个字段，串起来才是完整判据：

1. **`unless`（否决）**：命中任意一条直接出局。这是防止「有拍的东西被判成无拍长音」的唯一有效
   手段——光靠打分，5 条件的规则漏掉 1 条还能拿 0.8 分，照样通过。
2. **`must`（必要）**：缺一条出局。house / techno 必须有 `beat_clarity >= 3.0`。
3. **`when`（软性）**：过了前两关才轮到它算分，类型门槛 0.6，情绪门槛 0.8。

**多条都过**：只取最高分写进第 1 槽，次高的原样进「只能你答的问题」让用户二选一。
**一条都不过**：第 1 槽留空并列为待答问题。这是正确结果，不该凑一个出来。

**情绪门槛为什么比类型高**：情绪是唯一一个「错了没人会立刻发现」的槽位，宁可少写一个氛围词，
也不要给一段明朗的曲子扣上「紧张压抑」。明确反义的条件（如 `bright-hopeful` 对上 `very_dark`）
写成 `unless`，而不是靠扣分让它勉强通过。

**配器门槛 0.85**（比类型更高）：三条件的规则漏一条，靠软打分也能混进来，结果就是一段光秃秃的
鼓循环被配上「钢琴 + 弦乐 + 铺底 pad」。候选最多 3 个，且永远是候选，不是结论。
