把要分析的音频放在这里，命名 `target.wav`（或直接在命令里写绝对路径，不必真挪进来）。

## 素材要求

音频本身的质量直接决定读数的上限，比脚本本身重要得多：

- **优先无损**：wav / flac / aiff。有损压缩（尤其是低码率 mp3）会把 6–8 kHz 砍掉，
  亮度标签会系统性偏低，进一步影响「材质」和「情绪」两个槽位。
- **不要带 fade**：淡入淡出会让「动态」和「尾音长度」两个读数失真。
  要分析当元素材，就用原始导出版本，不要带加代码的版本。
- **完整胜过干净**：分析的是一段真实构成的话，素材至少要有 10 秒。
  只给 3 秒的话，脚本会在 stderr 里提醒你按音效路径处理。
- **不要提前归一化 / 限幅**：crest（波峰因数）是判断「有没有真正瞬态」的关键证据，
  压过一次就永久丢掉了。素材太响不怕，怕的是已削波——脚本会检出 clip_ratio 并给出警告。
- **不要加速 / 变调**：任何 pitch-shift 都会让调性与频谱质心同时错位。

## 二进制不入库

音频文件不进 git（见 `.gitignore`）。这个目录只留说明，等你把素材放在这里，
或把 `--out` 指向外部路径。
